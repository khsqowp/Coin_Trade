# 코인 공개 파생 아카이브 게이트 재점검 — 2026-11-24

## 목적과 경계

기존 코인 오더블록 라운드 R7–R10을 대체하지 않고, 고정 검증 기준을 충족할 수 있는 공식 공개 파생 데이터 경로가 있는지 확인했다. 시장 데이터 파일을 내려받거나 열지 않았고, 공용 `TRAIN_TRIALS.csv`, 사전등록, 러너, 기존 결과를 수정하지 않았다. 본 문서는 공식 웹 페이지의 현재 공개 메타데이터만 기록한다. 이 자료조사는 전략 시도 1회로 세지 않는다.

## 고정 게이트

- 코인 오더블록 후보는 최소 30개 종목, 사전등록된 시간대·기간, 비용·펀딩 반영, OOS 표본 기준 및 레드팀 검증을 충족해야 한다.
- 2018·2022 약세 구간을 빼거나, 현물 결과를 선물 결과로 간주하거나, 데이터가 부족한 상태를 성과 통과로 세지 않는다.
- Binance USDⓈ-M 로컬 보관자료는 2018년 월별 OHLCV·펀딩 파일이 없고, 2022년에는 26개 심볼만 있다는 기존 파일명 인벤토리가 있다. 이 문서에서 그 파일을 다시 읽지 않았다.

## 결정

이번 공식 페이지 재점검만으로 2018년과 2022년을 모두 포괄하는 30개 이상의 선물 종목 코호트를 증명한 대체 경로는 없다. 따라서 새 오더블록 백테스트를 시작하지 않는다. 이는 전략이 실패했다는 판정이 아니라 데이터 적격성 미충족이다. 기존 R8·R9의 실패 결과와 R10의 표본 부족 판정을 그대로 유지한다.

다음 진행은 원시 데이터 행을 열지 않고, 기존 저장소 카탈로그·인덱스에서 계약별 상장/상폐 시점과 월별 파일 존재를 메타데이터로 확정할 수 있는 소스만 좁히는 것이다. 이를 통해서도 고정 게이트가 열리지 않으면 코인 2개 목표는 미달로 보고하며 기준을 낮추지 않는다.

## 검증 경계

- 확인한 것: 위 공식 페이지의 현재 공개 설명 및 URL 동작.
- 확인하지 않은 것: 실제 데이터 파일의 월별 연속성, 종목별 모든 아카이브 객체, 데이터 이용권의 과거 적용, 전략 수익, OOS 결과, G 통과.
- 실행하지 않은 것: 데이터 다운로드, 가격행 분석, 백테스트, 공용 장부 기록, 추가 사전등록.
