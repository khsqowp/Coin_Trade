## 2. 장부 분모 (Bonferroni)
- 실행 직전 `TRAIN_TRIALS.csv` 데이터 행수 = `R`.
- **다중검정 분모 `N = R + 429 + 1000`** (429 = EXPLORE500 가산, 1000 = 전 레인 합 보수 산정, 다른 레인 동시 실행 가능분 포함). 이 레인의 300은 1000 안에 포함된다.
- 설정별 단측 p < 0.05 / N.
- 작성 시점 확인값은 실행 직전 재집계 값으로 대체하며, 보고서에 실제 R과 N을 기록한다.
- 실행 시 장부 잠금(`.cointrade_train_trials.lock`, `.ob_attrition_train_trials.lock`)과 `fcntl.flock`을 잡은 뒤 행수를 세고, 300행 추가는 단일 `os.write`로만 한다. 추가 직전 행수가 바뀌었으면 아무 행도 쓰지 않고 중단한다. 다른 레인이 쓴 경우 N을 재계산해 기록하고 사실을 보고한다.

## 4. 격자 생성기 (결정론적, 데이터 미열람)
- 계열 순서대로, 가변 파라미터 값 목록을 `itertools.product`(목록 기재 순서)로 전개. 격자 크기가 계열 배정 수와 다르면 실행 거부.
- 고정 파라미터: `reward_r=50`은 "목표 없음"(사실상 시간·손절 청산만). `horizon_bars`는 **24 또는 48만 허용**(`crypto.simulate_trade` 제약).
- C1: `lookback_days∈{1,2,3,5,7} × top_k∈{2,3,5} × horizon_bars∈{24,48} × stop_atr∈{2,3}`; 4h; 롱 = 수익 하위 K, 숏 = 상위 K.
- C2: `lookback_days∈{7,14,30,60,90} × top_k∈{2,3,5} × horizon_bars∈{24,48} × stop_atr∈{2,3}`; 4h; 롱 = 수익 상위 K, 숏 = 하위 K.
- C3: `vol_days∈{7,14,30,60,90} × top_k∈{2,4} × horizon_bars∈{24,48} × stop_atr∈{2,3}`; 4h; 롱 = 실현변동 하위 K, 숏 = 상위 K.
- C4: `window_bars∈{30,60,120,240} × entry_z∈{2.0,2.5,3.0,3.5} × horizon_bars∈{24,48}`; 4h; stop_atr 3.0 (각 레그).
- C5: `lag_bars∈{1,3,6,12,24} × shock_z∈{2.0,2.5,3.0} × horizon_bars∈{24,48}`; 1h; stop 2.0; 목표 1.5R.
- C6: `fast_bars∈{6,12,24,48,96} × slow_bars∈{120,240} × ratio_thr∈{1.3,1.6,2.0}`; 4h; horizon 24; stop 2.0; 목표 2.0R; 추세 = 현재 종가 − 24봉 전 종가 부호.
- C7: `fast_bars∈{6,12} × slow_bars∈{84,168} × rv_ratio_thr∈{1.3,1.6,2.0} × mode∈{trend,fade}`; 4h; horizon 24; stop 2.0; 목표 2.0R.
- C8: `offset_hours∈{1,2,3,4} × direction∈{long,short} × settle_hour_utc∈{0,8,16}`; 1h; horizon 24; stop 2.0; 목표 없음. 진입 봉 시각 = 정산시각 − offset.

## 5. 신호 정의 (모든 지표는 봉 i 이하 데이터만 사용: rolling·shift·diff, 합성 테스트로 확인)
- **횡단면(C1~C3)**: 4h 봉의 합집합 타임스탬프 격자에서 심볼별 로그가격 행렬을 만든다. 리밸런스 봉 `t`는 `t mod (horizon+1) = 0`인 봉만 신호 봉이다. 점수는 `t`까지의 값으로 계산한다. 유효 점수 심볼이 2K 미만이면 그 리밸런스는 건너뛴다. 롱 K개와 숏 K개를 같은 봉에 진입 신호로 낸다. 같은 봉 동시 진입, 달러 가중은 동일 가중(한 거래당 1단위).
- **C4**: `spread_i = ln(ETH_i) − ln(BTC_i)`. z = (spread_i − 직전 window봉 평균) / 직전 window봉 표준편차(표본). z ≥ e이면 ETH 숏·BTC 롱, z ≤ −e이면 ETH 롱·BTC 숏. 두 레그는 각각 독립 거래로 채점한다.
- **C5**: BTC의 L봉 로그수익 `r_L`과 직전 336봉 BTC 1봉 수익 표준편차 `σ`(직전 봉까지, 최소 168봉)로 `z = r_L / (σ√L)`. 충격 조건 `|z| ≥ shock_z`, 방향 `d = sign(r_L)`. 알트 `s`는 `d·r_L^s < d·r_L^BTC`일 때(같은 방향으로 덜 움직임) 방향 d로 진입 신호를 낸다.
- **C6**: `ratio = mean(V, fast) / mean(V, slow)`(봉 i 포함). `ratio_i ≥ thr`이고 `ratio_{i−1} < thr`인 교차 봉에서, 추세 `sign(C_i − C_{i−24})`가 0이 아니면 그 방향으로 신호.
- **C7**: `RV = std(1봉 로그수익, window)`(0 평균 아님, ddof=0). `RV_fast/RV_slow`의 상향 교차에서 추세(`sign(C_i − C_{i−fast})`) 또는 반대 방향(페이드)으로 신호.
- **C8**: 신호 봉 i에서 다음 봉(i+1)의 시각 시(hour)가 `(settle − offset) mod 24`와 같으면 신호. 방향은 direction 값.
- 워밍업: 각 심볼의 처음 500봉(`WARMUP_BARS`)의 신호는 금지한다.

## 6. 체결·비용·보유·중첩 (모든 계열 공통, 규칙 고정)
- 신호는 완결된 봉 `i`의 종가 기준. 진입은 **다음 봉 `i+1`의 시가**(기본). 같은 봉 체결 금지.
- **1봉 지연 검정**: 같은 신호에서 진입을 `i+2` 시가로 옮긴 거래(`delay=2`).
- 손절 = 진입가 ∓ stop_atr × ATR14(봉 i). 목표 = 진입가 ± reward_r × 손절거리. 같은 봉에서 손절·목표가 모두 닿으면 손절 우선(기존 규칙).
- 시간청산 = horizon 봉 뒤 다음 봉 시가(`crypto.simulate_trade`). 데이터 끝 부족 시 거래 없음(censored 계수).
- **비용**: 기본 편도 4bp + 슬리피지 2bp = 왕복 12bp. **비용×2**: 편도 8bp + 4bp = 왕복 24bp.
- 펀딩: 정책 `adverse_only`(순서 모호 정산은 불리한 방향으로 청구). 결과 불명 거래는 통계 제외하고 개수를 보고한다.
- **보유·중첩 규칙(고정)**: 심볼마다 동시에 최대 1포지션. 신호 봉 `i`가 직전 거래의 청산 인덱스(`exit_index`)보다 작으면 신호를 버리고 `skipped_overlap`으로 센다. 청산 봉 이후 신호만 채택한다. 동일 봉에서 여러 심볼이 신호를 내면 심볼별로 독립 처리한다. 횡단면 계열의 리밸런스 주기는 `horizon+1`이므로 시간청산 봉과 다음 리밸런스 신호가 겹치지 않는다(손절 청산 시 다음 리밸런스까지 기다리는 것은 정상).
- 포트폴리오 일별 수익: 거래별 일별 손익 합 / 종목 수(35), 기간 전체 일수에 대해 0 채움, 연환산 365일(기존 R14 방식).

## 7. 합격 규칙 (완화 없음)
### 7-1. 코어 게이트 — `metrics.core_gate(market="crypto")` 전부 통과
- 거래 수 ≥ 100 (코드의 코인 기준. 작업 지시문의 "60"은 코드 기준보다 느슨하므로 코드 기준 100을 따른다 — 더 엄격)
- 누적 수익 > 0, PF ≥ 1.30, 기대값 ≥ +15bp, Wilson 95% 하한 > 손익분기 승률, MDD < 누적수익/2, 연환산 Sharpe ≥ 1.0, 지급능력 유지.
### 7-2. 다중검정 — 거래별 순수익의 단측 정규근사 p < 0.05/N (N = R+1429)
### 7-3. 보강 검정 (반드시 함께 보고, **하나라도 실패하면 '후보 아님'**)
1. **1봉 지연**: 진입 `i+2` 시가 거래 집합에서 거래 ≥ 100, 기대값 ≥ +15bp, PF ≥ 1.30.
2. **진입일 군집 보정 p**: 거래를 진입일(UTC)로 묶어 군집 평균 수익을 만들고, 군집 평균에 대한 단측 t 근사 p < 0.05/N. (군집 수 ≥ 2 필요)
3. **비용×2**: 왕복 24bp 거래 집합의 기대값 > 0 bp.
4. **연도별**: 진입 연도(UTC)별 거래 수·기대값·합계를 전부 보고한다(약세 연도 2022 포함). 거래 ≥ 20인 연도는 **전부** 기대값 > 0. 그런 연도가 하나도 없으면 실패.
5. **상위 3종목 제외**: 기본 거래의 심볼별 순수익 합 상위 3개 심볼의 거래를 제외. 나머지 거래의 거래 ≥ 100, 기대값 ≥ +15bp, PF ≥ 1.30.
- **후보 = 7-1 & 7-2 & 7-3 전부 통과.** 후보라도 `TRAIN_ONLY_NOT_G`이며 G·OOS 승격이 아니다.
- 기준 완화 금지. 상위 결과를 보고 규칙을 바꾸지 않는다.
