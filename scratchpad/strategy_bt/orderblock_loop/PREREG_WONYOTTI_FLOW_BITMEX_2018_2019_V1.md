# 사전등록 — 워뇨띠 체결흐름의 BitMEX 2018–2019 단기 예측력

등록 시각: 2026-11-26 (Asia/Seoul)
상태: 실행 전 고정
실험 ID 접두사: `WONYOTTI-FLOW-BITMEX-2018-2019-V1`

## 질문과 해석 경계

워뇨띠 공개 XBTUSD 체결을 시간별 부호 순량으로 집계했을 때, 이미 완료된 흐름이 같은 거래소 XBTUSD의 다음 1시간 움직임을 예측하는가? 기존 2020–2021 Binance 대리시장 시험과 다른 과거 구간 및 동일 거래소 가격을 쓰는 단일 자산 탐색이다. 워뇨띠의 실제 규칙을 재현하거나 실시간 복제 가능성을 입증하지 않는다. 공개된 과거 원장에서는 계정 소유 체결을 실시간으로 식별할 수 없으므로, 성과가 양수여도 실행 가능한 실시간 신호가 아니다. 오더블록 전략도 아니며 시장별 G 통과 후보 수에 포함하지 않는다.

## 입력과 범위

- 계정 원장: `TRADING_DATA_DIR/external/crypto/wonyotti_bitmex/raw/aoa-execution-2018-03-01-2018-12-31.csv` 및 `aoa-execution-2019-01-01-2020-12-31.csv`에서 `exectype=Trade`, `symbol=XBTUSD`만 사용한다. `Buy` 수량은 양수, `Sell` 수량은 음수다. 수량 가중치 외 추가 가중은 없다.
- 시장 가격: 이미 보유한 `TRADING_DATA_DIR/external/crypto/wonyotti_bitmex/market/1h/XBTUSD-*-1h.json`의 같은 BitMEX XBTUSD OHLC만 쓴다. 외부 데이터·가격 파일은 받지 않는다.
- 사용 구간: 입력 파일로 확인 가능한 2018-03-05 00:00 UTC부터 2019-06-05 00:00 UTC 직전까지. 개발 구간은 2018-03-05 00:00 이상 2019-01-01 00:00 미만, 최종 시험 구간은 2019-01-01 00:00 이상 2019-06-05 00:00 미만이다. 시험 구간은 이 실행에서 한 번만 연다.
- 모든 시각은 UTC다. 지정 주간 파일 누락, 주간 파일 안 시간 누락·중복, 비정상 OHLC, 원장 또는 가격의 시간 공백은 해당 신호를 거래에서 제외하고 개수·비율을 보고한다. 데이터 구조 점검에서 66번째 파일 `XBTUSD-2019-06-03-1h.json`은 48시간만 포함해, 실사용 종료를 2019-06-05 00:00 UTC로 고정했다. 이 범위는 65개 완전 주간 파일과 마지막 파일 48시간, 총 10,968시간이다. 2019-06-05 이후는 사용하지 않는다.

## 고정 전략 규칙과 격자

각 신호시각 `t`에는 종료된 1시간 구간만 사용한다. 최근 `W={1,4,8}`개 종료 시간의 XBTUSD 순체결량 `net=sum(Buy qty)-sum(Sell qty)`와 총 체결량 `gross=sum(abs(qty))`로 `imbalance=net/gross`를 계산한다. `gross=0`이면 신호 없음이다. `abs(imbalance) >= T`, `T={0.00,0.10,0.25}`이면 `sign(net)` 방향 신호를 낸다. 따라서 개발 격자는 사전 고정한 9개 설정이다.

신호 구간이 완전히 닫힌 다음 시간의 BitMEX 1시간봉 시가에 진입하고 같은 봉 종가에 청산한다. 겹치는 포지션은 허용하지 않는다. 신호·체결이 같은 봉에 발생하지 않는다. BitMEX funding은 UTC 04:00·12:00·20:00에 발생한다. 정산 시각 직전과 직후의 진입을 모두 피하도록 진입 시각이 해당 시각 ±1시간이면 거래를 건너뛴다. 따라서 펀딩 정산을 통과하는 포지션은 없으며 funding을 0으로 가정해 보정하지 않는다.

XBTUSD inverse 계약의 1배 초기 증거금 대비 수익률을 사용한다. 매수 총수익은 `1-entry/exit`, 매도 총수익은 `entry/exit-1`이다. 체결 슬리피지는 진입·청산 각각 2bp 불리한 가격으로 반영하고, 수수료는 편도 10bp를 적용한다. 비용 2배 검사는 슬리피지 4bp/편도 및 수수료 20bp/편도다. 이 비용은 보수적 고정 가정이며 당시 계정의 실제 수수료 등급을 뜻하지 않는다.

자본곡선 진단은 매 신호마다 당시 자산의 10%를 1배 isolated 증거금으로 배정하고, 포지션은 한 시간 안에 종료하는 고정 규칙으로 만든다. inverse 수익이 증거금의 -100% 이하이면 증거금 전액 손실로 상한 처리한다. 실제 유지증거금 청산 체결은 자료가 없어서 모형화하지 않는다. 따라서 이 자본곡선은 계정 실현 수익이 아니라 보수적 크기 고정 진단이다.

## 개발 선택 및 시험 공개 조건

9개 개발 설정 모두를 같은 규칙으로 평가한다. 우승 설정은 개발 순손익 기대값이 가장 큰 설정이다. 동률이면 거래 수가 많은 설정, 그다음 짧은 W, 그다음 낮은 T 순으로 정한다. 개발 성과가 음수여도 시험 구간은 우승 설정 1개에 한해 열어 재현성 진단을 한다. 다른 8개 설정의 시험값은 산출하지 않는다. 따라서 최종 시험은 격자 선택에 재사용되지 않는다.

시험 구간 보고 항목: 표본 수, 방향 적중률과 Wilson 95% 구간, 거래당 기대값(bp), PF, 1배 복리수익, 종료시점 MDD, 비용 2배 결과, 반기별 손익, 정산시간 회피 수, 입력 파일 SHA-256. 탐색 후보가 되려면 시험 거래 ≥200, 방향 적중률 Wilson 하한 >50%, 순기대값 >0bp, PF>1, 2배 비용 기대값 >0bp를 모두 만족해야 한다. 이는 프로젝트 G 승인 기준이 아니라 단일 XBTUSD 탐색의 사전 고정 내부 필터다. Bonferroni/Reality Check/Deflated Sharpe를 포함한 전체 G 검증을 통과하지 않으면 검증된 전략이라고 부르지 않는다.

## 시도 수와 재현성

사전등록 기준선은 2026-11-26 01:03:21 UTC 장부 확인 시점의 기존 데이터 4,204행이다. 이전 4,195행 관측 이후 추가된 9행은 모두 미국 ETF TRAIN 전용 평가이며, ETF-REGIME-HEDGE-01~03은 FRED 빈티지 출처 부재로 fail-closed, 04~09는 CBOE VIX 종가의 1거래일 지연 조건으로 시험 구간을 열지 않은 기록이다. 현재 Wonyotti 연구 trial ID는 기존 Binance 1시간 시험 1개뿐이고 본 실험 접두사 중복은 없다. 실행 직전 이 기준선을 다시 확인한다. 개발 9개 설정은 각각 독립 trial ID로, OOS 우승 설정은 별도 1개 trial ID로 append-only 기록한다. 예정 분모는 4,204 + 10 = 4,214이다. 기준선이 달라지면 실행을 멈추고 대사한 뒤 이 사전등록을 새 해시로 다시 고정한다. 보고서에 기존 분모·추가 10회·최종 분모 및 preregistration/code/data 해시를 기록한다. 중복 실행은 허용하지 않는다.

재현 실행은 저장소의 `TRADING_DATA_DIR`가 정확히 `/Users/user/CODE/Coin_Trade/trading_data`인 상태에서만 수행한다. 입력 원본은 변경하지 않고 결과·로그는 `TRADING_DATA_DIR/cache/wonyotti_bitmex_2018_2019_v1/` 아래에만 저장한다. 실거래, 서버, 주문 API, 유료 데이터, 다른 저장 경로는 사용하지 않는다.

## 데이터 한계와 중단 조건

현재 BitMEX 공개 가격 보관본은 66개 주간 파일로 확인됐고 끝이 2019-06-03 주다. 이는 코인 전체·다른 종목·장기 G 조건을 충족하지 않는다. 파일 연속성 검사 실패, 원장-시장 시각 정합 실패, 데이터 해시 산출 실패, 저장 경로 사전검사 실패 시 결과를 생성하지 않고 `검증불가`로 종료한다. 기존 Wonyotti 2020–2021 결과는 덮어쓰거나 합산하지 않는다.

사전실행 구조 검증 중 최초 실행은 OHLC 오류와 마지막 주 파일 부분수록 때문에 수익 계산 전에 중단됐다. 데이터 품질 재검사에서 전체 10,968개 시간 중 42개(0.383%)가 OHLC 범위 검증에 실패했다. 이 42개 시각의 봉과 해당 시각을 포함하는 신호 lookback은 모두 제외하고 수를 보고한다. 2019-06-03 파일에는 48개 시간만 있어 종료일을 2019-06-05로 수정했다. 파라미터 결과·TRAIN/OOS 손익은 이 사전등록 수정 전에 열지 않았다.
