# 워뇨띠 공개 체결흐름 1시간 시험 결과

작성일: 2026-11-25 (Asia/Seoul)
판정: **탈락 — 비용 후 기대값 음수, 방향 적중이 50%와 구분되지 않음**

## 시험 정의

사전등록 [`PREREG_WONYOTTI_FLOW_BINANCE_1H_V1.md`](PREREG_WONYOTTI_FLOW_BINANCE_1H_V1.md) 기준으로 aoa 계정의 BitMEX XBTUSD 시간별 체결량을 매수는 양수, 매도는 음수로 더했다. 합계가 양수면 다음 시간 롱, 음수면 숏, 0이면 신호 없음으로 했다. 진입은 다음 정시 Binance USDⓈ-M BTCUSDT 시가, 청산은 그 1시간봉 종가다. 편도 수수료 4bp와 슬리피지 2bp를 적용했고, 보유시간 중 실제 펀딩 정산이 겹치면 그 정산률을 반영했다.

이는 워뇨띠의 실제 매매 규칙이나 계정 수익률을 재현한 것이 아니다. BitMEX의 계정 체결 흐름을 이용해 Binance 선물에서 다음 1시간 방향을 예측하는 교차거래소 시험이다. 1시간 내 체결 순량은 당시 시장가 주문 방향·의도와 같다고 증명되지 않으며, 두 거래소 가격 차이도 모형화하지 않았다.

최종 시험 방향 적중은 332/654건이며 50% 기준 양측 정확검정 p=0.725다. 방향 정보가 우연보다 낫다는 근거가 없다. 최종 시험에서 비용 후 순이익 거래 비율은 43.43%였다. 거래별 수익을 산술 합산한 값은 -60.17%이고, 1배 전액 재투자로 순차 복리 계산한 자산 변화는 -47.46%다. MDD는 거래 종료 시점 자산곡선 기준이며 거래 중 미실현 손실을 포함하지 않는다.

비용을 두 배로 올리면 시험 기대값은 -21.20bp/건, PF 0.579, 복리 손익 -76.06%, MDD 76.85%로 더 나빠졌다. 신호 부호를 뒤집은 사전등록 비교도 적중률 49.24%, 기대값 -14.80bp/건, PF 0.678, 복리 손익 -63.59%로 수익 후보가 아니다.

전체 구간에는 1분봉 1,052,640개와 완전한 1시간봉 17,544개가 있었다. 시간별 체결 흐름 구간 2,242개 중 순체결량 0인 구간은 48개였고, 나머지 2,194개를 평가했다. 펀딩 자료는 24/24개월의 8시간 정산 시간표가 맞았으며 개발 64건·시험 48건의 적용 정산이 기록됐다. 최종 시험은 사전 고정 60/40 분할의 뒤 40%다.

## 별도 BitMEX 가격경로 시험의 제한

원래 계획한 “BitMEX에서 재구성한 신규 포지션 방향 + BitMEX XBTUSD 손절·목표 경로” 시험은 이번 결과로 대체되지 않았다. 공개된 1시간봉 GitHub 저장소에서 로컬에 확인된 주간 파일은 66개, 마지막 주 시작일은 2019-06-03이었다. 2019-06-10과 2021-12-27의 명시 파일 요청은 HTTP 404였다. BitMEX 공개 REST 요청은 HTTP 403이었고 공개 데이터 주소는 BitMEX 종료 안내 페이지로 이동했다. 따라서 2018~2021 전 기간의 동일 거래소 경로를 확보하지 못했다. 이 봉 저장소는 1시간 데이터를 주 단위 JSON으로 저장한다고 설명하지만 전 기간 파일이 현재 제공된다는 뜻은 아니다.
