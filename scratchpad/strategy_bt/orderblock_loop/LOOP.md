## 2단계 선택 규칙 (PREREG v1.0 개정안, 실데이터 실행 전에 A가 PREREG에 정식 반영)
1. **탐색 단계 (train 60%만)**: 파라미터·정의 미세조정 무제한. 시도마다 `TRAIN_TRIALS.csv`에 1줄(또는 배치 단위 카운트 + 격자 정의 해시). 탐색 때 test 구간 데이터를 읽는 코드 경로를 만들지 않는다(함수 인자로 test 기간 접근을 막는다).
2. **동결**: 라운드 끝에 시장군(코인/주식)별로 train 상위 후보를 **최대 3개** 동결(`FROZEN_R<n>.md`에 파라미터·sha256·시각). 동결 이후 수정 금지.
3. **검증 단계 (test 40% 단 1회)**: 동결 후보만 test 채점. Bonferroni/RC/SPA 분모 = 누적 **test에 올린 동결 후보 수**, Deflated Sharpe의 시도 수 = 누적 **train 탐색 시도 전체**. 둘 다 PREREG에 공식으로 명시한다.
4. test에서 떨어진 후보는 같은 정의로 재튜닝해 다시 test에 올리지 않는다(새 정의 = 새 가설 = 새 사전등록).
5. 2026-06-01 이후 데이터는 G 1~7을 모두 통과한 최종 후보에만 1회 연다.
