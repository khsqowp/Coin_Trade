# KRX 공개 조회 화면과 자동 수집 권한 재확인 — 2026-11-24

## 결론

KRX 공개 화면은 조회일을 지정하는 지수 구성종목 조회와 상장폐지 종목 포함 선택, 상장폐지 종목의 일별 OHLCV 화면을 제공한다. 그러나 화면의 입력 항목은 2018·2022 과거 구성·가격의 실제 조회 성공, 전 종목 완전성, 정산가, 자동화된 백테스트 수집 권한을 증명하지 않는다. 현재 약관은 자동화된 무단 수집·복제·배포를 금지하고 정보 복사·전송에 사전 허락을 요구하므로, 승인된 별도 이용권 없이 화면을 자동 추출하는 경로는 실행 가능한 데이터 게이트가 아니다.

## 공식 화면에서 확인한 범위

- KRX 「지수구성종목」 화면은 지수명과 조회일자 입력란, 종목코드·종목명·종가·등락률·상장시가총액 열을 표시한다. 화면 설명은 입력 가능한 과거 범위, 특정 과거일의 실제 응답, 과거 구성원의 전체성 또는 대량 추출을 보증하지 않는다.
- KRX 「상장폐지종목 시세 추이」 화면은 조회기간 입력란과 상장폐지일·폐지사유, 일자별 OHLCV·거래대금·시가총액 열을 표시한다. 화면의 필드 존재만으로 정리매매 전 기간, 모든 상폐 종목, 최종 현금·주식 대가 또는 총수익이 보장되지는 않는다.
- KRX OPEN API 카탈로그는 주식 및 ETF 일별 매매정보의 제공 시작일을 2010-01-04로 표시한다. 2018·2022는 카탈로그가 주장하는 기간 안이지만, API 인증키 신청·서비스 신청 및 약관이 별도로 필요하고 실제 응답 완전성은 검증되지 않았다.

## 현재 약관의 데이터 취급 제한

KRX Data Marketplace 홈페이지 이용약관은 2026-08-29 시행본에서 다음을 명시한다.

- 제10조: 자동화 수단을 이용한 정보의 무단 수집·복제·배포 금지.
- 제12조 제2항: 거래소의 사전 허락 없는 정보 복사·복제·배포·전송·공중송신 금지.
- 제12조의2: 마켓데이터 상품을 구매·이용할 경우 별도 상품 구매·이용약관 준수.

따라서 웹 화면이 공개되고 다운로드 UI가 있다는 사실만으로 연구용 대량 수집, 로컬 장기 보관, 파생 결과 보존을 허용한다고 추정하지 않는다. 사전 허락이나 해당 상품의 명시적 권리가 확인되기 전에는 자동 요청·다운로드를 하지 않는다.

## 게이트 판정 및 다음 증거

| 항목 | 현재 증거 | 판정 |
|---|---|---|
| 2018·2022 일별 주식/ETF 자료의 카탈로그 기간 | OPEN API 설명은 2010-01-04부터라고 표시 | 날짜 범위 가능성만 확인 |
| 과거 시점별 지수 구성원 | 조회일자 입력 UI 존재 | 실제 과거 응답·전체 이력 미확인 |
| 상장폐지 가격 | 상폐 화면에 OHLCV 열 존재 | 종목·기간 완전성 및 최종 정산 미확인 |
| 자동화·로컬 연구 이용권 | 약관은 무단 자동수집·복제를 금지하고 사전 허락 요구 | 승인 전 자동 수집 불가 |
| 한국 주식 G 입력 자격 | 권리, PIT 유니버스, 상폐 결말, 기업행위 대사 미완료 | 미통과 |

후속 단계는 KRX가 제공하는 상품별 계약·이용약관 또는 서면 허락으로 개인 내부 백테스트, 자동 처리, 로컬 보관 기간, 비원자료 결과 보존 범위를 확인하는 것이다. 권리가 확인되면 실제로 허용된 방식으로만 2018·2022 PIT 구성원, OHLCV 연속성, 상폐·합병 대가, ETF 분배·기업행위 표본을 검증한다. 이 모든 조건을 충족하기 전에는 `PREREG_KR_TR_ETF_TREND_V1.md`의 전략을 실행하거나 데이터 게이트를 통과 처리하지 않는다.

## 조사 경계

KRX 공개 페이지와 약관의 텍스트만 열람했다. 로그인, API 키 신청·호출, 화면의 과거 날짜 조회, 다운로드, 자동화, 가격 행 열람, 데이터·장부·사전등록 수정 및 백테스트는 하지 않았다. 보고서는 기존 미확인 상태를 해소하지 않으며 전략 수익 결과를 포함하지 않는다.
