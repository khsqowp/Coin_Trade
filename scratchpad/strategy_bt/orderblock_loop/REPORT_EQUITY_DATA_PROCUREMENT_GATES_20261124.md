# 국장·미장 주식 데이터 조달 게이트 — 2026-11-24

## 결론

한국과 미국 모두 공식/공급자 경로에서 필요한 데이터 종류를 찾았지만, 현재 권리와 전체 비용이 확인된 적격 입력은 없다. 미국은 상폐 포함 일봉 archive의 단독 사용자 가격이 USD 190으로 공개돼 있고, PIT S&P500 구성원 dataset은 FirstRate Data의 별도 Fundamentals 제품에 포함되지만 그 제품의 일회성 가격은 공개 페이지에서 확인되지 않는다. 한국 KRX 공식 데이터 상품은 구매 절차와 상품별 사양 확인 경로가 있으나, 현재 연구에 필요한 가격·범위·보관권은 확인되지 않았다. 결제·계정·API 신청·공급자 연락은 하지 않았다.

## 미국: 가격과 PIT 이력을 나눠야 함

### HistoricalData.net 일봉 가격 archive

- 공급자 설명: 미국 주식·ETF의 일봉 자료는 2003-10-01부터 2026-11-20까지, 상장·상폐 종목을 포함하고 종목별 날짜 범위는 다르다. 원시 OHLCV, split/dividend 조정값, 배당·분할 이벤트 필드를 함께 제공한다고 한다.
- 단독 사용자 archive 가격: USD 190 일회성. 구매 후 2개월 업데이트가 포함되며 자동 갱신은 아니고, 해당 기간 이후 받은 파일은 구매 라이선스 범위 안에서 계속 쓸 수 있다고 FAQ가 설명한다.
- 라이선스: 구매한 범위 내 연구·분석·백테스트 및 결과 출판을 허용한다고 공급자가 안내한다. 원자료 재배포 또는 원자료를 상당 부분 복원할 수 있는 결과물은 제한된다.
- 한계: 각 종목의 정확한 기간을 구매 전 별도 확인해야 한다. 상폐 포함이 전체 상폐 종목 완전성 또는 상폐 최종 현금·주식 대가를 보증하지 않는다. 일부 상폐 ticker는 coverage에서 빠질 수 있고, ticker 변경·재사용 식별자 대사가 필요하다. 이 자료만으로 당시 S&P500·전체 거래소 유니버스가 복원되지 않는다.

### FirstRate Data S&P500 PIT 구성원 dataset

- 공급자 설명: 2000년 1월 이후 날짜별 전체 구성원, 발표일·효력일을 포함한 편입/편출, 종목별 일별 membership status를 제공한다고 설명한다. 데모 조회는 최근 364~365일로 제한된다.
- 라이선스 페이지는 원자료 내부 이용, 저장, 파생 연구·백테스트 결과의 공개를 허용하고 원자료 재배포를 금지한다. 다만 데이터 완전성·정확성에 대한 보증은 제한한다고 명시한다.
- 전체 이력은 US Fundamentals dataset 상품에 들어 있다. 공개 상품 페이지는 “일회성 전체 이력 접근”과 약 USD 60/월 업데이트를 구분하지만, 현재 페이지에서 일회성 구매 가격을 확인하지 못했다. 업데이트 구독은 필수로 보이지 않으나 실제 주문 조건은 미확인이다.
- 이것은 S&P500의 시점별 유니버스다. 미국 전체 종목을 대상으로 한 전략과 동등하지 않다. S&P500 구성 전략으로 새 사전등록을 만들 경우에도 상폐 이후 결과, 실제 가용 OHLC, 기존 G의 2018·2022/비용/지연/미사용 종목/귀무/다중검정 기준은 별도 입증해야 한다.

### 조합 가능성

두 상품을 결합하면 필요한 가격과 PIT 구성의 상당 부분을 충족할 가능성이 있다. 그러나 이는 공급자 설명에 근거한 조달 가설이다. HistoricalData.net 가격만 확인됐고, FirstRate Data의 1회 구매가는 미확정이므로 총비용은 현재 산출할 수 없다. 종목 ID 연결, 개별 상폐 보유 포지션의 청산값, 종목별 2018·2022 가격 연속성도 실제 허용 샘플 또는 구입 후 파일을 대사하기 전에는 미입증이다.

## 한국: KRX 데이터 상품

- KRX OPEN API 서비스 목록은 주식·ETF 일별 매매정보를 2010-01-04부터 제공한다고 설명한다. 서비스 신청·인증키·약관이 필요하고 카탈로그 설명만으로 상폐 정산금·전 PIT 구성·장기 보관 권리를 입증하지 않는다.
- 현재 OPEN API 약관(2025-12-26 시행)은 인증키 제공일부터 이용기간 1년(요청 시 1년 단위 연장 가능), 비상업 목적 이용, 받은 정보의 제3자 제공 금지, 이용계약 종료 후 제공정보 이용 금지를 명시한다. 본 프로젝트의 재현 가능한 장기 로컬 백테스트 캐시에 적용할 지속 사용권을 보장하지 않는다. 따라서 KRX API 경로는 API를 열어 호출할 수 있다는 점과 별개로 이 연구의 영구 보존 입력으로 승인하지 않는다.
- 프로젝트 공통 주식 개발구간은 `PREREG.md`에서 2007-06-05부터 시작하고 60/40 경계를 2018-10-26으로 고정한다. 2010-01-04 시작 API 데이터만으로는 고정 개발기간 첫 약 2.5년이 비므로, 기존 사전등록 실행 입력을 충족하지 못한다. 이 기간을 새로 설정하거나 구간을 옮기려면 별도 사전등록이 필요하다.
- KRX Data Marketplace의 별도 구매 상품에는 주식 및 ETF 일별 매매정보가 표시된다. 구매안내에 상품별 사양·기간·항목·샘플·가격을 확인한 후 신청하고 이용목적 심사를 거쳐 받는 절차가 적혀 있다.
- 상장폐지 종목 시세 화면에는 일별 OHLCV와 상폐일·사유 표시가 있으나, 이 필드가 모든 종목·날짜의 완전성 또는 정리매매·합병 최종 대가를 보장하지 않는다. 홈페이지 약관은 무단 자동수집·복제·배포를 금지하고 사전 허락 없는 복사·전송을 제한한다.
- 현재는 개인 전략 백테스트·로컬 장기보관, 2018/2022 PIT 코호트, 상폐/기업행위 정산을 함께 보장하는 구매상품·계약을 특정하지 못했다. 상품별 조건·견적·샘플을 확인하기 전에는 권한을 추정하지 않는다.

## 구매 후에도 자동 합격이 아닌 이유

사용권과 데이터를 확보해도 G 통과 증거는 별도다. 구매 파일을 cutoff-only immutable snapshot으로 고정하고 manifest·SHA-256·행수·스키마를 보존해야 한다. 2018·2022 연속성, PIT membership, 재사용 ticker 식별, 배당·분할·합병·상폐 정산, 거래정지/정리매매, 시가 체결 가능성, 비용 2배와 1봉 지연을 확인한 뒤 사전등록 TRAIN/OOS, 무작위 진입·순환이동 귀무, SPA/Reality Check/Deflated Sharpe, 미사용 종목군과 포워드 평가를 수행해야 한다. 데이터 구매 그 자체로 전략 후보가 생기지는 않는다.

## 실행 경계 및 필요한 승인

이 조사에서는 웹에 공개된 상품·라이선스 안내만 읽었다. 계정·API 키·결제·주문·공급자 연락·샘플/가격행 다운로드·백테스트·공유 장부/사전등록 수정은 하지 않았다. 데이터 조달을 진행하려면 적어도 미국 HistoricalData.net USD 190 구매와 FirstRate Data PIT dataset의 일회성 가격 확인, 한국 KRX 상품의 샘플·견적·이용권 확인이 필요하다. 사용자가 별도 결제 한도와 조달 범위를 승인하기 전에는 결제를 진행하지 않는다. 공급자 연락도 별도 메시지 발송 권한이 확인되기 전에는 하지 않는다.
