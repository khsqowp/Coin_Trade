# 2026-06-01 이후 KIS 캐시 열람 범위 사고 기록 — 2026-11-24

## 결론

이번 재조사에서 2026-06-01 이후 자료를 포함한 KIS 가격 캐시의 CSV 행을 읽었다. 이는 프로젝트의 봉인 규칙을 위반한 열람이다. 해당 파일과 이번에 계산한 집계는 이번 연구의 가설 선택·성과 평가·사전등록·후보 판단에 사용하지 않는다.

## 실제 수행 범위

- 대상 경로: `/Users/user/CODE/trading_data/market_data/kis-cache/*.csv`
- 실행 목적: 각 파일의 CSV 헤더와 행을 순회해 파일 수, 행 수, 날짜 열의 첫·마지막 값 범위를 요약하려 했다.
- 실제 실행: 접두어가 `KR_` 또는 `US_`인 CSV 184개 전체를 열어 모든 행을 읽었다. 한국 92개 파일과 미국 92개 파일의 행 수 합계 및 전체 파일에서 관측된 날짜 문자열의 최솟값·최댓값을 출력했다. 표본 3개 파일의 헤더도 출력했다.
- 출력된 집계: KR 326,414행, 관측 날짜 범위 2010-05-28~2026-11-17; US 339,303행, 관측 날짜 범위 2010-01-27~2026-11-12. 이 집계는 봉인 구간을 포함한 전체 파일을 읽어 얻었으므로 적격 연구 통계로 취급하지 않는다.
- 원인: 조사 전에 이 경로의 KIS 파일이 과거 고정 컷오프 전용 스냅샷인지 확인하지 않았다. CSV가 최근 날짜까지 포함한다는 점을 확인한 뒤에도 순회를 중단하지 못했다.

## 영향 및 처리

- 이 재조사에서 읽은 KIS 행 값·행수·날짜 범위·파일 목록은 전략 연구 근거로 사용하지 않는다. 기존 사전등록의 입력 해시나 컷오프 증거로도 사용하지 않는다.
- 봉인된 행이 메모리에서 정확히 어떤 값까지 처리됐는지는 추적하지 않았고, 재구성할 수 없다. 따라서 해당 184개 파일 전체를 이번 조사에서 오염된 입력으로 간주한다.
- 파일 내용 변경, 다운로드, API 호출, 사전등록 수정, 시도 장부 변경, 백테스트 실행은 없었다.
- 기존 연구 결과를 사후에 바꾸거나 TEST 성과를 열람하지 않았다. 이 진술은 이번 조사 행위 범위에 한정한다.
- 이후 이 캐시를 이용한 실행은 cutoff-only 스냅샷과 그 사전 고정 manifest/hash가 별도로 준비되고 승인되기 전까지 금지한다. 현재 사전등록을 수정하거나 이 캐시를 다시 검사하지 않는다.

## 다음 조치

1. 기존 오더블록 조사에서 봉인 구간을 읽은 사실을 이 보고서로 남기고, 해당 조사 결과를 승격 근거에서 제외한다.
2. 다른 데이터 경로를 살필 때는 먼저 문서화된 cutoff·manifest만 읽고, 파일 자체는 2026-06-01 이후 행을 포함하지 않는다는 점이 입증되기 전까지 열지 않는다.
3. 사용자가 사전등록된 적법한 cutoff-only 입력을 명시적으로 고정한 뒤에만 해당 입력을 사용한다.
