# 국장·미장 데이터 경로 재확인 — 2026-11-25

## 판정

현재 지정 데이터 루트에는 국장·미장 가격 패널이 확인되지 않았다. 따라서 이번 checkout과 데이터 루트에서 국장·미장 성과 백테스트를 실행할 입력은 아직 없다. 과거 데이터 게이트 보고서의 경로·파일 존재 주장은 현재 상태로 간주하지 않는다.

## 읽기 전용 관측

- `/Users/user/CODE/trading_data/external/equities` 경로는 현재 존재하지 않았다.
- `/Users/user/CODE/trading_data` 최상위에는 `cache`, `external`, `Users` 디렉터리가 있었다. `external` 아래 확인된 시장 하위 경로는 `crypto`뿐이었다.
- `Users/user/CODE/Coin_Trade/trading_data`라는 중첩 경로는 존재했지만, 최대 10단계 파일 검색에서 파일이 나오지 않았다.
- `cache`에는 코인 오더블록 bar/run 자료만 확인됐다. 이 점검은 파일·디렉터리 이름만 사용했고 가격 행은 열지 않았다.
- `/Users/user/CODE/Ochestration` 또는 다른 저장소는 열지 않았다.

## 결론과 재개 조건

국장·미장은 `DATA_BLOCKED`로 유지한다. 이 보고서는 “전 세계에 데이터가 없다”는 주장이 아니라 지정 루트에 승인된 입력이 없다는 현재 관측이다. 사용자가 데이터를 지정 루트에 제공하거나, 현존하는 보유 경로와 사용권·PIT·상폐 정산 적격성을 문서로 확인할 때까지 수익률을 계산하지 않는다. 새 데이터 다운로드·계정/API·구매는 수행하지 않았다.
