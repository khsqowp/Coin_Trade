# VOLREG-R1 TEST 동결 사전등록

상태: **TEST 결과 계산 전 고정**. 이 문서는 아래 TEST 측정값을 계산하거나 출력하기 전에 저장한다. `AGENTS.md` §2의 “test는 한 번만 본다” 규칙에 따라 TEST 성과를 산출하는 실행은 한 번으로 제한한다.

## 1. 가설과 고정 유니버스

가설은 V2에서 고정한 VOLREG-R1 레짐 전환이 TEST 구간에서도 100% SPY 매수보유보다 비용 차감 성과를 높이는지 평가하는 것이다. 파라미터는 `entry=-2.5`, `exit=2.5`로 고정하며 추가 조정·격자 탐색·결과 확인 후 재실행은 금지한다.

- 자산은 SPY 50% / QQQ 50% 위험 바스켓과 SHY 100% 방어 자산으로 고정한다. 시작 상태는 위험 바스켓이다.
- 입력은 V1/V2와 같은 `external/equities/us/yahoo_daily_us_etf.parquet` 및 `external/equities/vix/cboe_index_history.parquet`이며 시작일은 2002-07-30이다.
- 이번 실행은 cutoff를 적용하지 않고 전체 가용 데이터를 읽는다. 지표와 상태 계산은 시작일부터 마지막 가용일까지 연속 수행하여 TRAIN/TEST 경계에서 상태를 초기화하지 않는다. TEST 성과 집계만 날짜가 `2026-06-01`보다 큰 구간으로 분리한다.
- 이 문서를 저장하는 시점까지 2026-06-01 이후 데이터는 전혀 열지 않았다.

## 2. 신호·체결·비용·인과성

- `RV20`은 SPY 조정종가 로그수익률 직전 20개 관측치 표본 표준편차에 `√252 × 100`을 곱한다. 신호는 CBOE VIX 종가에서 RV20을 뺀 값이다.
- 위험 바스켓에서 시작한다. 스프레드가 -2.5 이하이면 다음 세션 조정시가에 SHY로 전환하고, 2.5 이상이면 다음 세션 조정시가에 위험 바스켓으로 복귀한다. 중간에서는 상태를 유지한다.
- 전략과 기준선은 왕복 12bp 비용으로 계산한다. 비용 2배인 24bp 재실행은 TRAIN에서 이미 확인했으며, TEST의 단 한 번 관측을 보전하기 위해 생략한다.
- 다음 세션 시가 체결 시프트 동등성 assert와 미래 가격/VIX 변형 후 prefix-invariance assert를 다시 확인한다. 실패하면 성과를 장부에 쓰지 않는다.

## 3. 사전 고정 TEST 측정과 판정 기준

TEST는 날짜가 `2026-06-01`보다 엄격히 큰 첫 세션부터 마지막 가용일까지다. 전체 연속 곡선을 TEST 시작 시점의 자산을 100으로 리베이스해 아래를 계산한다.

1. 전략과 SPY의 TEST 누적수익률 및 누적 초과수익(전략 − SPY, pp).
2. TEST 리베이스 전략 곡선의 MDD.
3. TEST 경계 이후 실행 타깃이 바뀐 전략 전환 횟수.
4. TEST에 포함된 각 연도/반기별 전략 및 SPY 수익률과 상대성과(pp). TEST가 1년 미만이면 TEST 전체를 단일 버킷으로 집계한다.
5. 다음 세션 시가 체결 시프트 동등성과 미래변형 prefix-invariance 룩어헤드 차단 assert 결과.

사전 고정 통과 기준은 (a) TEST 전체 누적 초과수익이 양수이고, (b) TEST에 포함된 모든 연도/반기 버킷(또는 1년 미만일 때 전체 버킷)에서 전략 상대성과가 0pp 이상인 것이다. 결과를 본 뒤 기준을 바꾸지 않는다.

## 4. 장부와 실행 횟수

실행 직전 `TRAIN_TRIALS.csv`는 헤더를 제외한 **4,269행**임을 `wc -l`과 큰 JSON 필드를 허용한 CSV 파싱으로 재확인했다. 마지막 기존 ID는 `VOLREG-R1-PREREG-V2-25`이며 새 ID `VOLREG-R1-TESTFREEZE-01`은 아직 없다. 실행 전 장부의 Git diff도 비어 있음을 확인했다.

- 실행 전 `N_train`: 4,269
- 계획된 추가 행: 정확히 1
- 실행 후 예상 `N_train`: 4,270
- 장부 기록은 TEST 결과를 계산한 단일 성공 실행에서만 한 행 append한다. 기존 행은 수정하지 않는다.

## 5. 실행 제한

`AGENTS.md` §2 규칙 3의 “test는 한 번만 본다”를 적용한다. 이 문서 저장 시점까지 2026-06-01 이후 자료는 전혀 열지 않았다. TEST 성과가 계산·출력된 이후에는 결과가 불리하거나 코드·판정이 마음에 들지 않아도 파라미터나 코드를 바꾸어 재실행하지 않는다. TEST 데이터를 전혀 읽기 전에 발생한 구문·import 오류만 수정 후 재시도할 수 있다.
