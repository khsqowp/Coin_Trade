# 공개 시장자료 경로 추가 검토 — 2026-11-25

## 목적과 제한

코인·한국·미국 각 시장에서 이전 게이트 감사 뒤 새로 확인된 공개 데이터 경로만 다시 평가했다. 공식/제공자 문서와 공개 메타데이터를 읽었다. 계정 생성, 명시적 약관 동의 버튼 선택, 데이터 다운로드, 유료 API 호출, 로컬 가격행·공유 장부·R12 열람, 테스트, 사전등록 변경은 없었다. HF Data Library 약관은 사이트를 열거나 탐색하는 행위도 약관 동의로 본다고 적으므로, 이 페이지의 공개 약관 조회가 그 문구의 적용 대상인지 법적 판단은 하지 않는다. 제공자의 광고·카탈로그 설명은 해당 제공자의 주장으로 표시하며 실제 파일 완전성 증거와 구분한다.

## 코인 — CDD 일봉 파일과 공개 카탈로그

- CryptoDataDownload는 Binance 현물 OHLCV가 일봉·시봉·분봉으로 제공된다고 설명한다. Binance 자료 페이지는 일봉 파일을 무료 공개한다고 안내하지만, 시간·분봉 자료목록 접근에는 무료 계정 등록 문구를 표시한다. 계정이나 파일은 취득하지 않았다. [Binance 자료 페이지](https://www.cryptodatadownload.com/data/binance/)
- 제공자의 API 문서는 익명 이용을 `No token — catalog browsing only`로 한정한다. 공개 문서의 검색 인덱스에는 Binance Spot 일봉·시봉 1,104개, 분봉 1,102개, 전체 시작일 2017-01-01 같은 집계가 표시되지만, 이 수치만으로 각 심볼의 첫날·마지막날을 대조할 수 없다. [API 카탈로그](https://api.cryptodatadownload.com/)
- API 페이지는 `summary JSON`과 `full JSON (per-symbol detail)`이라는 매니페스트 링크 문구를 노출하지만, 읽을 수 있는 본문은 `Loading manifest…`만 제공하고 실제 링크 대상과 JSON 필드 정의를 표시하지 않는다. 공식 문서 검색에서도 Binance 현물의 심볼별 기간 값을 계산할 수 있는 공개 URL/스키마를 확인하지 못했다. URL을 추측하거나 endpoint를 시험하지 않았다.
- 따라서 심볼별 2018·2022 공통 커버리지, 연속성, 불변 스냅샷·체크섬, 상장폐지 최종 회수는 미입증이다. 제공자의 무료 표시와 카탈로그 날짜 범위만으로 원자료 사용권이나 완전한 고정 코호트를 합격 처리하지 않는다. [무료 자료 안내](https://www.cryptodatadownload.com/data/), [정적 카탈로그](https://api.cryptodatadownload.com/static/catalog/CDD_Data_Catalog.html)
- 앞선 보고서의 로컬 메타데이터 검사도 참고한다. 현재 USDT 무기한 선물 캐시는 세 간격에서 2018년 전체 커버 종목 0개, 2022년 전체 커버 공통 종목 23개였고, 이는 고정 30종목 기준 미달이다. 세 간격 중 59/105개 manifest 행에는 `incomplete=1`이 기록돼 있어 별도 대사 없이는 전체 기간 테스트를 승인할 수 없다. [로컬 자료 범위 보고서](REPORT_LOCAL_DATA_COVERAGE_20261125.md)

## 한국 — KIND 상장폐지 목록과 DART 사건자료

- KIND의 상장폐지현황 화면은 시장·기간별 조회와 Excel 내보내기 버튼을 안내한다. 이는 폐지 종목 목록을 수동 대사할 후보지만, 화면 자체는 전체 과거 시점별 유니버스, 일별 OHLCV 또는 최종 현금·주식 대가를 보장하지 않는다. 내보내기와 보관 권리는 확인하지 않았다. [KIND 상장폐지현황](https://kind.krx.co.kr/investwarn/delcompany.do?method=searchDelCompanyMain)
- KIND의 상장폐지 최종심의 의사록과 KRX 제도 안내는 폐지 사유·절차를 확인하는 보조자료다. 정리매매 가격은 상장폐지 뒤 주주가 받은 최종 현금·주식 대가와 같은 자료가 아니다. [KRX 상장 업무 해설서](https://kind.krx.co.kr/external/dst/reference/10827/%EC%9C%A0%EA%B0%80%EC%A6%9D%EA%B6%8C%EC%8B%9C%EC%9E%A5%20%EA%B3%B5%EC%8B%9C_%EC%83%81%EC%9E%A5%20%EC%97%85%EB%AC%B4%ED%95%B4%EC%84%A4%EC%84%9C.pdf)
- DART 주요사항보고서 활용 화면은 합병·분할·주식교환·부도·영업정지·회생·해산 등 일부 공시 정보를 조회하게 한다. 금융감독원은 제공 정보가 공시 일부이며 정확성·완전성을 보장하지 않는다고 명시한다. 사건별 대가 조사에는 보조가 될 수 있어도 모든 상장폐지의 최종 지급액을 빠짐없이 제공하는 가격 패널은 아니다. [DART 주요사항보고서 활용](https://opendart.fss.or.kr/disclosureinfo/mainMatter/main.do)
- KRX/KIND의 공개 UI 기능을 확인한 것만으로 자료 복제·장기 로컬 보관권이나 자동화 이용권을 추정하지 않는다. 전체 PIT OHLCV와 종료 대가가 함께 검증되지 않아 한국 G는 닫혀 있다.

## 미국 — 공개 초단기 자료와 저가 요금제

- HF Data Library는 IEX 거래에서 만든 미국 주식·ETF 1분 OHLCV 1,253개 종목과 2022-03-07 이후 범위를 표시한다. 그러나 2026-10-10 시행 약관은 자료를 학술·교육 연구 전용으로 제한하고 매매·투자·전략·신호 판단에 쓰지 못한다고 명시한다. 또한 IEX 한 거래소 기록이며 미국 통합 시장자료가 아니고, 종목 범위가 제한적이며 생존편향이 없다고 보장하지 않는다. 이 프로젝트의 전략 검증에는 사용할 수 없다. [자료 설명](https://hfdatalibrary.com/), [이용약관](https://hfdatalibrary.com/pages/terms)
- HF Data Library 변경 기록은 2026-10-06에 과거 가격 파일을 분할만 반영하는 가격 기준으로 재생성하고, 2026년 일부 종목의 누락 세션을 나중에 채웠다고 적는다. 과거 파일과 현재 파일을 혼합할 수 없고, 최신 파일도 별도 품질 대사 없이 불변 완전 패널로 간주하지 않는다. [변경 기록](https://hfdatalibrary.com/pages/changelog)
- HistPrice는 상장·상폐 이력과 시점별 지수 편입을 광고하지만, 요금표에서 무료 등급은 월 1백만 봉·일봉/시봉이고, PIT 편입·상폐 기능 및 대량 파일은 월 USD 49 Quant 등급으로 표시한다. 이 문구는 제공자의 요금·기능 주장일 뿐, 원천·정산가 필드·완전성 방법론을 검증한 증거가 아니다. 유료 접근은 진행하지 않았다. [HistPrice 요금표](https://histprice.com/)
- SEC 공시, Nasdaq 상장·상폐 목록, 거래소 자료는 기업사건이나 시장가격의 일부를 보완할 수 있지만, 이 검토에서 무료 공개 단일 패널로 OHLCV·PIT·상장폐지 최종 대가·연구용 장기 보관권을 동시에 입증하는 경로는 찾지 못했다. 기존 CRSP/WRDS 기관 이용권은 확인되지 않았다.

## 판정

추가 확인된 자료는 일부 필드·사건을 대사하는 조사 후보일 뿐 전체 게이트를 열지 않는다. 현재 후보는 코인 0/2, 한국 0/2, 미국 0/2로 총 0/6이다. 데이터 취득과 실험 대신, 다음 적격 단계는 CDD의 공개 매니페스트 실제 링크/스키마를 허가된 화면으로 확인하는 일과 사용권이 이미 있는 공식·기관 데이터에 한해 기간·PIT·종료 대가를 대사하는 일이다. 전체 게이트가 닫혀 있는 동안 G 기준을 완화하지 않고, R12나 다른 실험·장부 행을 추가하지 않는다.
