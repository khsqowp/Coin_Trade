# VOLREG-R1 V2 — TRAIN 결과

판정: **이번 고정 TRAIN robustness battery는 통과했다.** 승자는 `entry=-2.5, exit=2.5`이며 SPY 매수보유 대비 초과수익은 **+1,369.24pp**다. 이 결과는 TEST를 열지 않은 TRAIN 결과이며 전략 인증이나 실거래 승인으로 해석하지 않는다.

## 실행 범위와 기록 무결성

- 데이터 구간: 2002-07-30~2026-06-01 포함, 공통 ETF 세션 5,998개. cutoff를 먼저 적용하고 읽은 날짜의 최댓값이 cutoff 이하인지 검사했다. `test_rows_accessed=false`.
- 입력·신호·조정시가 체결·비용·자산 바스켓은 V1과 같고 exit 격자만 상향 확장했다. 25셀 모두 처음부터 재계산했다.
- 실행 전 장부는 4,244행, 계획 ID 중복 없음, 장부 diff 비어 있음이었다. 실행 후 4,269행이며 새 ID 25개가 계획 순서로 추가됐다. `git diff --stat`은 **25 insertions(+), 0 deletions(-)**였다.
- Python 실행: 지정된 `python`에서 numpy·pyarrow 임포트 확인 후 실행. runner 종료 코드 0, 상태 `complete`, `rows_appended=25`. pyarrow가 macOS sysctl 캐시 크기 조회를 허용되지 않았다는 진단을 stderr에 출력했으나 계산은 완료됐다.
- 실행 후 `N_train=4,269`, Bonferroni 참고 경계 `0.05/4,269 = 0.000011712344` (약 `1.17e-5`). 무작위 비교의 가능한 최소 p값은 각각 0.004975 및 0.000999여서 이 참고 경계보다 거칠다. 따라서 무작위 백분위 게이트 통과가 Bonferroni 유의성을 입증하지 않는다.

## 승자와 게이트 결과

- 승자: `entry=-2.5, exit=2.5`, **+1,369.24pp**, 전략 누적수익률 +2,580.15%, SPY 누적수익률 +1,210.90%, 전략 MDD -30.47%.
- 위치: entry 5개 중 4번째, exit 5개 중 4번째이므로 **내부 셀**이다.
- 평탄도: 승자의 Moore 8-이웃 중 **8/8개(100%)**가 승자의 초과수익 50% 이상. 기준 70%를 넘어서 **통과**.
- 승자 전환 횟수: **84회**. 5회 미만 신뢰불가 조건에 해당하지 않는다. 이번 결과 때문에 추가 exit 확장은 요구되지 않는다.
- 비용 2배(왕복 24bp): 초과수익 **+1,110.48pp**, 통과.
- 추가 1세션 지연: 초과수익 **+1,714.46pp**, 통과.
- 무작위 전환일 배치: 200회, seed `20261126`, 승자 **100.0백분위**. 귀무 범위 -1,135.07~+560.80pp, 통과.
- 진입·복귀 신호 순환이동: 1,000회, seed `20261127`, 승자 **97.1백분위**. 귀무 범위 -868.02~+16,043.06pp, 통과.
- 2018년: 전략 +6.33%, SPY -4.57%, 상대 +10.89pp, 통과.
- 2022년: 전략 -14.85%, SPY -18.18%, 상대 +3.32pp, 통과.
- 2008년 정보용: 전략 -4.30%, SPY -36.80%, 상대 +32.49pp. 게이트가 아니다.
- 인과성: 25셀 전부 다음 세션 실행 시프트 및 미래 변형 prefix-invariance assert 통과.
- 장부 지표에 기록된 연도별 상대성과 중 양수 기여가 가장 큰 연도는 2008년 +32.49pp이며, 양수 연도 상대성과 합의 29.2%다. 수익이 한 연도에만 집중된 결과는 아니지만 2008년 비중이 가장 크다.
- 전체 고정 TRAIN battery: 모든 지정 게이트 통과. 다만 TEST, Reality Check/SPA/Deflated Sharpe 최종 다중검정, 미사용 종목군 평가 및 전체 G 게이트는 수행하지 않았다. 이를 통과로 간주하지 않는다.

## V1 비교

V1 최고 셀은 `entry=-1.5, exit=1.0`, 초과수익 **+1,249.37pp**였다. V2 승자 +1,369.24pp는 그보다 **+119.87pp 증가**했다. V1 승자는 exit 격자 가장자리였고 V2 승자는 내부 셀이다. 격자 확장 후 최고값은 exit=2.5에서 나타났으며 exit=3.0 셀은 +1,345.50pp로 승자보다 낮다.
