# 공개 S&P 500 시점별 데이터셋 후보 게이트 — 2026-11-24

## 결론

새 공개 경로로 GitHub 저장소 `Johnbrick123/sp500-data`를 확인했다. 제작자는 1996년 이후 S&P 500 편입종목의 일별 가격과 시점별 멤버십을 제공하고, 과거 가격을 여러 출처와 대사했다고 주장한다. 이는 기존 현재 상장종목 중심 Yahoo 패널보다 미국 횡단면 연구에 더 적합할 가능성이 있다. 하지만 원자료 재사용·재배포 권리, 실제 스냅샷의 행 품질·연속성, 기존 러너 스키마 적합성은 입증되지 않았다. 따라서 데이터를 내려받거나 백테스트를 시작하지 않았고, US 데이터 게이트는 계속 닫아 둔다.

## 제작자가 공개한 데이터 설명

- README는 1996년부터 현재까지 모든 S&P 500 편입종목을 일별 가격으로 제공한다고 설명한다. 멤버십은 일별 500–505개이며 전체 약 1,895개 티커 중 1,742개가 한 번 이상 편입됐다고 주장한다.
- 가격 필드는 `date,ticker,open,high,low,close,volume,adj_close,dividends,stock_splits,source`다. 종가·배당 조정값은 Yahoo, Tiingo, WIKI/Nasdaq Data Link, CRSP 등 여러 출처를 섞었다고 명시한다.
- 제작자는 1996년 이후 회원 종목 가격을 여러 제공자·아카이브와 대조하고, 1970–1995는 CRSP 가격을 사용했다고 설명한다. 1970–1995 범위의 CRSP 원자료는 이번 전략이 요구하는 2007년 이후 구간보다 앞서지만, 공개 배포물 전체의 공급원 권리와 파생 데이터 사용권은 별도 문제로 남는다.
- 2019년부터 현재까지 멤버십은 Wikipedia 변경 이력의 과거 버전을 재생해 연장했다고 공개한다. 따라서 2018년 및 2022년 구간은 정확한 과거 파일·구성 기록을 고정한 뒤 S&P 공식 변경 공지와 독립 대사해야 한다.
- 데이터셋은 2026년 11월 3일 immutable release snapshot을 표시하고, 현재 `main` 브랜치는 최신 데이터로 갱신된다. 컷오프 전략 입력으로 쓰려면 2026-05-31 이후 행을 포함하지 않는 별도 고정본과 후행 corporate action이 과거 값을 바꾸지 않는 정규화 절차가 필요하다.
- GitHub 공개 저장소의 루트 파일 목록에는 `LICENSE`가 나타나지 않는다. README의 “공개”·“무료” 표현은 Yahoo, Tiingo, CRSP 등 원공급자의 권리 허가를 대신하지 않는다. Tiingo 공개 약관은 API 데이터의 내부 사용과 별도 재배포 허가를 구분한다.

## 다음에 필요한 증거

1. 공급원별 원자료 라이선스와 작성자의 배포 권한, 내부 연구·로컬 보관 허용 범위가 문서로 확인돼야 한다. 권리가 불분명한 공개 릴리스는 입력으로 사용하지 않는다.
2. 데이터 사용이 허용되는 경우 immutable snapshot의 해시·파일 목록·스키마·행수·기간을 기록하고, cutoff-only 복사본을 만든다. 2026-06-01 이후 시세 행은 읽지 않는다.
3. 2018·2022 각 날짜에 실제 편입 회원 수가 규칙상 500개 내외인지, S&P 공식 announcement/effective date와 일치하는지, 편출·상폐된 종목이 가격과 정산으로 이어지는지 대사한다.
4. ticker 재사용을 회사 식별자로 분리하고, 거래정지·매매불가일 및 `exit_gaps`를 포지션 청산에 반영한다. 단순 직전 종가 대체는 허용하지 않는다.
5. S&P 500 PIT 유니버스를 쓰는 새 US 전략을 검토할 경우, 기존 `PREREG.md`의 테스트 기간·비용·미사용 심볼 기준에 맞는 별도 사전등록과 trial ID를 먼저 고정한다. 공개 데이터셋의 내장 10개월 이동평균 예제 성과는 이 프로젝트의 탐색·검증 결과로 세지 않는다.

## 수행 경계

GitHub 저장소 README, immutable release 안내 및 Tiingo 공식 이용약관만 열람했다. 파일·릴리스 asset을 다운로드하거나 원시 가격행을 조회하지 않았다. 가입·API 키·결제·작성자 연락·백테스트·공유 장부/사전등록 수정은 하지 않았다. 이 보고서는 새 데이터 게이트를 열지 않으며, 검증된 US 후보 수는 늘리지 않는다.
