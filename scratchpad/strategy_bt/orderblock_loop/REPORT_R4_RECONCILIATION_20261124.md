## 재현성·판정 한계

- 장부에 기록된 실행 코드 SHA `74d6301d…`는 현재 작업 트리 SHA `bc643f64…`, 현재 HEAD/index SHA `77a5f663…`와 일치하지 않는다.
- 현재 파일 조합 및 저장소에서 확인 가능한 614개 커밋의 파일 조합으로도 해당 실행 SHA를 재구성하지 못했다. 따라서 정확한 실행 당시 소스 스냅샷은 아직 찾지 못했다. 이 차이를 해소하기 전에는 결과를 현재 코드로 독립 재현했다고 말하지 않는다.
- 모든 수치는 장부에 저장된 TRAIN 진단값이다. 2018년 선물 데이터 게이트, OOS/TEST, 비용 2배, 1봉 지연, 무작위·순환이동 귀무, 다중검정 보정, 최종 미사용 종목군, 레짐별 G 검증은 완료되지 않았다. 이 기록으로 G 통과 후보를 선언할 수 없다.
- 개발 구간에서 72개 모두 M2 목표 80%에 크게 못 미쳤고, PF와 Sharpe도 기준 미달이다. 이는 해당 등록 격자의 TRAIN 선별 결과이며, 다른 전략이나 아직 실행하지 않은 사전등록 가설의 실패를 뜻하지 않는다.

## 다음 조치

1. 실행 SHA `74d6301d…`에 해당하는 실행 시점 코드 스냅샷 또는 변경 이력을 원 소유자 기록에서 확인한다. 불일치 원인을 찾지 못하면 이 72개는 재현 불가 탐색 기록으로 남긴다.
2. R4 격자를 승자로 선언하거나 OOS로 보내지 않는다. M2 80% 실패와 비용 후 PF/기대값·Sharpe 미달을 고정 실패 원인으로 기록한다.
3. 다음 가설은 이미 사전등록된 독립 구조만 선택한다. 실행 전 데이터 cutoff·입력 fingerprint·코드 지문·합성 인과성 테스트·전체 시도 분모를 재검증한다. 2018 데이터 부재를 숨기거나 G를 낮추지 않는다.
