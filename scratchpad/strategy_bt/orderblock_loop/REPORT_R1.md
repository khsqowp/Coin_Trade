# 라운드 1 보고서

- 상태: 사전등록 + 코인/주식 어댑터·훈련 검색기·fail-closed 지표의 독립 레드팀 보완 및 합성 테스트. **시장 데이터 백테스트 0회, 성과 결과 없음. R1 경험 검증은 미완료**.
- cutoff: 2026-05-31까지의 기존 자료만 허용. 이후 자료는 열지 않음.
- 자원 게이트: 이번 확인에서도 `sysctl vm.swapusage`는 `Operation not permitted`로 확인 불가. `memory_pressure`는 free pages 10,745/1,179,648, purgeable 323이며, `/` 여유 90GiB. 마지막으로 확인 가능한 스왑 수치는 4,905.38MB로 3GB 제한 초과였다. 현재 스왑값은 **확인 안 됨**이므로 데이터 실행을 하지 않았다.
- 저장소 변경: 이 폴더에만 코인·주식 어댑터, 포트폴리오/지표 모듈, 합성 테스트 및 사전등록 보완을 추가. 기존 사용자 변경은 보존.

## A — 총괄·통계

- 통과 후보: 0 (판정 전)
- 실행한 시도 N: 0
- 사전등록한 코인 설정: 72
- 사전등록한 미국 설정: 36
- 사전등록한 한국 설정: 36
- 전체 사전등록 설정 N: 144 (각 설정×시장×시간단위×방향 조합)
- Bonferroni 계획 기준: test 제출 동결 후보 누적 `N_test` 분모, train 탐색 누적 `N_train`은 DSR 분모로만 사용. 144는 R1 고정 후보 설정 수이며 통계 분모로 대용하지 않음.
- Reality Check/SPA/Deflated Sharpe: 미실행
- 남은 라운드: 12

- 시간단위: 15m / 1h / 4h
- 방향: 롱 / 숏
- 종목수: 미확인(데이터 미열람)
- 거래수·승률·Wilson 구간·손익비·PF·기대값·연환산 수익·Sharpe·MDD: 미실행
- 비용 2배·지연 1봉·2018/2022·미사용 종목·귀무검정·평탄도·집중도: 미실행
- 판정: 판정 전. 성과 수치 없음.

## C — 국장·미장 주식/ETF

- 가설·격자: 일봉/주봉 오더블록 재시험, 일봉 하락 갭 회귀. 상세 규칙은 `PREREG.md`에 고정
- 비용: 미국 편도 수수료 5bp+슬리피지 5bp; 한국 편도 수수료 1.5bp+슬리피지 5bp+매도세 18bp
- 유니버스: 시점별 구성·상폐 종목 가격 범위는 실행 전 미확인. 완전성 확인 전 평가를 제한하고 한계를 명시
- 분봉: 사용 금지. 일봉·주봉만 허용
- 상폐·포인트인타임 유니버스 한계: 미확인
- 성과 지표와 강건성: 미실행
- 판정: 판정 전. 성과 수치 없음.

## 데이터 적합성·비용 출처 감사 (카탈로그만 확인)

- 코인 카탈로그는 Binance UM 1분봉 35종목(요약 기간 2020-01~2026-11-19), funding 35종목(2020-01~2026-10)을 기록한다. 전체 1분봉은 약 4.33GB parquet이며 현재 15m/1h/4h 봉은 약 20종목이다. 따라서 30종목 조건은 1분봉에서 대상 구간만 종목·월 단위로 변환해야 한다. 실제 2026-05-31 cutoff 내 동시 유효 종목수와 funding 연속성은 아직 검증하지 않았다.
- 코인 4bp/편도 수수료+2bp/편도 슬리피지는 거래소 계정의 공식 요율 확인이 아니라 공통 하네스의 기존 연구 가정이다. 실거래 수수료로 표현하지 않는다. funding은 현금흐름으로 추가해야 하며, 기간 공백은 미판정 처리한다.
- 주식 카탈로그는 미국 Yahoo 일봉이 현재 상장 종목 위주이며 과거 S&P500 구성 이력은 있으나 제거 종목 가격이 빠진다고 명시한다. 한국은 상폐 4,229종목 중 1,190종목에만 가격이 돌아온 기록이다. 따라서 두 주식 시장 모두 생존편향이 남고, 완전한 point-in-time 검증은 확인되지 않았다.
- 주식 비용 가정은 사용자 명세값을 그대로 적용했으며 별도 벤더/브로커 비용 검증은 하지 않았다. US 5+5bp, KR 1.5+5bp 및 매도세 18bp.
- 카탈로그 수치의 기준일은 2026-11-20/21 문서 기록이다. 이 턴에서는 원시 시장 데이터나 2026-06-01 이후 시계열을 열지 않았다.

## D — 적대적 독립 검증

- 사전등록 문서 정적검토: 완료. C2의 원래 손절 조건은 OHLC상 불가능했고, 표본 단위·MDD 기준·다중검정 분모·평탄도 이웃·주봉 완성·ATR 시점이 불충분하다고 지적함. 추가로 bootstrap 블록 길이와 코인 OB 충돌 경계를 지적함.
- A 조치: C2 손절·진입 건너뛰기, 표본·일간 자본곡선·검정·누적 trial accounting·주봉/ATR 시점 정의를 기록. 후속 검토에서 고정자본 누적/임계값 변경/빈 게이트/파산 후 회복/최종 후보 상관·동결 논리를 수정했다. 코인 무효화·활성 OB·funding 순서·setup 가격 일치, 주식 비용·C1 중첩과 청산봉 신호, 수익곡선 계산을 합성 테스트로 보강.
- 독립 재구현·수익률 오차·귀무검정·평탄도·시장 레짐·전략 간 상관: 후보 실행 전이므로 미실행.
- 판정: 사전등록 정적 검토 통과, 경험적 검증은 미실행.

## 합성 코드 검증 기록 (시장 성과 검증 아님)

- `crypto.py`: 세 가지 OB 정의, 단일 활성 OB 필터, 첫 재방문 진입, 48봉 stop/target/time 체결과 funding 현금흐름을 구현했다. funding과 같은 candle-open 체결 순서는 시뮬레이션 가정으로 사전등록했다. 실제 funding 자료 누락 검사는 미구현이다.
- `equities.py`: C1/C2 신호와 결정론적 체결 시뮬레이터, 일봉/주봉 time-exit, 시장별 비용 선택을 구현했다. point-in-time 유니버스 데이터 대조는 미실행이다.
- `portfolio.py`: 고정 초기자본 동일가중 일간 손익 집계. 무포지션은 0으로 명시하고 종목 누락/비유한 PnL은 오류 처리한다.
- `data_access.py`: 기존 구현은 `load_bars`만 제공해 `search_crypto.py`가 요구하는 `iter_train_bars` 계약이 없었다. 이를 종목 스트림·stable shard·train cutoff 전용으로 구현했다. Funding은 사전 cutoff 월 파일만 보고 결제 직전 mark 1분봉 종가를 대용한다. 원시자료 내용의 시장 성과 분석은 아직 실행하지 않았다.
- `metrics.py`: Wilson 95% 하한, 사후비용 거래 통계, 고정자본 산술 누적 MDD/Sharpe, 시장별 고정 core 기준, 필수 robustness 키, 최종 두 개 이상 후보의 독립성·동결 판정을 추가했다. 서로 다른 거래일 달력은 휴장일 0 정렬 Pearson으로 계산한다.
- `equities.py`: 신호·무효화·실패 재방문·만료·right-censored·진입 스킵·미완료 time exit·완료거래 감사 카운터를 호출자 mapping에 기록한다.
- `tests/`, `redteam/tests/`: 합성 테스트 **86개 통과, 2개 건너뜀**. 건너뛴 2개는 공식 Reality Check/SPA 테스트이며 현재 환경에 `arch`가 없어 실행 불가하다. `arch`가 없으면 공식 검정 함수가 예외를 내며 통과를 막는다. 주봉 마지막 신호의 우측 검열, 진입·재방문 시점이 맞춰진 독립 오라클, 동시 청산 집계, R1 주식 격자 36개, 코인 data-access cutoff/lagged-mark 적합성을 합성 입력으로 확인했다. 실시장 신호 우위는 검사하지 않았다.
- 독립 레드팀: 코인 지적의 OB 경계/중첩·시가·비유한 값·시리즈 끝 상태를 반영하고 funding 동일시각 순서를 고정했다. 주식 리뷰가 찾은 청산봉 신호 누락과 만료/우측 검열 구분을 일봉·주봉에서 수정하고 회귀 테스트했다. 통계 리뷰의 고정자본 모순, threshold 완화, 빈 게이트, 파산 후 회복 및 유효하지 않은 상관값을 수정했다.
- 합성 테스트는 코드 경계 동작만 검사한다. 전략 엣지, 실자료 누출 부재, 펀딩 완전성, 상폐 편향, G 통과를 입증하지 않는다.
