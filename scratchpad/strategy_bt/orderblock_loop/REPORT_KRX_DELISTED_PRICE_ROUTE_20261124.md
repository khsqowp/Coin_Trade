# KRX 상장폐지 종목 시세 경로 재점검

조사일: 2026-11-24
범위: 공개 공식 페이지와 이용조건의 존재 확인만. 로그인, 자동수집, 다운로드, 데이터 행 열람, 가격 계산은 하지 않았다.

## 확인된 사실

- KRX Data Marketplace에는 **「상장폐지종목 시세 추이」** 공식 화면이 있다. 화면 설명은 날짜, 종목코드·명, 시장·증권 구분, 종가, 시가·고가·저가, 거래량·거래대금·시가총액, 상장폐지일·폐지사유 항목을 표시한다. 정규시장 시세 기준도 명시한다.
- 별도 종목검색 화면은 상장폐지 종목 포함 조회 항목을 표시한다.
- 이 사실은 해당 자료가 화면에 존재한다는 증거다. 전체 과거기간, 상장폐지 전 마지막 거래가격의 완전성, 상장폐지 후 현금정산 가치, 기업행위 보정, 종목별 이력 누락 여부는 확인되지 않았다.

## 권리·접근 게이트

- KRX Data Marketplace 홈페이지 이용약관은 사이트 정보의 복사·복제·배포·전송·공중송신에 사전 허락을 요구하고, 자동화 수단을 이용한 무단 수집·복제·배포를 금지한다.
- KRX OPEN API의 이용자별 수신방법 안내는 개인투자자의 단순 참고 목적 외 이용(재배포 프로그램 개발, 수익사업 등 기타 목적)에 별도 계약이 필요하다고 적고 있다.
- KRX 데이터 상품 구매 안내는 구매·결제 및 이용 목적 심사 후 다운로드하는 경로를 안내한다.
- 따라서 이 조사만으로 페이지 데이터를 자동 수집하거나 로컬 백테스트용 데이터셋으로 복제·보관해도 된다고 판단할 수 없다. 권리자가 연구·백테스트·로컬 보관 목적을 서면으로 허용하거나 적용 가능한 라이선스가 확인되기 전까지 **전략 테스트 입력으로 사용하지 않는다**.

## 결론과 다음 단계

KRX는 상장폐지 종목의 일별 OHLCV가 있을 가능성을 보여주는 공식 데이터 경로를 제공한다. 이는 데이터 가용성 조사에는 유의미한 진전이지만, 데이터 권리·전체 기간·정산가·포인트인타임 완전성이 미확인이라 국장 생존편향 게이트를 열지 못한다.

다음은 데이터 구매나 계정 생성 없이 KRX에 연구용 과거자료의 이용권한, 상장폐지 종목 전체 조회기간, 다운로드 가능한 필드, 마지막 거래·정리매매/현금정산 가격 포함 여부, ETF와 보통주 범위를 문의하는 것이다. 서면 답변 또는 공개 라이선스 확인 전에는 수집·정규화·백테스트를 시작하지 않는다.
