## 결론

**한국·미국 주식 모두 G 검증 후보는 0개다.** 기존 TRAIN 성과는 생존편향·PIT·상폐 정산 또는 데이터 품질 문제를 안고 있어 시장 전체 성과나 검증된 엣지로 해석할 수 없다. 미장 SPY 매크로 오버레이는 실데이터 백테스트가 0회이며, 단일 ETF라 현재 G의 미사용 종목군 기준을 충족하지 못한다. 데이터 취득·로그인·키 발급·구매는 아직 하지 않았다.

## 3. 사용자 결정 / 조치 항목

1. **KRX:** 계정 로그인으로 상품 상세·견적·샘플 이용 조건을 확인할지 결정한다. 확인할 항목은 개인 비상업 백테스트, 로컬 장기 보관·변환, 자동 수집, 2018/2022 PIT, 상폐 OHLC 및 정리매매·최종 정산, ETF 분배/기업행위다. 로그인 권한만으로 데이터 수집 권리가 생기지는 않는다.
2. **유료 PIT 데이터:** 미국 HistoricalData.net USD 190 archive와 FirstRate Data PIT 구성 dataset의 적격성·총비용을 먼저 비교할지 결정한다. 구매 전 데이터 식별자 연결, 상폐 정산, 종목별 2018/2022 coverage 및 재사용권을 서면/샘플로 확인해야 한다. 이는 구매 권유·비교 제안이며 구매를 실행하지 않았다.
3. **OpenDART 키:** 공시 기반 기업행위 근거가 필요하다고 판단하면 API key 발급 가능 여부와 사용조건을 확인할지 결정한다. 공시 키만으로 가격 데이터 게이트가 열리지 않는다.
4. **기존 KR 품질 문제:** 558개 중 529개를 탈락시킨 1틱 close-high 불일치와 0가격 정지 구간을 어떻게 처리할지 선택해야 한다. 별도 사전등록된 1틱 허용오차를 만들지, 원천 파일을 재생성할지, 현 29개 survivor 결과를 참고용에만 둘지 선택 전 임의 완화는 금지한다.
