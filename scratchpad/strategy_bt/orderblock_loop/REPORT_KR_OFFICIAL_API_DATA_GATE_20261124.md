# 국장 공식 API 과거 시세·이용권 재점검 — 2026-11-24

## 질문과 범위

현재 보유한 한국 일봉·상장폐지 데이터와 별도로, 공개 공식 API가 연구용 로컬 백테스트에 필요한 가격 이력과 이용권을 제공하는지 확인했다. 공식 설명·메타데이터만 읽었다. API 인증키 사용, 가입, endpoint 호출, 데이터 다운로드·행 열람, 가격 계산, 백테스트, 공용 장부 수정은 하지 않았다.

## 공식 자료에서 확인된 사실

1. 공공데이터포털의 금융위원회 「주식시세정보」는 KRX 제공 자료를 연계하고 종목코드·일자 기준으로 시가·고가·저가·종가·거래량 등 시세를 조회한다고 설명한다. 데이터는 매일 갱신되고 기준일 다음 영업일 오후에 제공된다고 안내한다. 그러나 메타데이터에는 전체 역사 조회 시작일, 상장폐지 종목 가격 포함 범위, 마지막 거래·정리매매·현금정산가, 시점별 전종목 유니버스가 명시되어 있지 않다. [금융위원회 주식시세정보 메타데이터](https://www.data.go.kr/catalog/15094808/openapi.json)
2. 같은 API의 현재 표시 이용허락은 **공공누리 제4유형: 출처표시·비상업적 이용·변경금지**다. 설명은 상업적 목적 여부와 무관하게 제3자 무단 제공·재배포를 금지하고, 상업적 활용은 원천 소유자인 KRX에서 구매하도록 안내한다. 이 조건만으로는 개인 연구가 가격 시계열을 변환·정규화해 내부 백테스트 입력으로 저장하는 행위가 허용된다고 확인할 수 없다. 그러므로 명시적 허가나 적용 가능한 라이선스를 확보하기 전에는 사용 적격으로 처리하지 않는다.
3. KRX OPEN API의 수신방법 안내는 개인투자자가 단순 참고 목적을 벗어나 재배포 프로그램 개발·수익사업·기타 목적으로 시세정보를 이용하려면 별도 계약이 필요하다고 명시한다. 시세 분배는 코스콤 이용계약과 KRX 승인 절차를 안내한다. [KRX 데이터 수신방법](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)
4. 금융위원회 「주식발행정보」 API는 상장일·상장폐지일 같은 종목 기본정보를 포함하지만, 이 자료는 상장폐지 가격·OHLC를 제공하지 않는다. 이 API 자체도 공공누리 제2유형과 상업적 이용계약 안내가 붙어 있어, 제3자 데이터와 결합·공유할 권리를 자동으로 부여한다고 볼 수 없다. [금융위원회 주식발행정보](https://www.data.go.kr/data/15043423/openapi.do)

## 현재 보유 자료와의 대조

- 저장소의 `data_sources/EQUITY_SOURCES.md`(2026-11-20 카탈로그)는 현재 KIS 일봉 캐시 184종목과 Naver Finance 기반 현·상폐 일봉 파일을 기록한다. 카탈로그상 상폐종목 4,229개 중 1,190개에서만 가격이 반환됐고, 전체 상폐 가격은 확보되지 않았다.
- 카탈로그에는 KIS 현금시장 일봉의 역사 범위가 기록되어 있지만 현재 종목 위주 캐시이며, 시점별 상장 유니버스와 모든 상폐 종목의 최종 가치까지 포함한다는 증거는 없다. 현재 KRX의 연구·복제 권리도 별도 확인되지 않았다.
- Naver Finance 가격은 KRX 공식 원시 가격 데이터가 아니다. 현재 저장 파일의 출처·완전성·보관 권리는 파일 존재나 FinanceDataReader 사용만으로 입증되지 않는다. 기존 자료는 후보 탐색의 단서일 수 있지만 현 G의 검증입력으로 승격하지 않는다.

## 판정

**국장 공식 가격 데이터 게이트는 계속 닫혀 있다.** 공식 메타데이터는 OHLCV 필드가 있다는 점을 확인해 주지만, 2018·2022 전체 기간, 상장폐지 종목 가격, 최종 정산, 시점별 유니버스와 로컬 연구용 변환·보관 권한을 함께 보증하지 않는다. 한국 주식 G 후보는 0개로 유지한다.

## 다음에 필요한 증거

1. KRX 또는 권리자가 개인 비상업 백테스트를 위한 과거 시세 로컬 보관·변환을 명시적으로 허용하는 문서 또는 적용 가능한 라이선스.
2. API·상품의 과거 조회 시작일, 전종목·상폐 종목 범위, 날짜별 행 완전성, 마지막 거래·정리매매·현금정산 값 포함 여부.
3. 일자별 상장 유니버스·상폐·심볼 변경·기업행위와 가격 패널을 연결한 PIT 매니페스트 및 누락 대사.
4. 2018·2022 연도별 손익, 미사용 종목군 60%, 고정 G의 나머지 비용·다중검정·강건성 기준을 실행할 적격 데이터와 사전등록 검토.

데이터 구매, 계정 생성, 문의 발송, 자동수집은 수행하지 않았다. 이용권과 범위가 문서로 확인되기 전에는 해당 API나 Naver/KIS 캐시를 G 평가용으로 사용하지 않는다.
