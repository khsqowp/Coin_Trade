# KRX 상장폐지 정보와 최종 정산 자료 구분 — 2026-11-24

## 결론

KRX와 금융위원회 자료는 한국 종목의 상장·상폐일, 사유, 일부 일별 OHLCV를 확인하는 공식 경로를 보여주지만, 그 자체로 전 기간 PIT 가격, 상폐 후 최종 현금·주식 대가, 총수익 또는 대량 백테스트 이용권을 입증하지 않는다. 한국 주식 G 데이터 게이트는 미통과다.

## 공식 경로별 구분

- 금융위원회 「주식발행정보」 API 설명은 종목별 발행 기본정보와 상장·상폐 날짜를 제공한다. 이 자료는 일별 OHLCV나 마지막 거래·최종 청산 대가를 대체하지 않는다.
- KRX 「상장폐지종목 현황」은 상장일·상폐일·상폐 사유를 제공하되, 설명이 기준일을 상폐 직전 마지막 매매일로 특정한다. 현금정산·합병대가 전체를 제공한다고 확인되지 않았다.
- KRX 「상장폐지종목 시세 추이」 화면은 종목코드, 날짜, OHLCV, 거래대금, 시가총액과 상장폐지일·사유 필드를 표시한다. 화면의 필드 존재만으로 최대 조회기간, 전 종목의 일별 완전성, 정리매매·최종정산 데이터, 자동 대량수집과 연구 저장권이 입증되지는 않는다.
- KRX OPEN API 목록은 주식 일별 매매정보 범위를 2010-01-04부터라고 설명하지만 계정·서비스 키가 필요하다. 이 목록만으로 과거 시점별 전체 유니버스와 상폐 종목 최종수익, 이용권 조건을 입증하지 않는다.

## 처리·판정

공식 페이지의 공개 설명만 조사했다. 로그인, 키 신청, API 호출, 화면 다운로드, 행 열람, 구매, 데이터 파일 변경, 전략 백테스트, 사전등록·공용 장부 수정은 하지 않았다. 가격·membership의 실제 데이터 커버리지와 보관권은 미확인이다. 현재 한국 전략 후보를 G 통과로 세지 않는다.

## 다음에 필요한 증거

1. 구매 또는 API 키 신청 전 허용된 방식으로 상품별 제공 기간·전 종목/상폐 커버리지·최종 정산 필드·총수익 산식·로컬 연구 보관권을 확인한다.
2. 실제 데이터 취득이 허가된 후에만 상폐 종목 표본을 가격·마지막 거래·정리매매·합병/청산 대가까지 독립 대사한다.
3. 2018·2022 시점별 투자 가능 유니버스와 가격 자료가 함께 완결되기 전에는 별도 전략 실험도 G 후보로 승격하지 않는다.
