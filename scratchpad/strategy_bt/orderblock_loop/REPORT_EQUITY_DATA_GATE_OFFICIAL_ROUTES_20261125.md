# 한국·미국 주식 데이터 게이트 공식 경로 점검 — 2026-11-25

## 판정

한국·미국 모두 **공식 조달 경로 후보는 좁혀졌지만, 전략 연구 데이터 게이트는 닫혀 있다.** 공개 자료는 특정 가격 데이터 범위와 상품 설명을 제공할 뿐, 이 프로젝트의 실제 사용권·저장권, PIT 전체 유니버스, 폐지 종목 최종 회수액 완전성, 2018·2022 전 종목 가격 연속성을 입증하지 않는다. 계정 신청, API 호출, 데이터 다운로드, 구매, 장부 열람, 백테스트는 하지 않았다.

## 한국 주식

- KRX OPEN API 서비스 목록은 유가증권·코스닥 일별 매매정보와 종목 기본정보가 2010-01-04부터 제공된다고 안내한다. 개별 매매정보 문구는 “시장에 상장되어 있는 주권”을 대상으로 한다. 따라서 2018·2022 가격의 조사 경로는 되지만, 당시 전체 구성종목과 상장폐지 종목까지 포함하는 PIT 패널의 증거는 아니다. [KRX 서비스 목록](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd), [유가증권 일별매매정보](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES002_S2.cmd?BO_ID=JvJFzlAENzZlPBDNGAWC), [유가증권 종목기본정보](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES002_S2.cmd?BO_ID=PiwgMdTwmsenXhmqqxuj)
- 금융위원회 주식발행정보는 상장·상장폐지일, 주식 발행내역, 일부 반환일·반환주식수를 제공한다고 설명한다. 문서는 모든 폐지 기업의 최종 현금·주식 회수액을 완전하게 제공한다고 보장하지 않는다. 데이터 포털은 해당 정보에 공공누리 2유형(상업적 이용 금지)을 표시하며, 상업적 활용은 원천 보유자인 한국예탁결제원과 별도 계약이 필요하다고 안내한다. [금융위원회 주식발행정보](https://www.data.go.kr/data/15043423/openapi.do)
- KRX OPEN API 약관은 비상업적 이용을 제한조건으로 두며, 제공 데이터 사용 계약이 만료·해지된 뒤에는 그 데이터를 계속 이용하지 못하도록 한다. KRX의 데이터 수신 안내는 전문 이용자가 코스콤과 이용계약을 체결하는 경로를 제시한다. 이 프로젝트의 장기 보관·변환·반복 백테스트 권리와 비용은 확인되지 않았다. [KRX OPEN API 약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp), [KRX 데이터 수신방법](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)
- 다음 단계는 이미 보유한 적법한 KRX/Koscom/KSD 사용권이 있는지와 연구·개인 저장·가공·반복 실행 범위를 문서로 확인하는 것이다. 권리가 확인되기 전에는 계정·키·API·다운로드를 시작하지 않는다.

## 미국 주식

- CRSP U.S. Stock Databases는 일·월 시장자료와 기업행위, 32,000개가 넘는 active/inactive 미국 증권, permanent PERMNO/PERMCO 식별자 및 survivor-bias-free history를 설명하며, NYSE 자료 시작일을 1925-12-31로 안내한다. 이는 PIT·상장폐지 연구에 가장 강한 문서상 후보지만, 특정 추출물의 결측 없는 2018·2022 자료나 모든 폐지 회수값을 증명하지 않는다. 공개 제품 페이지는 견적 요청만 제공한다. 정확한 구독 상품·가격·계약·로컬 저장권은 확인되지 않았다. [CRSP 제품 범위와 거래소 시작일](https://www.crsp.org/research/crsp-us-stock-databases-2025-layout/)
- WRDS 이용약관은 기관 구독계약과 허가된 이용자를 전제로 하고, 오프플랫폼 다운로드에도 벤더 이용조건을 적용하며, 소속 또는 구독 종료 때 자료 삭제를 안내한다. 현재 사용자의 CRSP/WRDS entitlement와 계약 범위는 확인하지 않았다. [WRDS 이용약관](https://wrds-www.wharton.upenn.edu/users/tou/), [WRDS 데이터 다운로드·분석 정책](https://wrds-www.wharton.upenn.edu/pages/about/data-download-and-analysis-policy/)
- Sharadar Prices(SEP)는 1997-12 이후 active·delisted 미국 주식의 일봉 OHLCV를 제공한다고 설명한다. Corporate Actions 문서는 active·delisted 종목의 티커 변경, 분할·배당·분사, 상장·폐지일과 사유, 인수 상대방 등을 1998년 이후 제공한다고 설명한다. 이는 필요한 필드에 가장 가까운 공개 상품 설명이지만, 실제 완전성·PIT 범위·최종 회수값의 모든 결측 처리까지 보장하지 않는다. [Sharadar 가격 범위](https://sharadar.com/docs/stocks), [기업행위 범위](https://sharadar.com/docs/actions)
- Sharadar 공식 가격 페이지는 Prices 10-year를 월 $19 또는 연 $199, Full History를 월 $39 또는 연 $299로 표시하고, Prices에 `stocks`, `actions`, `sp500` 표가 포함된다고 안내한다. 이 가격은 조사 시점의 공개표시이며 구매 승인이나 실제 권리 확인이 아니다. [Sharadar 구독 가격·포함 표](https://sharadar.com/subscribe)
- Sharadar 개인 사용권은 자연인의 개인적·비전문 목적만 허용하고 전문·기관·상업 연구를 금지한다고 명시한다. 데이터 적합성 평가를 외부 공개하기 전 서면 승인을 요구하는 조항도 있다. 프로젝트의 저장·분석·리포트 범위와 이 약관이 양립하는지 확인되지 않았으므로, 가격이 낮더라도 구매·취득 경로로 간주하지 않는다. [Sharadar 이용약관](https://sharadar.com/terms)
- 다음 단계는 기존 CRSP/WRDS 권리와 정확한 구독계약을 metadata-only로 확인하는 것이다. 보유 계약이 없다면 CRSP 가격 견적 요청, Sharadar 구매 또는 제공자 연락은 사용자 명시 승인 전에 하지 않는다. 계약 확인 후에도 PIT 식별자 효력구간, 폐지 회수값·미결 결측, 2018·2022 거래일별 OHLC 연속성, 저장·보관 권리를 각각 검증해야 한다.

## 출처 확인 범위와 한계

공식 KRX·금융위원회·CRSP·WRDS 및 Sharadar 공개 페이지를 읽기 전용으로 확인했다. CRSP 제품 범위와 WRDS/Sharadar 공개 조건은 공급자 설명이며, 실제 계약·데이터 추출물·코호트 검증을 대신하지 않는다. 2025–2026년의 가격·약관 표시는 추후 변할 수 있으므로 실제 계약 전 재확인이 필요하다.

## 개인 비공개 연구가 해결하는 범위 — 2026-11-25 재확인

외부 공개를 하지 않는다는 사실만으로 데이터 수집·복제·장기 보관 권리가 생기지는 않는다. 다만 KRX OPEN API 약관은 API 이용 목적을 비상업적으로 제한하며 개인도 이용자로 정의한다. 따라서 개인의 비상업적 내부 전략 연구는 목적 조항과 양립할 가능성이 있다. 이용에는 약관 동의와 개인별 인증키 신청이 필요하고, 이용기간은 1년 단위이며 계약이 만료·해지되면 제공 정보를 계속 이용할 수 없고, 제3자 제공도 금지된다. KRX의 시세 수신 안내는 단순 참고 외 목적으로 시세정보를 쓰려는 개인에게 별도 계약이 필요하다고 적는다. 두 공식 문구의 적용 범위가 완전히 같은지는 문서만으로 확정할 수 없다. 그러므로 “비공개이니 무조건 허용”이라고 판정하지 않는다. [KRX OPEN API 약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp), [KRX 시세 수신 안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)

KRX OPEN API는 조사 가능한 다음 경로다. 사용자가 약관을 직접 확인하고 이용 범위와 보존기간을 승인한 뒤 개인 키를 발급받으면, 공개 서비스 목록에 올라온 데이터로 적격성 점검을 시작할 수 있다. 그러나 현재 문서상 서비스 대상은 “시장에 상장되어 있는 주권”의 거래정보이며, 상장폐지 종목까지 포함한 PIT 유니버스나 폐지 후 현금·주식 대가를 제공한다고 확인되지 않았다. 따라서 이 경로는 상장 종목 일봉의 부분 데이터 문제를 풀 수 있어도 현재 G의 전체 상폐·PIT 요건을 풀었다고 볼 수 없다. API는 정확성·완결성도 보증하지 않는다. 키 신청·API 호출·데이터 취득은 하지 않았다.

미국은 개인 비공개 연구만으로 현재 식별된 적격 상품이 무료가 되지 않는다. Sharadar 개인 사용권은 개인적·비전문 목적만 대상으로 하고, 전문 연구·조직/기관 목적은 제외한다. 사용자가 개인으로 사적 학습을 하는 경우에도 이 프로젝트의 전략 연구가 “개인적·비전문적” 범위인지 자동 확정할 수 없다. CRSP/WRDS 또는 다른 기관 라이선스가 이미 있다면 계약상 사용자·저장·반복분석 권리를 확인하는 경로가 우선이다. 공개 무료 표본은 전시장 PIT·상폐 가격·최종 회수액을 함께 보장하지 않는다. [Sharadar 개인 사용권](https://sharadar.com/terms), [CRSP 제품 범위](https://www.crsp.org/research/crsp-us-stock-databases-2025-layout/), [WRDS 이용약관](https://wrds-www.wharton.upenn.edu/users/tou/)

따라서 해결 가능성은 있다. 우선 로컬 보유 경로에서 계약·라이선스 문서와 데이터 파일의 존재를 확인하고, 적격한 자료가 나오면 샘플을 받아도 되는 범위·PIT 유니버스·상폐 종결값·가격 연속성을 대사해야 한다. 이번 경로 이름 검색에서는 `/Users/user/CODE/trading_data` 아래 CRSP, WRDS, Sharadar, KRX, Koscom 또는 delisted 이름을 가진 데이터/디렉터리를 찾지 못했다. 이 파일명 검색은 다른 이름으로 저장된 자료나 계정 권리를 배제하지 않는다. KRX 키 발급·외부 문의·유료 구독·계약 동의는 수행하지 않았다. 그 권한이 명확해져도 데이터 G가 통과하기 전까지 백테스트 후보로 승격하지 않는다.
