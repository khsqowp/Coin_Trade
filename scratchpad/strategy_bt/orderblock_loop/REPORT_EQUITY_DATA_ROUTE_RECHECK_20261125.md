# 국장·미장 주식 데이터 경로 재점검 — 2026-11-25

## 결론

**새 전략 백테스트를 열 수 있는 데이터 경로는 아직 확인되지 않았다.** 국장은 KRX 화면에 상장폐지 종목 OHLC 화면이 존재하지만, 자동수집·로컬 백테스트 이용권과 전체 기간/PIT 완전성이 확인되지 않았다. 미장은 공개 GitHub S&P 500 데이터셋이 구조상 유망하지만 데이터·코드 라이선스와 2026-06-01 이전 고정 사본이 증명되지 않았다. 두 시장 모두 가격 파일을 받거나 열지 않았다.

## 국장 — KRX 공식 화면/API

- KRX Data Marketplace의 “상장폐지종목 시세 추이” 화면은 일자·종목코드·종목명·시장·증권구분·시가·고가·저가·종가·거래량·거래대금·시가총액 필드를 표시하고 조회기간 입력란을 제공한다. 따라서 폐지 종목 OHLC를 조회하는 공식 화면 경로가 존재한다. 화면의 날짜 선택 범위, 결과 상한, 모든 상폐 종목을 일괄 내보낼 수 있는지, 종목별 마지막 실제 체결/정산 처리가 완전한지는 확인하지 않았다. [KRX 상장폐지종목 시세 추이](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT239.jsp)
- KRX Data Marketplace의 현 홈페이지 약관(2026-08-29 시행)은 자동화 수단에 의한 무단 수집·복제·배포를 금지하고, 거래소의 사전 허락 없는 복사·복제·전송·공중송신도 금지한다. 그러므로 화면을 스크레이핑해 대량 백테스트 데이터를 만들지 않는다. [KRX 홈페이지 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd)
- KRX OPEN API 안내는 개인 투자자의 단순 참고 목적을 구분하고, 재배포 프로그램 개발·수익사업 등 기타 목적으로 시세를 쓰려면 별도 계약이 필요하다고 명시한다. 이 연구의 오프라인 과거 데이터 저장·반복 백테스트가 허용되는지는 해당 문구만으로 확정할 수 없으므로 서면 확인 전에는 사용하지 않는다. [KRX OPEN API 데이터 수신방법](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)
- 금융위원회 주식시세정보 API 카탈로그는 KRX 연계 상장 주식 OHLCV를 설명하지만, 이용권은 공공누리 제4유형(상업적 이용 금지·변경 금지·재배포 제한)이라고 명시한다. 상폐 과거 범위와 PIT 유니버스가 설명되지 않아 전략 입력 gate는 닫혀 있다. [공공데이터포털 금융위원회 주식시세정보](https://www.data.go.kr/data/15094808/openapi.do)

**판정:** 자료가 “없다”가 아니라, 공식 조회 화면의 존재만 확인됐다. 과거 범위·전 종목 완전성·상장일/폐지일 시점 유니버스·최종 정산·수정주가 규칙·연구용 보관권이 미확인이다. 따라서 국장 성과 계산은 계속 차단한다.

## 미장 — 공개 S&P 500+ETF GitHub 데이터셋 후보

- `Johnbrick123/sp500-data` README는 일별 OHLCV/기업행위/PIT 구성원 데이터를 주장하며, 현재 릴리스 데이터는 계속 갱신된다. 1970–1995 일부 값은 CRSP 계열, 1996년 이후는 여러 공급원 조합이라고 작성자가 설명한다. 이는 저장소 작성자의 주장이지 독립된 검증 결과가 아니다. [데이터셋 README](https://github.com/Johnbrick123/sp500-data/blob/main/README.md)
- 저장소 공개 Release 목록에서 2026-09, 2026-10, 2026-11 스냅샷이 확인됐다. 이는 2026-06-01 이후 데이터일 수 있어 현재 고정 cutoff 연구에 열지 않는다. 2026-05 또는 그 이전 immutable snapshot의 존재는 이번 확인에서 입증되지 않았다. [GitHub Releases](https://github.com/Johnbrick123/sp500-data/releases)
- 저장소의 `LICENSE` 경로는 404였다. 데이터 설명에 CRSP 기반 구간이 포함되고 현재 데이터를 무료 공개한다고 적혀 있어도, 데이터와 파생물 재사용 권한이 확인된 것은 아니다. 제공된 스크립트가 외부 데이터 공급원에서 재구성하도록 안내하는 부분도 있으므로, 데이터 이용권과 코드 라이선스를 분리 확인해야 한다. [저장소](https://github.com/Johnbrick123/sp500-data)
- 그러므로 이 저장소는 “조사 후보”로만 남기고 가격 파일·GitHub Release asset은 다운로드하거나 쿼리하지 않았다. cutoff-safe release와 명시적 데이터 권리를 확인하기 전에는 미장 전략 파이프라인에 입력하지 않는다.
