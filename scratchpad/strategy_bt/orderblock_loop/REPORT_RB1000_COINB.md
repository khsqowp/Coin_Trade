# RB1000-COINB — 300개 코인 크로스에셋·달력·팩터 TRAIN 결과

## 판정

**최종 후보 0개.** 300개 설정 중 297개는 채점됐고 3개는 거래가 없었다. 고정 다중검정 분모는 4,618이며 Bonferroni 통과 설정은 0개다. 사전등록 보강 검정까지 모두 통과한 설정도 0개다. 아래 일부 설정은 수익·PF가 높지만 모두 기준 미달이며, 동일 TRAIN으로 재선택·재튜닝하지 않는다.

## 배치와 통계

- 이 레인은 8개 계열 300설정을 2026-11-25까지 저장된 COINB 장부 행에서 사후 분석했다. 가격행을 새로 읽거나 백테스트를 다시 실행하지 않았다.
- 장부의 실행 전 데이터 행 수는 3,189, 실제 Bonferroni 분모는 `3,189 + 429 + 1,000 = 4,618`, 설정별 단측 p 임계값은 `0.05/4,618 = 0.0000108272`다.
- 모든 300행은 고유 설정 ID이며 격자 해시는 동일하다. 결과 상태는 `scored` 297개, `no_trades` 3개다. COINB 통과 후보와 Bonferroni 통과는 모두 0개다.
- 장부 실행 지문: grid SHA-256 `a7d1622f539965b55f96b0b5e7b24e178c0e365f7a3b44730e57b34215245adf`; code SHA-256 `b9efc8fc34e9eb10d907b05b8d4650616c8c852a6bef59029bf42d1a8f17bd89`; 상세 prereg SHA-256 `051845c28ee471a4b83f9773ed63d2e83c4da1ccc65e6bf4af13af50a888ab97`; master prereg SHA-256 `7c5ce17430674ac8e30644dde6fdd43894597de32c21ab44dd42793993b913e2`; TRAIN 입력 fingerprint `3c882300819de7fecc0385851d152ae498cba519fc6bc34bd88dfd13d8428992`.
- 이 분모는 COINB 행에 기록된 값이며, 통합 요약 보고서 첫 문장의 `4,918~5,418` 범위와 맞지 않는다. COINB 사전등록 공식 `R+429+1000`, 사전 행수 3,189, 행별 기록 4,618이 서로 일치하므로 COINB 판정에는 행별 4,618을 썼다. 다른 RB1000 레인의 분모는 이 보고서에서 재검증하지 않았다.

## 데이터·방법 제한과 다음 결정

- 입력 코인 유니버스는 고정 35개 현 상장 심볼이다. 세 심볼은 TRAIN 봉이 없어 거래가 없었고, 상폐·이름변경 종목을 포함한 시점별 유니버스가 아니다. 생존편향이 있으며 2018년 고정 G 데이터 요구도 충족하지 않는다.
- 표본은 2020~2023 TRAIN이다. 이 보고서는 2018년 구간, 봉인 OOS/TEST, 고정 보유 연수익 비교를 검증하지 않았다. 2026-06-01 이후 자료도 열지 않았다.
- 보강 검정은 사전등록된 1봉 지연, 비용 2배, 진입일 군집 p, 연도별, 상위 3종목 제외까지다. 무작위 진입, 신호 순환이동, Reality Check/SPA, Deflated Sharpe, plateau 주변 70% 검사, 독립 재구현, forward paper는 이 배치에서 입증되지 않았다.
- 같은 TRAIN에서 최상위 셀을 골라 추가 필터를 덧붙이는 후속 탐색은 이 결과를 새 독립 증거로 만들지 못한다. 이 보고서의 숫자를 사용해 새로운 설정을 고르거나 이미 봉인된 OOS를 열지 않는다. 새 검증은 결과를 보지 않은 별도 자료·기간과 그 범위에 대한 사전등록을 확보한 뒤에만 가능하다.
- 고정 보유보다 안정적인 연수익을 보였다고 주장할 수 있는 전략은 없다. 코인 0/2, 한국 0/2, 미국 0/2, 총 0/6으로 유지한다.
