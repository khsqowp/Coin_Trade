# Binance Spot 오더블록 파일럿 적격성 메모

작성: 2026-11-24 17:22 KST  
범위: 기존 현물 1분봉 카탈로그·manifest 경로 메타데이터, 현재 공식 데이터 약관, 코인 오더블록 사전등록만 확인. 원시 가격 행·2026-06-01 이후 데이터·공유 장부는 열지 않았다.

## 판정

Binance Spot 1분봉은 개인 비상업·비프로덕션 역사 백테스트 약관 범위 안에서 별도 개발 파일럿에 사용할 수 있다. 그러나 기존 USDⓈ-M 주문블록 시험의 데이터 대체가 아니며 2018·2022 G 요건이나 30심볼 최소치를 충족하지 않는다. 파일럿은 R4가 끝나고 장부 writer가 없는 것을 확인한 뒤 별도 사전등록으로만 제안한다. R4 실행 중에는 시작하지 않는다.

## 확인된 입력 범위

`data_sources/CRYPTO_SOURCES.md`는 Spot 1분봉을 2017-08부터 보유한다고 기재하며, Phase 1 인벤토리는 33심볼·2,442개 symbol-month 파일·105.8M rows·2026-11-19까지로 집계한다. 본 점검은 manifest에서 `spot_klines_1m` 경로만 필터하고, 파일 경로의 심볼·월 및 행 수 메타데이터만 사용해 2026-05까지 재집계했다.

| 구간 | 자료가 있는 심볼 | 12개월 모두 파일이 있는 심볼 | 파일 수 |
|---|---:|---:|---:|
| 2018 | 8 | 4: BTCUSDT, ETHUSDT, BNBUSDT, LTCUSDT | 79 |
| 2022 | 25 | 23 | 286 |

현재 cutoff 이전의 manifest symbol-month 수는 2,249개다. 각 심볼에서 첫 파일부터 마지막 파일 사이 월 파일 누락은 0개였다. 월 파일 연속성은 분봉 내부 캔들 연속성, 원본 파일 완전성, 당시 상장 유니버스 또는 상폐 심볼의 포함을 증명하지 않는다. 2018 완전연도 cohort는 4개뿐이므로 기존 최소 30개 문턱과 차이가 크다.

## 약관과 사전등록 적합성

Binance Vision Dataset Terms는 2026-08-26 갱신본에서 순수 개인·비프로덕션 역사 백테스트를 허용 용도로 열거한다. 데이터는 CC BY-NC-SA 4.0 적용, 상업 이용은 제외되며, 파생물을 재배포할 경우 출처 표시와 동일 라이선스 조건을 요구한다. 따라서 **개인 비상업 연구에 한정한 파일럿은 약관상 허용 용도에 해당**한다. 데이터의 실거래 실행·상업 신호·제3자 유료 배포에는 사용할 수 없다. 이미 저장된 각 파일의 다운로드 당시 약관 적용과 파일별 취득 출처는 별도로 확인되지 않았다.

기존 `PREREG.md`의 코인 오더블록 가설은 Binance USDⓈ-M 고정 35심볼과 실제 funding 반영을 전제로 하고, 30개 적격 심볼 및 2018 약세장 검증 요건을 유지한다. Spot은 다른 venue/instrument다. 선물 funding이 없고, 현물 보유만으로 숏 포지션을 재현할 수 없다. 따라서 spot으로 전략 수익률·G를 다시 산정하거나 funding=0으로 치환하는 것은 현재 사전등록 범위에 없다. Spot 파일럿의 결과를 기존 후보 통과나 30심볼 요건의 충족으로 합산하지 않는다.

## 제안하는 다음 실험: 고정 파라미터 구조 전이 진단

1. 시작 전 R4 PID 종료 및 공유 장부 writer 부재를 별도로 확인한다. 현재 상태를 이 메모는 갱신하지 않는다.
2. 새 파일 `PREREG_SPOT_OB_STRUCTURE_PILOT_V1.md`에 본 목적을 결과 확인 전에 등록한다. 고정 입력은 2018년·2022년 12개월 모두 파일이 확인된 BTC/ETH/BNB/LTC 4심볼, 기존 오더블록 정의와 기존 파라미터 1개(최고성과 선택 금지), 기간은 각 연도 TRAIN 진단만이다. 1분봉을 1시간·4시간 OHLCV로 UTC 경계 기준 집계하되 분봉 누락/중복/불완전 월은 보간하지 않고 해당 구간을 제외·계수한다.
3. 목적은 수익성 탐색이 아니라 입력 적격성 및 구조 전이 진단이다. 심볼·연도별 사용 가능 봉 수, 누락 구간, 블록 생성→최초 재방문 funnel, 롱 신호와 숏 신호 발생 수를 기록한다. P&L·파라미터 순위·G 통과 판정은 산출하지 않는다.
4. 2018 cohort 4개로 결과가 일관돼도 30심볼 기준을 바꾸지 않는다. 완전연도 2022 cohort가 23개이므로 2022도 G 충족으로 처리하지 않는다. 이후 별도 perp 확인은 해당 심볼·기간이 실제 겹치는 부분에만 신호 발생 시각의 구조 일치도를 보고한다. spot 결과를 perp 체결·funding의 대용으로 사용하지 않는다.
5. 이 진단이 의미 있는 자료 품질·구조 일치 증거를 주지 못하면 중단한다. 30심볼·상폐/PIT·실제 선물 funding 차단을 해결할 새 자료 경로가 발견되지 않는 한 기존 코인 G는 `DATA_BLOCKED`/`검증불가`로 유지한다.

이 설계는 별도 실험 제안이며 아직 사전등록 작성이나 실행은 하지 않았다. 본 작업에서는 다운로드, API, 코드 변경, 백테스트, 공유 장부 접근을 하지 않았다.
