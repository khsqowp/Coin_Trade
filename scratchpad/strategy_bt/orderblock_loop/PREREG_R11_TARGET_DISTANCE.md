# R11 — 오더블록 목표 거리 축소 사전등록

작성: 2026-11-24  
상태: 결과 열람 전 사전등록. 기존 R11/R12 미등록 스크립트와 별도 실험이며, 해당 스크립트는 사용·수정하지 않는다.

## 가설

R4 오더블록 재방문 진입은 1.5R·2R 목표에서 목표 선도달률(M2)이 낮았다. 진입·손절·수수료·펀딩·보유기간은 바꾸지 않고 목표만 더 가까이 두면 M2가 높아질 수 있다. 너무 가까운 목표는 비용에 잠식되어 기대값과 PF가 악화될 수 있으므로, M2와 비용 후 손익을 함께 측정한다. 이는 새 수익 전략 확정이 아니라 실패 원인을 겨냥한 TRAIN 탐색이다.

## 범위·고정 규칙

- 데이터: 기존 `data_access.iter_train_bars`만 사용, 4시간봉 Binance USDⓈ-M, 동일 기존 R4 TRAIN cutoff `2023-11-06T16:00:00Z`. 새 데이터 다운로드·TEST 열람·2026-06-01 이후 자료 접근 금지.
- 유니버스: R4와 동일한 고정 35심볼 파일·정확한 파일 집합 검사를 적용하고, 실제 봉이 있는 종목 수를 보고한다. R4와 같은 최소 30심볼 미달 시 해당 trial은 `unscorable`이다. 현재 고정 코호트의 PIT/상장폐지 한계는 해소되지 않는다.
- 진입: 기존 R4 `displacement`, `bos_origin`, `volume_displacement` 오더블록 정의, 첫 유효 재방문, 재방문 다음 봉 시가 진입을 그대로 사용한다.
- 방향: 롱·숏 모두.
- 오더블록 유효기간: 신호 후 24·48개 완성봉.
- 손절: 기존 오더블록 distal 경계 바깥 신호 시점 ATR의 0.10배. 변경 금지.
- 목표: 실제 진입가와 기존 고정 손절 간 위험폭 R의 `{0.25, 0.50, 0.75, 1.00}`배. 목표가 먼저 터치해야 M2 성공. 동일 봉에서 목표·손절이 모두 닿으면 손절 우선.
- 보유시간, 다음 봉 시가 체결, 왕복 12bp 기본비용, 펀딩 처리·미판정, 일별 자산곡선은 R4 공통 구현을 그대로 쓴다.
- 총 시도: 정의 3 × 방향 2 × 재방문 기한 2 × 목표 4 = **48개**. 하나라도 실패·미판정이면 장부에 남기며 삭제하지 않는다. 기존 R4 grid의 1.5R·2R 설정은 반복하지 않는다.

## 사전 판정 규칙

- 후보 선별용 TRAIN 통과 문턱은 코인 고정 G의 핵심 하한과 같다: 전체 신호 M2 점추정 ≥80%, 별도 비중복 N≥200, 비용 후 기대값 ≥+15bp, PF≥1.30, 연환산 Sharpe≥1.0, 양(+)의 누적 순수익. Wilson 95% 구간, 승률·손익비, MDD, 연도별 수익, funding 미판정 수, 2배 비용·1봉 지연은 별도 기록한다.
- 이는 개발 TRAIN 선별일 뿐 G 통과가 아니다. R11 설정은 R4와 같은 진입 메커니즘을 공유하므로, 수치가 좋아도 독립 전략 2개로 세지 않는다.
- 2018 파생 데이터/30심볼 코호트 게이트가 닫혀 있고 최종 미사용 TEST·독립 재구현·다중검정 강건성도 수행하지 않았으므로, 이 라운드에서 `VALIDATION_CANDIDATE` 또는 최종 합격 선언은 금지한다.
- 48개 시험을 포함한 실제 누적 장부 행 수를 실행 전에 다시 고정한다. 사전 기준 현재 N=1,606행이었다면 계획상 N=1,654이며, 실행 직전 장부 변화가 있으면 시험 결과를 열기 전에 실제 N으로만 보정 분모를 갱신한다.

## 실패 분석 규칙

- 0개 설정이 TRAIN 선별선을 만족하면 단거리 목표만으로 기존 실패를 구제하지 못한 것으로 기록하고, 같은 신호·진입·목표 격자를 반복하지 않는다.
- M2가 높아져도 기대값/PF/Sharpe가 미달하면 `정확도-경제성 충돌`로 기록한다. 거래 수가 적으면 우수 신호로 포장하지 않는다.
- 고립된 단일 목표 설정만 통과하면 파라미터 spike로 분류하며 OOS 후보로 동결하지 않는다.
- 결과는 `REPORT_R11_TARGET_DISTANCE.md`에 전체 48개, 선별 결과, 기준 미달 이유 상위 3개, 데이터·인과성 한계와 재현 명령을 기록한다.
