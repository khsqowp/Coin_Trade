## 2. 체결·청산·비용 (모든 계열 공통, RB500-US와 동일 규칙)
- 신호는 봉 i 종가 확정 후 발생, **진입 = 봉 i+1 시가**. 같은 봉 체결 금지.
- 롱 전용. 종목(또는 ETF)당 동시 포지션 최대 1개. 보유 중 발생한 신호는 무시하고, 청산 봉 x 이후 신호부터 재진입 가능.
- 같은 봉 다수 심볼: 심볼별 독립 처리(심볼 간 자본 제약 없음, 각 거래를 독립 표본으로 기록). 횡단면 계열은 리밸런싱일 선택 수를 상한까지 채우며 적격 후보가 적으면 있는 만큼만 선택.
- **손절**(stop_atr = k > 0): 손절가 = 진입가 − k×ATR14(신호 봉 i). 보유 봉 j에서 L_j ≤ 손절가이면 청산; O_j ≤ 손절가면 시가 청산(갭), 아니면 손절가 청산. 손절은 규칙·시간 청산보다 우선. 진입가 ≤ 손절가면 신호 무시.
- **규칙 청산**: 봉 j 종가에서 조건 참이면 j+1 시가 청산. **시간 청산**: 보유 H봉째 봉의 종가 청산. 손절·규칙·시간이 같은 봉에서 겹치면 손절 > 규칙(j+1 시가) > 시간.
- 우측 검열: 청산 봉이 데이터 끝 이후이면 집계하지 않고 건수 기록.
- **비용**: 편도 수수료 5bp + 슬리피지 5bp, 왕복 **20bp** (`equities.preregistered_costs("US")`). 순수익률 = 청산가/진입가 − 1 − 0.0020.
- ETF(SPY·섹터) 계열도 동일 비용. 현금 보유 구간은 이자 0.

## 3. 계열 정의 (사전 타당성 순서, 근거 한 줄)

신호 전부 인과적(봉 i 신호는 i 이전 및 i 종가만 사용). 봉 단위 지표: 조정 종가 SMA, ATR14, CLV=(C−L)/(H−L)(H=L이면 신호 없음), 일간 수익률, 52주 고점 비율 ratio52 = C_i / max(H_{i−251..i}), vavg20 = 직전 20봉 평균 거래량.

**L01 섹터 절대모멘텀 로테이션 + 금리 게이트 (27) — 근거: 섹터 모멘텀(Moskowitz & Grinblatt 1999).**
월말 리밸런싱(SPY 달력 월말 봉). 점수 = C_i / C_{i−21·L} − 1, L ∈ {3,6,12}개월. 점수 > 0인 섹터 중 상위 top_k ∈ {1,2,3} 동일 가중(절대 모멘텀 필터). 게이트: none / `t10y2y_pos`(T10Y2Y_i > 0) / `t10y2y_rise3m`(T10Y2Y_i > T10Y2Y_{i−63}). 게이트 실패 시 현금. 보유 21봉 시간 청산. 손절 없음.

**L02 옵션만기 주 시즌성 (24) — 근거: 옵션만기 전후 헤지 수요 변동(Stivers & Sun 2010 계열).**
옵션만기일 O = 해당 월 셋째 금요일(휴일이면 직전 거래일). 진입 = O−pre_days 봉의 시가, pre_days ∈ {1,3,5}. 신호 봉 = 진입 전 봉. 보유 hold_d ∈ {1,2,4,6} 봉 시간 청산. trend ∈ {none, SMA200}: 신호 봉에서 SPY 종가 > SMA200. 손절 없음. SPY 단일 종목.

**L03 저베타(BAB) 월간 N종목 포트폴리오 (16) — 근거: 베타 저평가/레버리지 제약(Frazzini & Pedersen 2014).**
베타_i = Cov(r, r_m)/Var(r_m), 창 beta_window ∈ {126, 252}봉, 전 구간 유효 필수(min_periods=창). r_m은 SPY 일간 수익률을 주식 달력에 정확히 맞춘 값. 리밸런싱 간격 rebal_d ∈ {21, 63}봉마다 베타 하위 bottom_n ∈ {10,20,30,50} 종목 동일 가중. 보유 = rebal_d 시간 청산. 손절 없음.

**L04 Amihud 비유동성 프리미엄 N종목 (16) — 근거: 비유동성 프리미엄(Amihud 2002). 수급 계열 대체 프록시.**
ILLIQ_t = |r_t| / (C_t × V_t), 달러거래대금 0 이하면 결측. 창 window ∈ {63, 252}봉 평균(전 구간 유효). 리밸런싱 rebal_d ∈ {21,63}봉마다 ILLIQ 상위 top_n ∈ {10,20,30,50} 종목 동일 가중, 보유 rebal_d 시간 청산. 시가총액 통제 없음(유동성과 규모 혼재 한계 명시).

**L05 다요인 복합 N종목 월간 포트폴리오 (18) — 근거: 다요인 결합 감소 분산(Fama–French 계열 결합).**
구성요소: 모멘텀 mom = C_{i−21}/C_{i−252} − 1; 52주 근접 ratio52; 저변동 lowvol = −stdev(일간 로그수익률, 63봉, ddof=1). factor_set: `mom_52w` = {mom, ratio52}; `mom_lowvol` = {mom, lowvol}; `mom_52w_lowvol` = {mom, ratio52, lowvol}. 적격 종목(모든 구성요소 유효)에서 구성요소별 횡단면 백분위 순위의 평균을 복합 점수로 하여 상위 top_n ∈ {10,20,30} 선택. 리밸런싱 rebal_d ∈ {21,63}봉, 보유 rebal_d 시간 청산. **RB500-US F01·F02와 구성요소가 일부 겹치므로 중첩 표기(결합 자체가 새 설정).**

**L06 VIX 수준 레짐 오버레이 SPY (14) — 근거: 변동성 타이밍(Moreira & Muir 2017). US-VIX 곡선(미실행)과 변수가 다른 별개 계열.**
mode: `levelX` = VIX_i < X (X ∈ {20,25,30,35}); `pctQ` = VIX_i < 직전 252봉(i−1까지) VIX의 Q 분위수(Q ∈ {0.70, 0.80, 0.90}). 위험선호 상태 = 해당 조건이 confirm_d ∈ {1,3} 연속 봉 참. 상태 진입(꺼짐→켜짐 봉 i)의 다음 시가 매수, 조건 거짓(VIX_i ≥ 임계 또는 결측) 봉 j의 다음 시가 청산. 시간 청산 없음, 손절 없음.

**L07 VIX 급등 후 첫 하락 역추세 SPY (9) — 근거: 공포 정점 후 반등(Whaley 2000 계열). L06과 방향 반대의 역추세 진입.**
신호 봉 i: VIX_i ≥ vix_thr ∈ {25,30,35} **그리고** VIX_i < VIX_{i−1}. 다음 시가 매수, hold_d ∈ {5,10,20}봉 시간 청산. 손절 없음.

**L08 섹터 대비 상대강도 비율 추세 (12) — 근거: 산업 상대강도/추세 추종(상대 비율 신호는 절대 수익률 순위와 다름).**
비율 R_s,i = C_s,i / C_SPY,i. 리밸런싱 간격 rebal_d ∈ {5, 21}봉의 시점 i에서 R_i > SMA_n(R)_i이면 해당 섹터 보유, n ∈ {50,100,200}. spy_trend: none / `spy_sma200`(C_SPY,i > SMA200 일 때만 편입). 편입 섹터 동일 가중, 보유 rebal_d 시간 청산. 손절 없음. 9개 섹터 대상.

**L09 갭 상승 지속 (24) — 근거: 갭 상승 후 장중 매수세 지속(일봉 근사). RB500 F05(갭 하락 반전)의 반대 방향.**
신호 봉 i: 갭 = O_i/C_{i−1} − 1 ≥ gap_pct/100 (∈ {1,2,3}%), CLV_i ≥ clv_min (∈ {0.5,0.8}), C_i > O_i. 다음 시가 매수, hold_d ∈ {3,10}봉 시간 청산, 손절 stop_atr ∈ {2,3}×ATR.

**L10 종가 저점 투매 반전 (16) — 근거: 장 마감 직전 투매 후 단기 반등(일봉 근사). RB500 F03/F04(과매도 반전)와 개념 일부 중첩 표기.**
신호 봉 i: CLV_i ≤ clv_max (∈ {0.1,0.2}) 그리고 수익률 r_i ≤ ret_max_pct/100 (∈ {−1%, −2%}). 다음 시가 매수, hold_d ∈ {2,5}봉, 손절 stop_atr ∈ {2,3}×ATR.

**L11 52주 고점 근접 × 거래량 급증 결합 (16) — 근거: 52주 고점 근접(George & Hwang 2004)과 거래량 확인의 결합. RB500 F06·F07의 단일 계열을 결합한 중첩 변형.**
신호 봉 i: ratio52_i ≥ prox (∈ {0.90,0.95}) 그리고 V_i ≥ vol_mult (∈ {1.5,2}) × vavg20_i. 다음 시가 매수, hold_d ∈ {10,20}봉, 손절 stop_atr ∈ {2,3}×ATR.

**L12 연말·1월 효과 SPY (8) — 근거: 1월 효과(세금 매도 후 반등 가설, 약한 근거).**
각 완전 연도 y(1993~2017, 2018은 컷오프로 불완전하므로 제외)의 마지막 거래일 D_y. 신호 봉 = D_y − entry_before_ye ∈ {2,5}, 진입 = 다음 시가. hold_d ∈ {10,21}봉 시간 청산. trend ∈ {none, SMA200}. 손절 없음. SPY 단일.

## 4. 격자 평탄도·부수 기록 (정보용, 후보 판정에 쓰지 않음)
- 이웃 점검: 같은 계열 내 숫자 파라미터 한 단계 차이 이웃 중 기대값 > 0 비율, 기대값 ≥ 승자의 50% 비율. 문자열 축(mode, curve_gate 등)은 이웃 정의에서 제외.
- 계열별 설정 수, 기대값 양수 수, PF≥1.3 수, Bonferroni 통과 수, 우측 검열·결측 건너뜀·손절가 이하 무시 건수.
- 장부 행 metric에 위 값 전부 기록.

## 5. TRAIN 스크린 합격 규칙 (RB500-US와 동일, 완화 없음)
설정이 **스크린 통과**하려면 전부 충족:
1. 거래 n ≥ 60
2. PF ≥ 1.30
3. 기대값 ≥ 30bp
4. Wilson 95% 승률 하한 > 손익분기 승률 (손익분기 = 평균손실/(평균이익+평균손실))
5. 단측 t검정 p ≤ 0.05/N (N = §0의 분모). 거래 간 독립 가정 위반으로 p는 낙관적 상한임을 명시.

## 6. 보강 검정 (사전 고정, 후보 판정 필수)
스크린 통과 설정만 아래 전부를 계산한다. **하나라도 실패하거나 계산 불가이면 '후보 아님'.** 기준 완화 금지.
- **(a) 1봉 지연**: 신호와 규칙 청산을 모두 1봉 뒤로 민 실행(진입 = 봉 i+2 시가). 5번 기준 전부 충족.
- **(b) 비용×2**: 왕복 40bp로 재계산. 1~5번 기준 전부 충족(기대값 ≥ 30bp 포함).
- **(c) 진입일 군집 보정 p**: 같은 진입 봉 거래를 묶어 날짜별 평균 순수익률의 단측 t검정 p ≤ 0.05(명목).
- **(d) 연도별**: 거래 ≥ 5건인 연도 중 기대값 > 0 연도 비율 ≥ 0.60 그리고 약세 연도 중 거래 ≥ 5건인 연도가 최소 1개 있고 그 약세 연도 합산 기대값 > 0. 약세 연도 = SPY 달력연도 수익률 < 0(1993 첫해는 첫 거래일 기준, 2018은 컷오프까지). 약세 연도 검증 불가이면 실패.
- **(e) 상위 3종목 제외**: 종목별 순수익 합 상위 3개 종목 거래를 제외하고 1~5번 재계산. 단일 자산 계열(L02, L06, L07, L12)은 **계산 불가 → 후보 아님**으로 표기.

후보(candidate) = 스크린 통과 AND (a)(b)(c)(d)(e) 모두 통과. 현재 실행은 TRAIN 전용이며 어떤 결과도 G가 아니다. 후보가 있어도 후속 동결·TEST 절차를 별도로 밟는다.
