# 미국 주식 공식 시세·PIT 데이터 경로 점검 — 2026-11-24

## 질문과 범위

미국 주식 후보가 고정 G의 과거 약세장·상장폐지·미사용 종목군 검증에 필요한 합법적 과거 가격과 시점별 유니버스를, 현재 보유 또는 공개 공식 자료만으로 만들 수 있는지 확인했다. 공개 웹 설명과 저장소 데이터 카탈로그만 읽었다. 로그인, 구독·결제, 자동 수집, 가격 행 다운로드·열람, 백테스트, 장부 수정은 하지 않았다.

## 확인된 공식 자료

1. Nasdaq의 공개 과거 데이터 페이지는 각 주식의 일별 과거 가격·거래량을 최대 10년 제공한다고 설명한다. 이 설명만으로는 상장폐지 종목의 보존 여부, 시장 전체를 빠짐없이 다루는 다운로드 방식, 기업행위 조정 규칙, 대량 로컬 연구 저장 권리를 확인할 수 없다. [Nasdaq Historical Data](https://www.nasdaq.com/market-activity/quotes/historical)
2. Nasdaq Daily List 사양에는 배포 시각(ET), 효력일, 신규·삭제·심볼 변경, 최초 거래일, 상장폐지 사유 같은 필드가 있다. 다만 사양서의 전달 경로는 자료 계약 및 사용자 ID/비밀번호 부여 뒤 제공되는 보안 FTP로 적혀 있다. 이는 목록 필드가 존재한다는 증거이지, 공개 무상 자료나 현재 보유권의 증거가 아니다. [Nasdaq Daily List 사양서](https://www.nasdaqtrader.com/content/technicalSupport/specifications/dataproducts/dlcompletespec.pdf)
3. Nasdaq Data Link의 North American Historical Daily Maintenance(ZHDM)는 1987년부터 미국·캐나다 상장 및 상장폐지 30,000개 이상 기업의 기업행위 정보를 제공한다고 설명하지만 상품은 Premium이다. 이는 시점별 종목 이벤트 보조자료 경로일 뿐, OHLC 가격 자료를 제공한다는 뜻은 아니다. [Nasdaq Data Link ZHDM](https://data.nasdaq.com/databases/ZHDM)
4. SEC의 무인증 API는 제출 이력과 XBRL 재무 공시를 제공한다. 공식 설명에 시장 OHLC 시계열이 포함되어 있지 않으므로, 상장·공시 이벤트 보조자료로는 쓸 수 있어도 가격 자료 대체재로 볼 수 없다. [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)
