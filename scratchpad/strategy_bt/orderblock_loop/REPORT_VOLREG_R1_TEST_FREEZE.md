# VOLREG-R1 TEST 동결 실행 결과

판정: **TEST 동결 실행 통과**. 고정 파라미터 `entry=-2.5, exit=2.5`의 TEST 누적 초과수익은 **+0.9555pp**였고, 1년 미만인 TEST 전체 구간에서 SPY보다 나쁘지 않았다.

## 실행 범위와 결과

- 연속 지표·상태·백테스트 구간은 2002-07-30부터 실제 마지막 가용일 **2026-11-19**까지다. 상태를 TRAIN/TEST 경계에서 초기화하지 않았다.
- TEST는 cutoff 다음 거래일인 **2026-06-02**부터 **2026-11-19**까지다. 총 **120거래 세션**, 달력상 5개월 17일의 구간이다. TEST 구간은 1년 미만이며 2026년 하반기 일부를 포함하므로 사전등록대로 전체를 한 버킷으로 평가했다.
- 왕복 비용은 12bp만 반영했다. TEST 비용 스트레스 24bp 재실행은 TRAIN에서 이미 확인했고 TEST를 한 번만 관측하기 위해 생략했다.

| TEST 측정 | 결과 |
|---|---:|
| 전략 누적수익률 | -4.2486% |
| SPY 누적수익률 | -5.2041% |
| 전략 대 SPY 초과수익 | +0.9555pp |
| 전략 MDD | -10.4632% |
| TEST 경계 이후 전환 횟수 | 3회 |

TEST 전체 단일 버킷의 상대성과는 다음과 같다.

| 구간 | 시작 | 끝 | 전략 수익률 | SPY 수익률 | 상대성과 |
|---|---|---|---:|---:|---:|
| TEST 전체 (2026년 하반기 일부) | 2026-06-02 | 2026-11-19 | -4.2486% | -5.2041% | +0.9555pp |

절대수익은 전략과 SPY 모두 음수지만, 사전등록 기준은 절대수익이 아니라 SPY 대비 상대성과다. 이 구간의 초과수익이 양수이고 유일한 버킷의 상대성과가 0pp 이상이므로 두 TEST 판정 조건을 모두 충족했다.

## 룩어헤드 검사와 기록

- 다음 세션 시가 체결 시프트 동등성: **통과 (`true`)**.
- 미래 변형 prefix-invariance: **통과 (`true`)**. 검사 pivot은 2014-09-23이다.
- TEST 성과 계산 및 장부 기록을 포함한 성공 실행은 지정 Python 실행기에서 **종료 코드 0**, `status=complete`로 정확히 1회 완료했다. 출력 JSON의 `test_rows_accessed`는 `true`다. pyarrow가 macOS sysctl 캐시 크기 조회를 허용되지 않았다는 진단 4건을 stderr에 냈지만, 계산과 장부 append는 완료됐다.
- 실행 전 장부는 4,269행이었고 해당 ID는 없었다. 실행 후 **4,270행**이며 `VOLREG-R1-TESTFREEZE-01` 한 행을 추가했다. 기존 행 수정은 없다.
- 실행 후 `N_train=4,270`; 참고선 `0.05 / 4,270 = 0.000011709602`(약 `1.17e-5`)이다. 이 값은 참고선일 뿐 정식 다중검정 보정이 아니다. Reality Check/SPA/Deflated Sharpe 정식 보정은 현재 인프라가 없어 미시행이다.
- 실행 직후 `git diff --stat`은 `TRAIN_TRIALS.csv | 1 +` 및 `1 file changed, 1 insertion(+)`를 표시했다. 기존 파일 삭제는 0건이다. Git diff는 아직 추적되지 않은 신규 파일을 이 통계에 표시하지 않으므로, 전체 변경 파일은 사전등록, 실행 스크립트, 이 보고서, 장부의 총 4개다.

## 연구 단계

TRAIN V2 고정 robustness battery와 이번 단일 TEST 기준이 모두 통과해 사전등록 체계상 가장 강한 증거 수준에 도달했지만 실거래 투입과는 다르며, 포워드 가상매매 등 추가 검증이 보통 다음 단계다. 정식 다중검정 보정은 미시행이며, TEST의 전략 대 SPY 초과수익은 +0.9555pp이고 TEST 내 전환은 3회뿐이다. 이 결과만으로 확정된 수익 전략 또는 실거래 적합성을 주장하지 않는다.
