## 1. mach7 이평선눌림목 버그 수정 (b)

`app/mach7_indicators.py::add_mach7_ma_pullback` 에서 발견:

1. **미래참조 — 프랙탈**: `_williams_bullish_fractal` 이 봉 `i` 를 `i+1, i+2` 로 판정하고 `i` 에 기록. `i+2` 에야 알 수 있는 신호.
2. **미래참조 — FRACTAL_LOW**: `fractal_lows.bfill()` = backward fill = 미래 프랙탈 저점으로 채움. 손절가가 진입가보다 높아지는 경우 발생 → `risk_amount < 0` → `tp_price < 진입가` → 다음 봉 즉시 손실 청산. **-90% 국장 결과의 직접 원인.**
3. **눌림 미감지**: `ENTRY = 정배열 & (Close > FRACTAL_LOW)` 는 상승추세면 매 봉 참. 실제 '가격이 이평선까지 밀렸다 반등' 을 안 봄. 종목당 267 매매.

### 수정 로직 (전부 과거 정보만)
- 추세: EMA_fast > EMA_mid > EMA_slow 정배열
- 눌림: 최근 `pullback_window` 봉 중 저가가 EMA_fast 이하로 눌린 적 있음
- 방아쇠: 종가 > EMA_fast 이고 종가 > 전봉 고가 (반등 확인봉)
- 손절: 최근 `pullback_window` 스윙 저점 (진입가보다 낮을 때만 진입)
- 청산: 종가 < EMA_exit
- `mach7_backtest_core.simulate`: 봉내 고저로 손절/익절 판정, 무효손절 스킵, 청산 후 쿨다운 3봉, B&H 벤치마크 추가

## 2. 파라미터 스윕 (a, `mach7_ma_pullback_sweep.py`)

`ema_fast × ema_slow × pullback_window × RR × exit_ema` 48조합, 코인.

- **`exit_ema=50` 압승** — 상위권 전부. 추세이탈 빠르게 끊는 게 하락장 유리
- `ema_fast=10` > 20
- `pullback_window=10` 이 평균 알파 최고 (+7~8%)
- RR 1.5가 2.5보다 일관성 높음
- **48조합 전부 median 연환산 -9 ~ -15%.** median 알파는 +10~13% (덜 잃음).

## 3. 전략 구조 실험실 (`mach7_ma_pullback_lab.py`)

파라미터 아닌 *구조* 를 바꿈. 손절방식 × 익절방식 × 레짐필터 × 상대강도 = 72조합, 코인.

- stop: `swing` / `atr`(2.5×ATR) / `pct`(-7%)
- exit: `rr15` / `rr25` / `trail_atr`(고점-3ATR) / `trail_ema`(종가<EMA_fast)
- regime: `none` / `self_sma200`(종가>자체SMA200) / `btc_sma200`(BTC>BTC SMA200)
- rs: `off` / `rs_top`(90일 수익률 유니버스 중앙값 초과)

### 결과: 72조합 전부 median 연환산 마이너스. 최고 -0.36%.

| 레버 | 효과 |
|---|---|
| **레짐필터** (가장 큼) | `none` → 바닥(-9~-28%). `*_sma200` → 상위권. medMDD 45~60% → 26~30% 로 반토막 |
| **상대강도 `rs_top`** | 상위권 대부분 포함 |
| **익절 `trail_ema`** | 추세 끝까지 타는 게 고정 RR보다 나음. `trail_atr` 최악(타이트해서 다 털림) |
| **손절방식** | 영향 최소 |

최고: `swing / trail_ema / btc_sma200 / rs_top` → median 연환산 -0.36%, medMDD 26%, B&H초과 72%, 평균 알파 +22%.

## 결론 (2020~2025 코인 구간)

- 마하세븐 눌림목 계열, **롱온리, 알트 유니버스로는 절대수익 플러스 불가.** 최선이 손익분기 근처 + MDD 통제.
- 원인: (1) 2022~2025 알트 약세장, (2) 종목별 독립 백테스트 산술평균 = 실제 포트폴리오 아님, (3) 롱온리는 하락장에서 구조적으로 못 범.
- **먹히는 레버**: 레짐필터(200MA 위에서만) + 상대강도 필터 + 트레일링 EMA 청산. 손실완화 오버레이로는 유효(알파 +20% 이상).
