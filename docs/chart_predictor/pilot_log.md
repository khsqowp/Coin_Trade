# 라이브 파일럿 로그

## Pilot-001 — BTCUSDT 1m (2026-11-14)

**목적**: 파이프라인 점검. 표본 1건이라 정확도 근거가 아니다.

**조건**
- 앵커: 2026-11-14 00:50:00 KST. 직전 확정 캔들(open 00:49:00)의 close = 68741.4 USDT.
- 입력: 확정 1분봉 240개 스냅샷(`btc_1m_snapshot.json`, 00:50:08 저장). 에이전트는 네트워크 접근 금지, 스냅샷만 읽음.
- 예측 구간: 앵커 +10~20분 (01:00~01:10 KST). 채점은 확정 캔들만 사용.
- 모델: Claude(구독제 서브에이전트), Codex(구독제 에이전트). API 키 미사용.
- 정지 한계: 예측 파일 생성 시각이 00:50:50(Claude), 00:51:07(Codex)로 앵커 이후다. 입력은 앵커 이전 데이터뿐이라 룩어헤드는 없지만, 프로덕션에서는 앵커 시각과 예측 생성 시각을 둘 다 기록해야 한다.

**입력/예측 해시 (SHA-256)**
- `btc_1m_snapshot.json`: `7f8ec257916f5e34b0d01e8d0b5a783a53a403738670257b555fa2aa79c1938a`
- `pred_claude.json`: `69644e8b4653870cc51f5c1a8a7d4320bf3092bef5596126a2fbef7d6a2aa025`
- `pred_codex.json`: `7054f4644517e028884f12f601ce0b0f250b93fab5d2bddb41f88016507475b9`

**예측 (채점 전 기록)**

| 항목 | Claude | Codex |
|---|---|---|
| 방향(+20분) | flat | up |
| 신뢰도 | 0.50 | 0.58 |
| side / 배율 | none / 1x | long / 2x |
| 경로 +5/+10/+15/+20 | 68710 / 68690 / 68720 / 68735 | 68810 / 68875 / 68910 / 68940 |
| 목표 구간 | 68450 ~ 69000 | 68580 ~ 69150 |
| 무효화 | 68800 | 68480 |

**채점 규칙 (결과 보기 전에 고정)**
- 확정 캔들만 사용. +N분 가격 = 앵커 이후 N번째 1분봉의 종가.
- M1 방향: |+20분 가격 − 앵커| ≤ 0.1 × ATR14 이면 flat, 아니면 부호로 up/down.
- M2 목표 구간: +10~+20분 구간의 고저가 목표 구간과 한 번이라도 겹치면 적중(터치 기준).
- M3 경로: +5/+10/+15/+20 예측가와 실제 종가의 평균 절대 오차(USDT, ATR 정규화).
- 롱/숏: 무효화 가격 접촉 여부 + 배율 적용 수익률(수수료 제외).
- 베이스라인: 직전 5분 모멘텀 지속, 항상 flat.
- 채점기: `score.py`(결정적 코드). 01:10:30에 자동 실행.

**결과 (2026-11-14 01:10:30 자동 채점, 확정 캔들만 사용)**

실제: 앵커 68741.4 → +5분 68677.1 / +10분 68873.2 / +15분 68564.9 / +20분 68819.1 (+77.7, ATR14 121.9 기준 flat 한계 ±12.2를 넘어 **up**). +10~20분 구간 고가 68927.9, 저가 68457.8.

| 항목 | Claude (flat, 보류) | Codex (up, 롱 2x) | 모멘텀 베이스라인(up) |
|---|---|---|---|
| M1 방향 적중 | 아니오 | **예** | 예 |
| M2 목표 구간 터치 | 예 | 예 | - |
| M3 경로 MAE | 113.8 USDT (0.93 ATR) | 150.2 USDT (1.23 ATR) | - |
| 무효화 접촉 | (거래 없음) | **예**(저가 68457.8 < 68480) | - |

**해석 (과대 해석 금지)**
- 표본 1건이다. 방향 적중 1/2는 아무것도 증명하지 않는다. 모멘텀 베이스라인도 같은 방향을 맞혔으므로, Codex의 적중은 "베이스라인 대비 이득 없음"이다.
- **파일럿 채점기의 결함**: 롱의 배율 수익률 +0.226%는 손절(무효화)을 무시하고 +20분까지 보유한 값이다. 무효화 가격 68480이 구간 중 닿았으므로 실제 거래라면 손절로 청산됐다. 68480 체결을 가정하면 2x 기준 약 −0.76%(수수료 전)로 **손실**이다. 방향은 맞았지만 거래는 졌다. P2 채점기는 무효화/청산 우선 규칙을 적용해 이 문제를 처리한다.
- Claude의 "예측 보류"는 방향 미적중으로 채점됐지만, 거래 관점에서는 손실을 피했다. 방향 적중률과 손익을 항상 분리해 보고해야 하는 이유다.
- 이 파일럿 결과는 개선 루프의 시험 횟수나 성능 지표에 포함하지 않는다(점검용).
