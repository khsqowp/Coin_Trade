# Strategy Lab

This directory holds preregistered portfolio-strategy studies that compare net performance with a matched Buy-and-Hold baseline. These studies are separate from P5–P9 intraday signal tests and from the chart-prediction M4 accuracy objective. No result in one track satisfies another track's gate.

Each study uses an immutable run directory with `plan.md`, `manifest.json`, `results.json`, `decision.md`, and `handoff.md`. Large inputs and machine-generated row-level outputs remain under ignored `chart_predictor/data/strategy_lab/<run_id>/`; source datasets are never overwritten or committed. Plans precede any performance metric calculation. A run that lacks required data is recorded as blocked at the data gate, with no performance claim.

See [`DATA_ATTRIBUTION.md`](DATA_ATTRIBUTION.md) for required attribution and the non-commercial share-alike notice on Binance Vision-derived research outputs. Raw market archives are not committed.

## Current objective

Find two separate Korea/US stock-and-ETF portfolio strategies that outperform a matched Buy-and-Hold baseline after costs and risk controls, with user-fixed gates of net CAGR >=20%, MDD <=30%, annualized Sharpe >=1.0, and >=200 OOS closed trades per claim. Separately find a crypto USDT-perpetual selective long/short signal with OOS target-first precision >=80% and >=200 non-overlapping OOS events per claim; deadline-close direction accuracy is secondary. The Round 0 charter records the governing figures and open risk/data gates. Existing P5–P9 and MACD-zero/RSI-50 experiments remain immutable prior evidence and are not rerun under new names.
