# BB-01 볼린저밴드 단타 (급등 20~50위 + 거래 활발) 리포트 2026-11-13
결론: 비용 못 이김. 총수익(gross) 거의 0, 비용 0.37~0.40%/왕복. 판정 = hurts(순손실). 가설 수준 스크린, 증명 아님.

## 데이터 (짧음, 생존편향)
- US 5m yfinance: 513종목(S&P500+NDX 일부), 60세션 2026-08-20~11-12. 상장 유지 종목만.
- KR 5m yfinance: 거래대금 상위 299종목, 60세션 08-18~11-13. 현재 상장만.
- KR 틱(NAS archive): 40종목 감시목록, 가격만(거래량 없음), 18세션 10-19~11-11 -> 1m/5m. 20~50위 필터 사실상 무의미(40종목), 거래량 필터 불가 -> 보조 표본.
- 1m yfinance는 7일뿐이라 생략. data/minute 수집기는 prereg 시점 부재 -> 미사용.
- 분할: 워밍업 10세션(US/KR; 틱은 1) 후 앞 70% DEV / 뒤 30% TEST. TEST 1회(TEST_LOCK). prereg.md 18:37 선기록(sha256 일치).

## 규칙 (prereg 고정)
순위=전일종가 대비 %등락 내림차순, 20~50위 AND 누적거래대금>=동시각 20일평균 1.5배. BB(20,k) 5m 종가. 하단 터치 매수(base: 다음봉 시가, opt: 이전밴드 지정가), 상단/중단 터치 매도, 손절 -1/-1.5%, 12봉 시간청산, 장마감 청산, 종목당 1포지션, 동시 5개, 롱만.
격자 k{2,2.5} x 목표{상단,중단} x 손절{1,1.5%} = 셀 8개 x 데이터셋 4개(US,KR,틱5m,틱1m) = 시행 32회 + fill 2종 + 필터 A0/A1/A2. 전부 results.json.
비용: KR 매도세 0.20%+수수료 0.015%x2+슬리피지 0.05/0.10%x2 (~0.37%); US 0.1%x2+SEC+FX0.1%+슬립 0.05%x2 (~0.40%); Prime/2x 병행.

## 주의/버그 이력 (투명 공개)
- 1차 실행: 거래활발 필터 버그(세션/봉 인덱스 혼동)로 A0/A1 거래 0 -> 수정 후 재실행. 결과파일 results_dev_buggy_activity.json 보관.
- 2차: opt(지정가) 변형이 봉 종가 기준 순위를 써서 미래정보 유출(KR opt A0 +0.02%처럼 보였음) -> 직전봉 상태로 수정, 재실행. results_dev_optleak.json 보관. 이 둘은 TEST 보기 전 수정(DEV만 본 상태).
- opt는 지정가 체결 가정이라 낙관적: 최고 KR 중단목표 opt gross +0.13~0.18%여도 net -0.2%.
## 판정: hurts (순손실, gross edge ≈0 = noise). advance 아님. 다음 단계 불필요.
## 결론 보강하려면 필요한 추가 데이터
1) 분봉(1m/5m) 1~2년 + 상장폐지 포함 전종목(생존편향 제거). 2) 실제 호가(스프레드)·체결 데이터로 슬리피지 실측: 0.05%/면 가정이 핵심 변수. 3) 시초 30분 등 시간대별 분리, 시장 국면 구분. 4) 비용이 0.1% 아래로 내려가는 경로(KR ETF/선물, 시장조성)가 없으면 어떤 밴드 단타도 불가: 필요 gross >= 0.4%/건.
