# Addendum A5: price bases, per-symbol execution, and unit assertions
Registered 2026-11-08 KST before any US v3 performance metric is calculated. A5 supersedes ambiguous price-basis and monthly-execution wording in earlier addenda. No market strategy results have been calculated.

## Price bases
Yahoo chart cache open/high/low/close are split-adjusted OHLC; adjclose/close is the dividend-adjustment factor. The existing loader's adjusted OHLC (used by RSI/SMA/residual returns, execution NAV and the SPY benchmark) scales OHLC by adjclose/close, giving a vendor total-return price basis. The overnight gap is a raw price-gap condition and therefore uses raw split-adjusted open(t+1)/raw split-adjusted close(t)-1 so the dividend adjustment factor does not alter the gap threshold. Trend eligibility uses total-return adjusted close>SMA200. Liquidity uses raw split-adjusted close×raw volume. Execution and NAV use the adjusted OHLC basis. Split product consistency is supported only by six spot checks and remains conditional, not exhaustive.

## Per-symbol execution rules
The local v3 monthly target engine stores remaining target deltas per symbol. At each decision close it captures reference NAV and per-name target weight; at the next valid open it executes that symbol's delta once, charging fees on actual notional. A symbol with invalid/missing OHLC or zero volume remains pending; already completed symbols are not re-traded each day while another symbol is blocked. A new monthly target replaces outstanding per-symbol orders. Invalid opens never create stale-close fills. Prior valid close is only used to mark existing holdings until the next valid bar. Buy orders that exceed available cash stay pending; unused slots remain cash. The SPY benchmark uses this engine and pays its actual entry friction.

Gap trading is a position/cash/NAV ledger. At the signal close, buy up to 20 names at 5% of NAV each after observing the opening gap. Exit after one full close-to-close interval at the first valid close. If that close is invalid/missing, defer the exit until the next valid close. Entry and exit costs are recorded on actual fills; missing returns are neither replaced with zero nor treated as fictional exits.

Residual momentum computes per-symbol OLS in daily log-return space on paired stock/SPY rows over trailing 252 sessions, including intercept and slope and requiring at least 200 paired rows. It sums the latest 126 complete residual log returns. Month-end positive signals select at most 20 names, each with a 5% target; remaining budget stays cash. Target orders use the per-symbol engine.

## Output contract and gates
Run all 3 signal families × 3 liquidity universes × 4 per-side cost levels (5/10/20/40bp); report all 9 base-cost cells, every sensitivity, benchmark rows, fills, costs, turnover, exposure, pending end-state orders/positions, available universe counts, IS/reused-OOS/full-period metrics and descriptive fixed regime slices. Daily return and exposure curves are retained. Regime labels do not choose or promote strategies. Primary end date remains the last membership snapshot, 2026-08-18; no stale membership tail is included. This remains conditional exploratory work on a partial PIT S&P 500 sample, not a complete US-market test or strategy promotion.

The final script is us_v3.py. It begins by verifying all hashes in INPUT_HASHES_PRECALC_A5.txt and aborts on mismatch. It runs deterministic synthetic unit assertions for per-symbol deferred fills, no duplicate completed rebalance fills, fee/turnover accounting, RSI open-fill deferral/exit, and gap close-exit deferral. These assertions validate mechanics only; they are not strategy performance results. No v3 market metrics have been run.
