# US point-in-time S&P500: 40주 이동평균(SMA40) 트렌드추종 백테스트

**이 전략은 포트폴리오 단위로는 OOS에서 양(+)의 Sharpe를 내지만, IS·OOS 전 구간에서 SPY 매수&보유와 "적격 유니버스 동일가중" 벤치마크 둘 다에 뒤진다. 종목 단위로 봐도 자기 매수&보유를 이긴 종목은 5곳 중 1곳 수준이다. 다음 단계로 넘길 근거가 없다.**

## 전략 (고정, 변형 없음)

- 신호: 주봉(조정)종가가 40주 단순이동평균(SMA40, 당주 포함 최근 40주 종가 평균)보다 **위**로 마감하면 보유(롱), **아래**로 마감하면 미보유(현금). 숏 없음, 파라미터 튜닝 없음, 단일 가설 1회 검정.
- 체결: 결정 주의 마지막 거래일 종가에서 신호 확정 → 다음 거래일 시가에 체결.

## 유니버스 & 데이터

- `research/us_daily_v2/usbt2.py`의 `load_panel()`을 그대로 재사용 — point-in-time S&P500 멤버십 스펠(`data/us_daily/pit/sp500_ticker_start_end.csv`, `src/tp/fetch_universe.py` 산출물) × Yahoo chart 엔드포인트 조정종가(`tp.usdata`).
- 유니버스 정의(`P.E`, house 기준 그대로): 해당일에 S&P500 멤버십 스펠 안에 있고, 조정종가 데이터가 있고, 관측 거래일 ≥260일. 데이터가 있는 심볼 678개 중 이 조건을 한 번이라도 만족한 **617개** 종목이 개별 종목 백테스트 대상.
- **알려진 한계(PREREG에 이미 명시, 그대로 disclose)**: 상장폐지·인수합병으로 제외된 종목 중 Yahoo가 더 이상 서빙하지 않는 경우는 유니버스에서 빠진다(생존편향 방향: 낙관적). 티커 재사용/리네이밍 관련 알려진 왜곡도 동일하게 남아있다. 이 한계를 보정하지 않고 그대로 사용했다.
- IS/OOS: `coverage.json`에 이미 계산된 `is_start`(2008-01-02)를 재사용. IS = 2008-01-02~2016-12-30, OOS = 2017-01-03~2026-11-02(최신 거래일).
- 비용모델(하우스 그대로, `usbt2.BASE_COST`): 편도 10bp(수수료+슬리피지 합산). 민감도로 20bp/40bp도 돌렸다.

(평균 종목당 진입 횟수 FULL 25.5회, 보유 비중 시간 FULL 59.8%. "승률"은 보유 중인 날의 일간 수익이 양(+)이었던 비율이며, 라운드트립 승률이 아니다.)

- 종목 단위 평균 초과수익이 극단적으로 음수인 것(FULL -247%p)은 소수의 메가캡 성장주(예: 장기 우상향한 몇몇 대형 기술주)가 매수&보유로 수백~수천%를 벌어들인 반면, 트렌드추종은 휩쏘로 일부 상승분을 놓쳤기 때문 — 평균이 왜곡되므로 중앙값(FULL -97%p)과 "이긴 종목 수"가 더 대표성 있는 지표다.
- 자기 매수&보유를 이긴 종목은 IS 19.8%, OOS 19.4%, FULL 23.2% — 세 구간 모두 5곳 중 1곳 수준으로, 명백한 열위.

## 2) 포트폴리오 성과 (동일비중, 적격 유니버스)

매주 "현재 신호가 롱인 모든 적격 종목"에 동일가중을 배분하고 매주 재조정하는 포트폴리오(`usbt2.sim_targets` 재사용, 10bp 비용)를 SPY 매수&보유, 그리고 "적격 유니버스 전체를 매주 동일가중 재조정"하는 정적 벤치마크와 비교했다.

| 포트폴리오 | 구간 | Sharpe | CAGR | MDD | 연간 비용 드래그 | 연환산 회전율 |
|---|---|---|---|---|---|---|
| **MA40 전략** | IS | 0.210 | +2.2% | 66.2% | 1.45%/년 | 14.5x |
| | OOS | **0.645** | +9.6% | 33.8% | 1.21%/년 | 12.1x |
| | FULL | 0.413 | +6.0% | 66.2% | 1.33%/년 | 13.3x |
| SPY 매수&보유 | IS | 0.427 | +7.1% | 52.3% | — | — |
| | OOS | **0.861** | +14.9% | 33.7% | | |
| | FULL | **0.633** | +11.1% | 52.3% | | |
| 적격 유니버스 동일가중(정적, 참고용) | IS | **0.557** | +11.1% | 55.6% | 0.15%/년 | 1.5x |

| | FULL | 0.636 | +12.0% | 55.6% | 0.15%/년 | 1.5x |

**민감도(OOS)**: 편도 비용 20bp → Sharpe 0.570(Δ-0.075), 40bp → Sharpe 0.420(Δ-0.225). 비용을 올릴수록 더 나빠지지만, 10bp 기준 결과(벤치마크에 열위)의 방향 자체는 바뀌지 않는다.

**해석**: MA40 포트폴리오는 OOS에서 절대적으로는 양(+)의 Sharpe(0.645)를 내고 IS(0.210)보다 개선되지만, 같은 OOS 구간 SPY 매수&보유(0.861)와 적격 유니버스 동일가중 정적 벤치마크(0.740) 모두에 못 미친다. IS에서는 격차가 더 크다(0.210 vs 0.427 vs 0.557). 연환산 회전율은 12~15배로, KR과 달리 비용 드래그(연 1.2~1.5%) 자체가 결과를 지배하는 수준은 아니다 — 즉 이 전략이 못하는 이유는 회전율 비용이 아니라 신호 자체가 벤치마크 대비 우위가 없기 때문이다.

## 결론

- **종목별**: 자기 매수&보유를 이긴 종목이 IS·OOS·FULL 모두 19~23%에 불과 — 명백한 열위. (트렌드추종이 소수의 장기 우상향 메가캡 승자에게 특히 불리하다는, 문헌에서도 흔히 보이는 패턴과 일치.)
- **포트폴리오**: OOS Sharpe는 절대적으로 양수(0.645)이지만 SPY 매수&보유(0.861), 적격 유니버스 동일가중(0.740) 둘 다에 뒤진다. IS에서도 동일한 순위.
- **민감도**: 비용을 올리면 더 나빠질 뿐, 기본 비용(10bp)에서도 이미 벤치마크 열위이므로 비용 가정이 결론을 바꾸지 않는다.
- 다음 단계(실거래/페이퍼 트래킹)로 넘길 근거 없음. 추가 변형(파라미터 서치) 없이, 요청된 단일 가설 그대로 기각.
