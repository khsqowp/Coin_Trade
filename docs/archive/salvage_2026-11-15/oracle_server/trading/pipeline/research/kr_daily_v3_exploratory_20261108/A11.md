# Addendum A11: trade-only price marks and jump QC

Created 2026-11-08 before the A11 rerun. The source daily panel has rows with zero volume and stale or corporate-action-adjusted close quotes. The prior panel forward-filled every finite close, allowing such rows to update indicators and marked NAV even though no trade occurred. The prior jump QC also counted those rows as price changes.

A11 changes only data treatment and diagnostics:
- The panel forward-fills the last close from rows with positive traded volume only. Simulator open and close marks update only on positive-volume rows; otherwise they carry the prior mark.
- Instrument last-trade date and early-ending status use positive-volume rows, so halted names remain unresolved rather than looking current.
- Raw and repaired jump diagnostics compare consecutive positive-volume closes; calendar gaps over seven days remain excluded from daily-limit jump counts.
- Last-observed instrument date and early-ending status use the last positive-volume trade, so halted names remain unresolved rather than looking current.
- Invalid OHLC checks remain over all source rows.
- No source parquet, universe, signal threshold, portfolio sizing, execution, fee, or cost schedule is changed.
- RSI price exits require a positive-volume current bar; age-based exits continue using the registered maximum holding period.
- Because signals and marks can change where source rows have zero volume, A11 output replaces A10 as the current exploratory series; A10 remains archived unchanged.

This is a post-run data-quality correction discovered after examining A10 output. A11 remains exploratory, and its historical OOS period is reused. A winner is not promoted.
