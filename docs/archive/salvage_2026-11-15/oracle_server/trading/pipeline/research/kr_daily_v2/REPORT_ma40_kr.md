# KR 전종목: 40주 이동평균(SMA40) 트렌드추종 백테스트

**승패가 뚜렷하다: 이 전략은 코스트를 반영한 KR 전체 유니버스에서 KODEX 200 매수&보유 대비 IS·OOS 양쪽 모두에서 명백히 열위이며, 다음 단계로 넘길 근거가 없다.**

## 전략 (고정, 변형 없음)

- 신호: 주봉 종가가 40주 단순이동평균(SMA40, 당주 포함 최근 40주 종가 평균)보다 **위**로 마감하면 보유(롱), **아래**로 마감하면 미보유(현금). 숏 없음, 파라미터 튜닝 없음, 단일 가설 1회 검정(멀티플테스팅 보정 불필요).
- 체결: 결정 주의 마지막 거래일 종가에서 신호 확정 → 다음 거래일(다음 주 첫 거래일) 시가에 체결. 신호가 바뀌지 않으면 다음 결정 시점까지 포지션 유지.

## 유니버스 & 데이터

- `research/kr_daily_v2/bt2.py`의 `load_panel()`을 그대로 재사용 — KOSPI+KOSDAQ 상장폐지 종목 포함 point-in-time 패널(기업행위 보정 `repair()` 포함, KIS 일봉, 종가 조정).
- "전종목"의 하우스 정의 = `P.elig` (point-in-time 거래 가능 유니버스): 최소 252거래일 이력, 당일 거래(volume>0), 최근 60거래일 중 55일 이상 거래, 60거래일 median 거래금액 ≥ 10억원. 전체 패널에 데이터가 있는 종목 2,236개 중 이 기준을 한 번이라도 만족한 종목 **1,826개**(상장폐지 종목 포함, 생존편향 없음)가 개별 종목 백테스트 대상.
- IS/OOS 분리는 `PREREG_kr_daily_v2.md`를 그대로 재사용: IS = 2012-06-01~2019-12-31, OOS = 2020-01-01~2026-11-03.
- 비용모델(PREREG 그대로): 매수/매도 수수료 0.015%(편도), 매도세 0.20%(사용자 지정 범위 0.18~0.20% 내 상단), 60일 median 거래금액 기준 구간별 슬리피지(≥500억 0.05% / 100~500억 0.10% / 10~100억 0.25% / <10억 0.50%, 편도). 체결 불가(정지·상하한 고정)일 매수는 5거래일 후 취소, 매도는 계속 재시도 — bt2.py의 기존 체결 엔진(`bt2.simulate`)을 그대로 사용했다.

## 1) 종목별(개별 종목) 성과 — 유니버스 평균/중앙값

같은 비용모델로 종목별로 독립적으로(교차단면 랭킹 없이) 롱/현금 전략을 시뮬레이션하고, 그 종목 자신의 매수&보유(조정종가, 무비용)와 비교했다.

| 구간 | 평균 총수익률 | 중앙값 총수익률 | 평균 CAGR | 중앙값 CAGR | 평균 Sharpe | 중앙값 Sharpe | 평균 MDD | 중앙값 MDD | 평균 승률(보유중 일간) | 매수&보유 대비 평균 초과수익 | 중앙값 초과수익 | 자기 매수&보유를 이긴 종목 수 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| FULL (2012-06~2026-11) | -4.0% | -37.0% | -17.5% | -15.7% | -0.358 | -0.152 | 61.9% | 66.0% | 43.5% | -21.7%p | +0.7%p | 944 / 1,826 (51.7%) |
| IS (2012-06~2019-12) | -15.2% | -26.1% | -18.5% | -16.8% | -0.533 | -0.282 | 50.4% | 52.7% | 43.5% | -3.5%p | 0.0%p | 593 / 1,826 (32.5%) |
| OOS (2020-01~2026-11) | +7.1% | -22.4% | -14.6% | -13.9% | -0.374 | -0.111 | 53.5% | 56.3% | 43.3% | -16.0%p | 0.0%p | 881 / 1,826 (48.3%) |

(평균 종목당 진입 횟수 FULL 11.8회, 보유 비중 시간 FULL 57.4%. "승률"은 보유 중인 날의 일간 수익이 양(+)이었던 비율이며, 라운드트립 승률이 아니다.)

- 평균이 중앙값보다 훨씬 나쁜 구간이 많다 — 상장폐지·초소형주 등 일부 종목의 극단적 손실이 평균을 크게 끌어내리므로, 분포 전체 그림은 중앙값(그리고 "이긴 종목 수")을 더 신뢰할 수 있다.
- IS 구간에는 전체 종목의 겨우 32.5%만 자기 매수&보유를 이겼다. OOS·FULL로 갈수록 그 비율이 올라가 48~52%가 되지만, 이는 "거의 동전 던지기"이며 통계적으로 유의한 우위라고 보기 어렵다.

## 2) 포트폴리오 성과 (동일비중, 전체 유니버스)

매주 "현재 신호가 롱인 모든 적격 종목"에 동일가중을 배분하는 포트폴리오를 두 가지 방식으로 시뮬레이션했다(둘 다 `bt2.simulate` 재사용):

- **매주 전량 재조정(full re-equalize)**: 매주 활성 종목 수(n)가 바뀔 때마다 보유 중인 모든 종목의 비중도 1/n으로 다시 맞춘다(하우스의 교차단면 전략들이 월간으로 하는 방식을 그대로 주간에 적용). 활성 종목 수가 수백~천 단위로 매주 바뀌는 "전종목" 유니버스에서는 이 방식이 신호 자체와 무관한 리밸런싱 회전율을 크게 늘린다.
- **진입시점 고정비중(sticky-weight)**: 종목이 신규로 롱에 진입할 때만 그 시점의 1/n_active로 매수하고, 신호가 꺼질 때만 전량 매도한다. 다른 종목의 진입/퇴장으로 비중을 다시 맞추지 않는다 — 회전율 중 "신호 자체"가 아닌 "유니버스 폭" 때문에 발생하는 부분을 분리해서 보기 위한 보조 지표.

| 포트폴리오 | 구간 | Sharpe | CAGR | MDD | 연간 비용 드래그 |
|---|---|---|---|---|---|
| **MA40(매주 전량 재조정)** | IS | -0.354 | -8.0% | 60.8% | 3.82%/년 |
| | OOS | -0.045 | -5.3% | 62.7% | |
| | FULL | -0.170 | -6.8% | 74.5% | |
| **MA40(진입시 고정비중)** | IS | -0.315 | -7.1% | 60.5% | 2.17%/년 |
| | OOS | **+0.205** | +1.8% | 45.7% | |
| | FULL | -0.011 | -3.0% | 71.9% | |
| B1: KODEX 200 매수&보유 | IS | **0.387** | +4.2% | 23.1% | — |
| | OOS | **0.758** | +20.4% | 41.9% | |
| | FULL | **0.590** | +11.6% | 41.9% | |
| 적격 유니버스 동일가중 매수&보유(참고용) | IS | -0.041 | -2.2% | 43.7% | 1.30%/년 |
| | OOS | 0.171 | +0.9% | 48.6% | |
| | FULL | 0.081 | -0.8% | 62.1% | |

**민감도(OOS, 전량 재조정 기준)**: 슬리피지 2배 → Sharpe -0.165(Δ-0.12), 매도세 0.30%로 상향 → Sharpe -0.072(Δ-0.03). 비용 가정을 바꿔도 이미 음수인 결과의 방향은 바뀌지 않는다.

**해석**: 주간 전량 재조정 방식은 회전율 비용(연 3.82%)이 상당해서 결과를 과도하게 깎아먹는다. 회전율을 신호 변경 시점으로만 최소화한 "고정비중" 버전은 OOS Sharpe가 양(+)으로 돌아서지만(0.205), 그래도 KODEX 200 매수&보유(OOS 0.758)에는 크게 못 미치고, 적격 유니버스 동일가중 매수&보유(OOS 0.171)를 겨우 소폭 앞선다. IS에서는 두 버전 모두 KODEX 200과 적격 유니버스 벤치마크 모두에 뒤진다.

## 결론

- **종목별**: 개별 종목 단위로 봐도 이 규칙이 그 종목 자신의 매수&보유를 이긴 비율은 IS 32.5%, OOS 48.3%, FULL 51.7% — 유의미한 우위가 아니다.
- **포트폴리오**: 두 구현 방식 모두 KODEX 200 매수&보유에 IS·OOS 전 구간에서 뒤진다. 회전율 비용을 최소화해도(고정비중 버전) 벤치마크 우위는 없다.
- **민감도**: 비용 가정을 더 낮춰야 결과가 바뀔 정도는 아니다(이미 기본 비용에서 음수/열위).
- 다음 단계(실거래/페이퍼 트래킹)로 넘길 근거 없음. 추가 변형(파라미터 서치) 없이, 요청된 단일 가설 그대로 기각.

## 재현 방법

```
docker run --rm --entrypoint python \
  -v $PWD/research/kr_daily_v2:/app/kr:rw \
  -v $PWD/research/kr_daily_v2/data:/app/kr/data:ro \
  -v $PWD/research/kr_daily_v1:/app/v1:ro \
  -v $PWD/src:/app/src:ro -w /app/kr tp-pipeline:local ma40_bt.py
```
(기존 `run_pipeline.sh`가 쓰는 `kr2fetch`/stage 컨테이너와는 별개의 1회성 컨테이너이며, `data/`는 읽기 전용으로만 마운트했다.)

## 파일

- `research/kr_daily_v2/ma40_bt.py`(신규) — 이 백테스트 스크립트. `bt2.py`의 패널 로더·체결 엔진(`load_panel`, `simulate`, `week_end_idx`, `slip_of`, `COMM`/`TAX`, `split`)을 그대로 재사용하고, 종목별 독립 시뮬레이션만 벡터화된 신규 코드로 추가했다. `bt2.py`, `PREREG_*`, `run_pipeline.sh` 등 기존 파일은 전혀 수정하지 않았다.
- `research/kr_daily_v2/results_ma40.json`(신규) — 전체 수치 결과(종목별 1,826개 행 포함).
- `research/kr_daily_v2/nav_ma40.csv`(신규) — 포트폴리오(전량 재조정) NAV 시계열.
