# 코인 스크립트 백테스트 기록

## 실행 범위와 출처

- 요청한 SSH 사용자명은 `opc`다. 처음 붙인 `ocp`는 철자 순서가 바뀌어 `Permission denied (publickey)`가 났다. 같은 키와 `opc@152.67.206.89`로 접속되는 것을 확인했다.
- 로컬의 `Source_Collector` 체크아웃은 `2026-10-03` 커밋 `a348179c78bc2ec969a2356f4949ff7d41906843`이고, tracked tree에는 코인 거래 디렉터리가 없다. GitHub 원격 API 조회도 404로 끝나 현재 링크의 최신 내용을 직접 가져오지 못했다.
- Oracle 서버에는 `~/ochestration-trading-test/trading` 폴더가 있었다. README 제목과 구성은 Coin_Trade 매매 로직 저장소였으며, `.git` 메타데이터는 없어 어느 Git commit에서 복사됐는지는 확인할 수 없다. 따라서 아래 수치는 **Source_Collector 최신 원격본의 재현 결과가 아니라, 서버에 남아 있던 Coin_Trade 코드 사본의 실행 결과**다.
- 기존 운영 컨테이너와 분리하기 위해 `trading/Dockerfile`로 일회성 연구 이미지를 만들고, `--rm`, CPU 1개, 메모리 2GB 제한으로 실행했다. Binance 공개 OHLCV만 읽었고 API 키, 주문 함수, 실거래 엔드포인트는 사용하지 않았다.
- 데이터는 실행 당시 Binance 공개 API에서 받았다. 백테스트는 현재(2026-10-25 KST) 시점까지의 데이터를 썼다. 데이터 자체를 별도 저장하지 않은 원본 스크립트여서, 결과 재현 시점에는 최신 캔들이 달라질 수 있다.

## 실행 스크립트 및 결과

### 1. 현물 EMA 추세 스크리닝

스크립트: `app.crypto_trend_probe`

- 50개 현물 USDT 페어, 1일봉, 2021-01-01부터 수집했다.
- EMA9/EMA21 교차와 SMA200 필터, 시작자본 10,000, 매수·매도 각 체결 수수료 0.1%(왕복 약 0.2%)를 적용했다. 슬리피지는 적용하지 않았다.
- 스크립트 내부 게이트는 Profit Factor ≥ 1.25, MDD ≤ 15%, 거래 ≥ 5건이다.
- 게이트 통과: **13/50**. 상위 일부 결과는 아래와 같다.

| 자산 | 전략 수익률 | Buy & Hold | Profit Factor | MDD | 거래 수 |
|---|---:|---:|---:|---:|---:|
| SUI | +12.2% | +68.0% | 10.43 | 4.0% | 7 |
| XRP | +28.6% | +133.4% | 7.51 | 11.2% | 19 |
| STX | +6.3% | -66.8% | 5.91 | 3.4% | 6 |
| FIL | +5.9% | -97.9% | 5.55 | 6.9% | 6 |
| AAVE | +12.6% | -42.7% | 4.70 | 3.9% | 16 |
| TRX | +13.2% | +516.3% | 3.19 | 14.0% | 28 |
| BNB | +4.1% | +165.1% | 2.09 | 4.0% | 20 |

이 스크립트는 통과 자산만 출력한다. 게이트는 Buy & Hold 초과, 표본 외 성과, 시도 횟수 보정, 통계적 유의성을 검사하지 않는다. 통과 자산 중 다수는 같은 기간 Buy & Hold보다 낮았고, 5~28건의 적은 거래로 성과가 산출됐다. 현재 알려진 상위 자산 목록을 2021년부터 소급 적용하므로 생존/선택 편향이 있다. 따라서 13개는 후속 연구 후보일 뿐, 검증된 엣지로 볼 수 없다.

### 2. 무기한 선물 상대모멘텀 롱숏 로테이션

스크립트: `app.futures_momentum_rotation_probe`

- 47개 USDT 무기한 선물, 1일봉, 2022-01-01 이후 데이터를 받았다. 지표 계산을 시작한 실제 성과 구간은 2022-01-16~2026-10-25(약 4.8년)이다.
- 14일 모멘텀 상위 8개 롱·하위 8개 숏, 롱/숏 각각 자본의 50%, 3일마다 리밸런싱했다.
- 재실행 결과: 총수익률 **+244.5%**, 연환산 **29.59%**, MDD **18.6%**, 리밸런싱 582회, 구간 승률 51.4%, 연환산 변동성 23.8%.
- 스크립트는 거래 회전분에 0.04% 비용을 적용했다. 슬리피지와 펀딩비는 반영하지 않는다. `futures_data.py`도 펀딩비 미반영을 명시하며, 따라서 수익률을 낙관적 상한으로 다뤄야 한다. 사용자 Binance 일반등급 taker 0.05% 가정을 그대로 쓰지 않은 점도 비용 검증에 남는다.
- 데이터 유니버스는 현재 코드에 정해진 자산들이다. 당시 상장돼 있던 자산만 포함되고 상장폐지된 종목이 빠질 수 있어 생존 편향이 있다. 47개 중 상장 시점이 다른 종목이 섞였고, 최초 가격 이후 데이터가 있는 구간만 계산에 반영된다.

### 3. 선물 모멘텀 파라미터 민감도 스윕

스크립트: `app.futures_momentum_rotation_sweep`

- 동일한 47개 자산과 기간에서 lookback 14/30/45/60일, 리밸런싱 3/7/14일, 롱·숏 각 3/5/8개를 조합한 **36개**를 돌렸다.
- 연환산 수익률 ≥ 10%인 조합은 **12/36**. 평균 8.43%, 중앙값 8.11%, 범위 -5.40%~29.59%였다.
- MDD는 조합별 18.6%~59.6%였다. 기본값(14일·3일·각 8개)이 가장 높은 연환산 29.59%였고, 바로 옆 설정인 14일·3일·각 5개는 21.30%, MDD 32.4%로 낮아졌다.
- 이 스윕은 같은 과거 데이터로 조합을 비교하고 가장 좋은 값을 고르는 인샘플 절차다. 여러 조합을 시도한 데 대한 통계 보정이나 별도 기간 검증이 없다. 12개가 10%를 넘었다는 사실만으로 강건성을 입증하지 않는다.

## 종합 판단

선물 로테이션은 해당 스크립트가 가정한 비용 아래에서 수익이 양수였지만, 결과가 기본 파라미터에 가장 유리했고 MDD도 무시할 수준이 아니다. 펀딩·슬리피지, 실제 거래 수수료, 생존 편향, 인샘플 파라미터 선택을 반영하기 전에는 실거래 후보로 승격할 근거가 부족하다. 현물 EMA 스크리닝은 내부 게이트 통과 수가 있었지만, Buy & Hold를 이긴 사례가 제한적이고 표본 외 검증이 없어 동일하게 연구 후보 수준이다.

특히 이 결과는 앞선 대화의 별도 파이프라인에서 나온 66개 변형 탈락 결과와 모순이라고 단정할 수 없다. 여기서는 다른 저장소 사본, 다른 전략, 다른 기간/비용/유니버스와 느슨한 1차 필터를 사용했다. 서로 다른 실험 결과를 같은 전략 증거처럼 합쳐서는 안 된다.

## 실행 후 정리

일회성 연구용 Docker 이미지는 실행 결과 기록 후 삭제한다. 운영 컨테이너, Freqtrade 설정, 거래소 키, 80/443 포트는 변경하지 않았다. 보고서에 기록된 수치는 스크립트가 출력한 값이며, 결과의 전략적 유효성을 검증한 것은 아니다.
