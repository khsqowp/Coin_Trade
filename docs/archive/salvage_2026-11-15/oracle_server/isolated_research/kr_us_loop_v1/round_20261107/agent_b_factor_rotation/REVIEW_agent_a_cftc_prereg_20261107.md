Recomputing the rolling z-score availability from those three CFTC fields yields 90 valid signals, zero zero-variance windows; the source report-date span is 2025-02-04 through 2026-10-20. This is a source-signal count only, not a count of NYSE-session executions.
- **Material DATA_GATE discrepancy.** `DATA_GATE.md` says the prior label `E-MINI S&P 500 STOCK INDEX - CHICAGO MERCANTILE EXCHANGE` has 494 rows from 2012-01-10 through 2022-02-01. The same ZIP set contains **526** rows in that stated date interval, with no duplicate dates or invalid required signal/open-interest values. It also contains 290 earlier rows under that label from 2006-06-13 through 2011-12-27; all 290 have finite required fields and positive open interest. Thus 816 rows exist through 2022-02-01, not 494, for the cited date span plus the pre-2012 history. This does **not** authorize merging the alias into the frozen candidate: the preregistration explicitly locks the exact market label. Correct the gate report's count/coverage description in an addendum or leave it explicitly unresolved; do not silently alter the frozen candidate.
- **Vintage / lookahead assessment.** CFTC's official FAQ says reports are generally Friday 3:30 p.m. ET based on the prior Tuesday; it also says holiday weeks can shift timing, no complete historical release-date list is available (only 13 months), and historical data are not updated after publication. The fixed `Report_Date + 8 calendar days` rule is later than the ordinary Friday release and the observed holiday-week shifted dates, so no concrete lookahead violation was found. However, exact historical publication timestamps cannot be independently verified for the full sample; document the 8-day lag as a conservative timing assumption rather than observed point-in-time release-vintage evidence. Official source: https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm (FAQ lines 105-117).
- **Internal precision issue.** `DATA_GATE.md` says exact-name history leaves too few rows “to populate the preregistered historical evaluation windows.” The frozen windows are 2009–2016, 2017–2020, and 2021–cutoff, with empty windows explicitly permitted; the source series does provide 90 post-warm-up observations in 2021–cutoff. The claim should say that older windows have no eligible observations and the surviving window has only 90 weekly signals, not that no evaluation window can be populated. Separately, the preregistered pass condition requires beating the benchmark in “every fixed historical window,” which is undefined when two windows are empty. Clarify the pass rule in a transparent addendum before any performance test; do not revise the frozen rule after seeing results.

## Verdict

The CFTC ZIP hashes and frozen exact-label source coverage are reproducible, and the 90-signal warm-up count is correct. The gate report has a **verified 32-row discrepancy** for the old-label 2012–2022 count and an imprecise statement about evaluation-window coverage/pass criteria. These are documentation/gate issues, not evidence of a CFTC signal-data defect. No performance test was run; no edge claim is made.
