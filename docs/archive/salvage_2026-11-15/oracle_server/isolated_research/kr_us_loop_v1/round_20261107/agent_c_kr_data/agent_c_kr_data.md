# Agent C — 국내 주식 데이터 접근성·적격성 조사

- 조사일: 2026-11-07 (KST)
- 결과: `DATA_BLOCKED`
- 범위: KRX·공공데이터포털의 공식 공개자료, 접근·인증 방식, 이용 조건, PIT/기업행위/총수익 데이터 요건
- 금지사항 준수: API 키·사용자 비밀정보를 열람하지 않음. 계정 생성, 활용신청, API 호출, 다운로드, 유료 계약을 하지 않음. Oracle 서버·거래 파이프라인·컨테이너·실거래 코드를 조작하지 않음.
- 전략: 사전등록하지 않음. 적격한 데이터가 확인되지 않았으므로 수익률 계산 및 백테스트를 실행하지 않음.

## 결론

무료 공식 자료로 전략 입력의 일부는 확보할 가능성이 있다. 그러나 현재 권한·문서만으로는 국내 전종목 PIT 일별 데이터가 상장폐지 종목, 거래정지·무거래일, 종목 식별자 변경, 주식분할·배당·합병·상장폐지 현금흐름, 수정 이력까지 완전하게 포함한다고 입증할 수 없다. 다운로드/API 인증키도 현재 제공되지 않았고, 생성·신청 권한은 주어지지 않았다. 따라서 이 라운드에서의 판단은 `DATA_BLOCKED`다.

## 다운로드/API 실행 상태

- API·다운로드 명령: 실행하지 않음. 인증키/승인 없이 호출하는 방식이나 비인증 대량 다운로드 경로를 확인하지 않았다.
- API 키 요구: KRX Open API는 신청한 인증키를 요구하고, 공공데이터포털 API는 서비스키를 필수 파라미터로 표기한다. 사용자의 키·환경 변수·`.env`·서버 비밀 저장소는 열람하지 않았다.
- 계정/약관: 신규 계정을 만들거나 이용약관에 동의하지 않았다. 권한이 없는 신청을 대행하지 않았다.
- 파일 원본: 내려받은 파일 없음. 데이터 파일 해시 없음.
- 조사 문서 SHA-256: 동봉한 `REPORT.sha256`의 detached checksum을 기준으로 검증한다.

## 백테스트 입력 적격성 판정

다음 요건 중 하나라도 확인되지 않으면 성과 계산 금지다.

1. 2010년 이후 모든 거래일·유가증권/코스닥 전 종목의 OHLCV가 과거 기준일에 재현되고, 거래정지·무거래·상장일·상장폐지일 처리 방식과 결측률이 검증될 것.
2. 단축코드 변경·합병·이전상장·종목코드 재사용을 막는 영구 식별자 및 유효기간 조인 규칙이 제공될 것.
3. 분할·병합·배당·유무상증자·합병·감자·상장폐지 정산을 반영할 공식 기업행위 원장이 있고, 기준일 당시 알 수 있었던 공시/정정 버전과 가격조정 규칙이 검증될 것.
4. KOSPI/KOSDAQ 비교지수의 TR 시리즈가 해당 기간 전체에 제공되고, 지정 전략과 동일 날짜로 정렬 가능할 것.
5. 데이터 사용 허가가 비상업적 사적 연구와 지표·전략 계산을 허용하고, 저장·백테스트 산출물의 처리 및 제3자 공개 제한을 충족할 것.
6. 로그인/API키 발급 및 일일 호출량을 승인받은 후, 실제 첫 데이터 스냅샷에서 상장폐지 사례·corporate action 사례를 표본 대조하고 전체 PIT 커버리지와 해시를 고정할 것.

현재는 1~6 모두를 만족한다고 확인할 수 없다. 특히 인증된 호출도 없고, 상폐 포함 범위와 정정본·기업행위 원장을 실제 응답으로 검증하지 않았다. 그러므로 “무료니까 곧바로 재현 가능한 완전 PIT”라고 판단하지 않는다.

## 전략/테스트 상태

- 사전등록: 없음. 데이터 계약과 이용권한을 통과하기 전에 전략을 선택하면 범위·기간·유니버스의 사후 변경 위험이 생긴다.
- 시장 데이터값 열람: 없음.
- 가격·수익률·시그널·포트폴리오 지표 계산: 없음.
- 단위 테스트/백테스트: 없음. 실행 가능한 고정 후보/러너가 만들어지지 않았다.
- 최종 상태: `DATA_BLOCKED`; 성과에 대한 긍정·부정 결론 모두 없음.

## 다음에 필요한 권한/증거

1. 소유자가 KRX Open API의 이용자 계정·서비스 신청 및 약관 동의를 직접 완료하거나, 이미 허가된 비밀키를 Codex가 읽지 않는 방식으로 해당 API 역할에 안전하게 주입한다.
2. 키 발급 이후에도 비상업적 개인 리서치 및 저장·변환 범위가 허용되는지 KRX terms와 해당 서비스 조건을 서면/공식 문서로 확인한다. 제3자 배포/상업 이용은 금지로 취급한다.
3. 인증된 호출은 별도 승인 후 소량의 날짜·종목 샘플로만 검증하고, 상폐·분할·배당 사례와 공식 원문을 대조한다. 이는 이번 라운드에서 수행하지 않았다.
4. 샘플과 전체 커버리지 검증이 성공하면 전종목 PIT 데이터·TR 지수·기업행위 출처를 동결하고, 그 뒤에만 새 단일 전략을 사전등록한다. 새 후보의 시장 실행은 사전등록 승인 후 한 번만 한다.
