# Agent C — 국내 지수·ETF 자료 적격성 점검

- 조사일: 2026-11-07
- 범위: 공식 KRX 지수/ETF 경로와 운용사 공시의 접근·권리·시계열 정합성만 점검
- 상태: `DATA_BLOCKED`
- 성과 수치, 수익률 계산, 시뮬레이션, 백테스트: 수행하지 않음

## 결론

단일 지수·ETF로 바꾸면 종목별 PIT 유니버스 문제는 줄지만, 이번 조사만으로는 적격한 과거 시계열을 내려받지 못했다. KRX Open API는 지수·ETF 일별 자료를 2010-01-04부터 제공한다고 공개하지만, 이용약관 동의와 개인별 API 키 신청이 선행되어야 한다. 익명 API 접근은 확인되지 않았다. 공개 화면에서 지수/ETF 통계 메뉴가 있다는 사실은 기계 판독 가능한 전체 이력 다운로드 권한이나 재연구 허가를 뜻하지 않는다.

따라서 현재 GO 가능한 데이터 세트나 사전등록 가능한 지수/ETF 테스트는 없다. 인증키 발급 없이 API 호출을 시도하지 않았고, 권리 범위가 불명확한 비공식 엔드포인트도 호출하지 않았다.

## TR 지수 식별 결과

KRX 지수사업 안내는 TR(Total Return)을 현금배당 재투자를 가정한 지수로 설명하고 KOSPI 200 TR 및 KOSDAQ 150 TR 계열 지수의 존재를 확인할 수 있다. 그러나 이 조사에서 Open API의 개발명세서/응답 스키마에 들어가 특정 TR 시리즈 코드를 확인하지 못했다. 서비스 목록은 “KOSPI 시리즈”, “KOSDAQ 시리즈”의 집합 설명과 2010-01-04라는 공통 시작일만 보여준다. 이 안내를 근거로 특정 TR 지수 데이터가 2010년부터 실제 제공된다고 단정할 수 없다.

공식 지수 사이트에서 정확한 지수 코드·산출개시일·과거 소급 산출 여부를 확인하고, API 인증을 받은 뒤 최소 한 구간의 API 응답과 지수 방법론 문서를 대조해야 한다.

## ETF 후보 및 자료 공백

운용사 공식 자료에서 KODEX 200(종목코드 069500)이 확인되며 상품 페이지는 상장일을 2002-10-14로 표기한다. 이는 상품이 존재한 기간의 하한 참고일 뿐, KRX Open API에서 그 날부터 ETF 일별 시세가 완전하게 내려온다는 증거는 아니다.

공식 운용사 페이지에는 분배금 현황/공지 자료가 있지만, 이번 조사에서 과거 전 기간의 기계 판독 가능한 분배금 원자료와 조정 일봉의 공개 다운로드 경로, 자동 수집 권한을 함께 확인하지 못했다. ETF 일별 매매정보 API의 설명은 “매매정보”이며, 수정주가 또는 분배금 포함 총수익 시계열을 제공한다고 명시되어 있지 않다. 그러므로 ETF의 종가만으로 총수익을 대체할 수 없다.

## 지수 벤치마크와 ETF 실행수익률 정합성 기준

지수 TR은 직접 체결 가능한 자산이 아니다. ETF 전략과 비교하려면 동일 날짜 범위 및 거래일을 맞추고, 다음을 분리해야 한다.

1. 신호/벤치마크: 정확히 식별된 공식 TR 지수의 종가 수익률.
2. 실행 포트폴리오: ETF 실제 체결 가능한 가격(일봉이면 다음 거래일 시가 등 사전 고정한 체결 가정), 매수·매도 수수료와 슬리피지.
3. 분배금: ETF 분배락일·지급액·재투자 시점이 확인되면 현금흐름으로 반영. TR 지수와 ETF 분배금을 동시에 더해 이중계상하지 않음.
4. ETF 총보수/기타 비용은 NAV/가격에 이미 반영되는 항목과 별도 거래비용을 구분하고, 기준지수와 상품의 추적오차도 별도 기록.
5. 거래정지·상장폐지·상장 전 기간은 거래 가능한 관측값으로 가장하지 않는다. ETF가 상장된 기간만 전략 평가 가능하며 지수의 더 긴 과거 구간과 직접 비교할 수 없다.

실제 가격 수치나 수익률은 이 보고서에서 계산하지 않았다.

## 게이트 및 다음 조치

- `DATA_BLOCKED`: 공개 안내만으로 인증 없이 데이터 요청할 권한을 확인할 수 없음.
- `DATA_BLOCKED`: TR 지수 개별 코드와 API 응답 스키마가 미확인.
- `DATA_BLOCKED`: ETF 조정 일봉/분배금 전체 이력과 수집·보관 권리가 미확인.
- `DATA_BLOCKED`: 지수 API와 시장정보 이용계약 중 본 연구에 적용되는 라이선스 해석이 미확인.
- 실행하지 않은 것: API 키 발급, 계정 생성, 비공식 엔드포인트 호출, 파일 다운로드, 성과 계산, 백테스트.

GO 전 필요한 최소 증거는 (a) KRX가 허용하는 개인 비상업적 로컬 연구 범위에 대한 명시적 확인, (b) 인증 API의 지수 상세 코드/필드/시작일 샘플, (c) ETF의 조정 가격 또는 공식 분배 이벤트 이력과 상장폐지 포함 범위, (d) 지수 TR 방법론·소급 산출 시작일이다. 이 증거가 확보되기 전에는 단일 지수/ETF 대안도 백테스트 적격 데이터로 간주하지 않는다.
