# KR/US daily market-data eligibility audit

**Status: DATA_BLOCKED.** As of 2026-11-07, this audit found no free/public-domain source that both (a) provides daily security-level price/return data suitable for execution backtests, including delisted securities and corporate actions, and (b) explicitly permits private noncommercial research and derived analysis under the published rights. No prices were downloaded or viewed; no account, API key, or terms acceptance was used.

## Decision rule

A source clears the frozen-data gate only if its published documentation establishes all of the following: daily security-level prices or executable total returns; the historical universe including inactive/delisted instruments; corporate-action/dividend and delisting treatment sufficient to avoid survivorship/return omission; time/point-in-time caveats; and explicit rights allowing noncommercial research and transformation into derived strategy signals. “Free API” alone is insufficient. Missing any criterion is a block, not an assumed pass.

## Rights interpretation and boundary

KOGL’s official Type 4 definition is attribution + noncommercial use + prohibition on modification/derivative works. The official guide explicitly says modifications include changing content or format and making derivative works. A backtest that transforms OHLC/index values into adjusted returns, signals, or derived datasets may conflict with that published condition. This report does not give a legal opinion; the operational decision is to **not** transform Type 4 market data absent written permission from the rights holder.

The FSC portal’s “free” and automatic API approval labels describe access/cost, not a grant to change, redistribute, or use KRX-owned data without restriction. The pages identify third-party rights and direct certain use to KRX Data Marketplace. No key, API request, registration, or contract was initiated.

## Gate outcome

- **US:** no qualifying free/public-domain daily security/ETF dataset found. CRSP is the best documented technical fit but requires a subscription; French Library is aggregate returns, and FRED S&P 500 is copyrighted price-index data rather than an executable total-return series.
- **KR:** no qualifying source found. Free FSC/KRX daily price/index APIs have Type 4/no-modification and third-party-rights restrictions, while catalog-level PIT, delisted price, adjustment and revision coverage is not established. KSD lifecycle metadata and issuer notices are supplements, not price/return data.
- **Backtest decision:** DATA_BLOCKED for both markets. Do not calculate performance, use synthetic substitutions, infer missing corporate actions, or promote any candidate as tested evidence from these sources.
- **Next valid route:** obtain permission/licensing for CRSP or KRX data, or locate an explicitly open-licensed source that documents delisted coverage, corporate actions, PIT snapshots, and revision policy. Then inspect a small schema/coverage sample before any candidate preregistration or performance run.
