No candidate can be called a valid strategy from these runs: earlier OOS periods were inspected, cumulative historical trial count is unresolved, and PIT coverage/universe limitations remain. Do not tune thresholds or search factorial combinations. User requires every start, completion, and failure to remain recorded.

Use the same prices, eligibility, costs, daily-bar next-open simulator, and screening partitions as Generation 01, with these exceptions: Generation 02 formulas below are evaluated at each month-end; the breadth-gate holds the complete eligible equal-weight basket rather than a top-K basket. `run_gen02.py` records monthly decision counts. If benchmark or data setup is invalid, log failure for every affected candidate-market attempt and skip the market.

Families are intentionally not independent: Theil–Sen and multi-window OLS are trend-estimator comparisons; sign-flip and Kalman drift overlap price momentum/persistence; SSF is a smoothed-trend estimator; breadth is a market timing overlay related to prior SMA filters. The full six-by-two set must count as 12 additional tests, not six independent hypotheses. The prior total trial count remains unknown; DSR/PSR and global correction are not claimed.

## Frozen candidates

All names use adjusted daily close, observed only through month-end `t`; trades are placed at open `t+1`, long-only, unlevered. Candidates 1–5 hold up to 20 KR / 50 US names, equal weighted, ties by ticker, and hold cash for unfilled slots.

1. **TS63_KENDALL** — For each name, let `x[0..62]` be the last 63 observed log closes at `t`. Compute all 1,953 pair slopes `(x[j]-x[i])/(j-i)` for `i<j`; score is their median. Compute Kendall tau-a as the mean sign of those 1,953 pair differences. Require a complete 63-close window, positive median slope, and tau-a >= 0.30. Rank by tau-a descending; top K. No parameter variants.
2. **OLS_MULTI_3OF4** — Compute trailing OLS slopes on log close for fixed windows 21, 63, 126, and 252 sessions. Qualify if at least three slopes are positive. Rank first by the count of positive slopes, then by the mean cross-sectional percentile rank of only the positive slopes (ticker resolves remaining ties); hold top K. This tests timeframe agreement, not a new independent momentum factor.
3. **SIGN_FLIP63** — On the latest 63 close-to-close log returns, ignore zero returns. `flip_rate` is the number of sign changes between adjacent nonzero observations divided by the number of such adjacent pairs. Enter when cumulative 63-session return > 0 and flip_rate <= 0.32. Once held, remain until cumulative return <= 0 or flip_rate >= 0.50. Rank by `63-session return * (1-flip_rate)`; top K. Entry/exit state is sampled at month-end only.
4. **KALMAN_DRIFT63** — For each name, daily log return `r_t` observes latent drift `mu_t`; `mu_t=mu_(t-1)+eta_t`, `r_t=mu_t+epsilon_t`. At each date, `R_t` is the sample variance of the latest 63 completed returns and `q_t=R_t/63^2`. Filter only (no smoother): `Pminus=P+q`, `K=Pminus/(Pminus+R)`, `mu=mu+K*(r-mu)`, `P=(1-K)*Pminus`. Initialize after 63 returns with `mu=mean(r63)`, `P=R/63`; update forward causally and allow signals only after 126 observed returns. `z=mu/sqrt(P)`. Enter at month-end if `z>=1`, exit when `z<=0`; rank by z, top K. If the current variance window is invalid, carry the prior `mu/P` unchanged. If `R_t` is valid but `r_t` is missing, perform prediction only (`Pminus`, unchanged `mu`); no lookahead.
5. **EHLERS_SSF40_SLOPE5** — Let `x_t=log(adjusted close)`. `a=exp(-sqrt(2)*pi/40)`, `b=2*a*cos(sqrt(2)*pi/40)`, `c1=1-b+a^2`, `c2=b`, `c3=-a^2`. Recursive filter `SSF_t=c1*(x_t+x_(t-1))/2+c2*SSF_(t-1)+c3*SSF_(t-2)`. Initialize the first two observed values to their x values; restart after a missing-price gap at the next observed x; require 200 observed bars after restart before signals. `s=SSF_t-SSF_(t-5)`. Enter if `s>0` and `x_t>SSF_t`; exit if `s<=0` or `x_t<SSF_t`. Rank by `s / trailing-63-session daily log-return standard deviation`, top K. No centered filters or future values.
6. **BREADTH_60_40_BASKET** — At month-end, among then-eligible PIT names with at least 200 observations, breadth is the fraction with close above their own trailing SMA200. State turns on at breadth >= 0.60 and off at breadth <= 0.40; retain the previous state in between. When on, hold the full then-eligible universe equal weighted; when off, hold cash at 0%. Execute state/basket changes next open with the same costs. This is a breadth exposure rule, not a single-index SMA rule. Results remain nonconfirmatory because PIT membership and KR universe reconciliation are unresolved.
