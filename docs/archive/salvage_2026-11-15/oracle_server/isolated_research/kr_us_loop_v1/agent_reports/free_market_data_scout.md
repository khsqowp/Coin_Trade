# 무료 공개 시장 데이터 경로 조사

조사일: 2026-11-07  
범위: 합법적 공개 무료 경로만 조사. 다운로드·가입·연락·Oracle 접속·백테스트는 하지 않았다. 웹페이지의 주장을 독립 검증한 것이 아니라, 명시된 제공 범위와 이용조건을 확인했다.

## 결론

현재 확인된 무료 공개 경로만으로는 KR·US 양쪽에 대해 장기 일봉 OHLC, 상장폐지 포함 PIT 유니버스, 배당·분할 등 기업행위, 거래소 캘린더를 모두 충족하는 단일한 검증 가능 데이터 공급원을 확보할 수 없다.

- **한국:** KRX Open API가 가장 직접적인 무료 후보지만, 약관 동의와 인증키 신청이 필요하다. 2010년 이후 일별 주식·지수·ETF 데이터를 제공한다고 공개되어 있다. 별도로 KRX Data Marketplace에 상장폐지 종목의 시세 추이 조회 페이지가 있어 일자별 OHLCV 열을 노출하지만, 조회 한도·기록 범위·자동수집 조건은 확인되지 않았다. 어느 경로도 PIT 커버리지와 조정/기업행위 완결성을 입증하지 못했다.
- **미국:** 공개 소스 중 pitindex는 MIT 라이선스의 PIT 지수 구성원 자료지만 가격·기업행위 데이터가 아니다. sp500-data 공개 저장소는 S&P 500 PIT 가격 자료를 주장하나, 저장소 페이지에서 데이터 배포 라이선스를 확인하지 못했고 CRSP 자료 사용 및 재배포 출처가 섞여 있다. 라이선스·원천 권한이 확인되기 전에는 데이터 사용 후보로 승인할 수 없다.
- **일반 무료 API/스크래핑:** 제한된 최근 기간만 제공하거나 자동수집·보관이 약관상 제한될 수 있어 장기 연구의 기반으로 삼기 어렵다. 특히 Yahoo 약관은 사전 명시적 허가 없는 자동 수집을 금지한다.

## 시장별 실행 가능한 다음 단계

1. **KRX 경로:** 사용자가 KRX Open API 이용 약관을 직접 수락하고 개인 인증키를 로컬 비밀 저장소에 발급한 뒤, 공개된 주식·지수 API에서 작은 검증 샘플만 요청한다. 키는 채팅·저장소에 넣지 않는다. 우선 현재 상장/상장폐지 표본 각각의 과거 날짜 조회 가능 여부, 종목코드 변경, OHLC 필드, 배당·분할·감자·합병 이벤트를 판정한다. 별도로 KRX 상장폐지 시세 페이지의 조회범위·내보내기 조건도 검증한다. 하나라도 미확인인 구간은 과거성과 판정에 포함하지 않는다. 원자료를 제3자에게 제공하지 않고 내부 비상업 연구에만 쓸 수 있는지 약관 적용도 확인한다.
2. **US 경로:** pitindex는 구성원 날짜만 보완하는 후보로 분리 검증한다. 가격 데이터는 기존 로컬 data_mirror를 1차 기준으로 삼고, 빠진 494개 유니버스 파일 및 이름 변경/재활용 사례를 식별자 기준으로 정리한다. 외부 공개 Parquet은 라이선스가 확인되지 않으면 투입하지 않는다. 장기 OHLC·기업행위·delisted 완전성과 재사용권을 동시에 충족하는 무료 출처를 찾지 못하면 US 전종목 성과시험은 **데이터 차단** 상태로 유지한다.
3. **벤치마크/달력:** KRX 2010+ 지수 API와 공공데이터포털 2020+ 자료는 중복 구간 교차검증용 후보이나, 제공 약관에 맞춰 내부 사용·출처표시를 제한한다. 거래일 달력은 현지 거래소의 공시 휴장일 및 조기폐장 자료와 대조하고, 라이브러리 생성 캘린더만으로 authoritative calendar라고 단정하지 않는다.
4. **무료 티저는 경계가 있다:** FinzData 등 무료 키가 있어도 최근 12개월 제한은 장기 OOS 검증을 해결하지 않는다. 무료 계정 등록도 하지 않았다. 유료 자료·키 발급에 수반되는 계정 생성은 사용자의 직접 조치나 별도 승인 없이는 진행하지 않는다.

## 연구 게이트에 미치는 영향

- 이 조사로 신규 가격 자료를 취득하거나 성과시험을 실행하지 않았다.
- 공개 웹의 코드·자료 설명은 공급자/관리자 주장이지 검증된 데이터 품질 증거가 아니다.
- 무료 데이터가 없다는 이유로 현재 PIT 데이터 검증, 비용 반영, 사전등록, IS/OOS, 다중검정 게이트를 완화하지 않는다.
- 현재 시점의 결론은 **무료 공개 경로만으로 양 시장의 모든 필요조건을 입증하지 못함**이다. 이 판단은 전략에 edge가 없다는 뜻도, edge가 있다는 뜻도 아니다.
