# KIS OpenAPI 개인 연구 및 로컬 시세 보존 권리 점검

- 조사일: 2026-11-24
- 조사 범위: KIS 공식 공개 약관과 공식 개발자 포털 문서
- 조사 금지 준수: 로그인, 계정·키 접근, API 호출, 문의, 데이터 다운로드, `KR_069500.csv` 행 열람을 하지 않았다.
- 판단 범위: 이 문서는 법률 자문이나 KIS의 개별 허가를 대신하지 않는다. 문서에 적힌 허용과 문서가 답하지 않는 항목을 구분한다.

## 결론

KIS 고객 약관은 고객이 직접 개발한 프로그램 등 개인 업무에 시세정보를 사용하는 것을 허용하고, 그 정보를 제3자에게 제공하지 못하도록 명시한다. 다만 개인 오프라인 과거 백테스트와 내려받은 시세 파일의 로컬 보존 기간·백업·저장소 보관은 확인한 약관에 명시되어 있지 않다. 따라서 개인 내부 연구 취지와 부합한다고 볼 여지는 있으나, 지속 보존 권리가 명시적으로 확인됐다고 판정할 수는 없다.

## `KR_069500.csv` 연구 범위

`KR_069500.csv`는 이 과제에서 검토 대상으로 지정된 기존 KIS 일봉 파일이다. 파일의 존재 여부 외 메타데이터나 데이터 행을 확인하지 않았고, 기간·조정 방식·결측·기업행위 반영 여부도 판정하지 않았다. 이 문서만으로 해당 파일의 품질이나 전체 기간을 보증하지 않는다.

069500 자료를 사용한다면 해당 ETF 자체에 대한 별도 가설과 사전등록을 거쳐야 한다. 등록된 278530 대상은 현재 없다는 과제 지시를 그대로 적용한다. 069500을 278530의 대체자료나 동일한 등록 후보로 취급하지 않는다. 이 메모는 전략 실험을 승인하거나 사전등록을 변경하지 않는다.

## 보수적 운영 경계

확인된 명문 범위는 고객 본인의 직접 개발 프로그램 등 개인 업무 이용과 제3자 제공 금지다. 오프라인 재현 실험이 이 범위에 해당하는지, 과거 시세 파일을 계속 저장하는 것이 허용되는지는 약관 문언만으로 확정되지 않는다. 이 불확실성이 해소되기 전에는 파일을 외부에 배포하거나 공개 저장소·공유 서비스에 올리거나, 제3자가 접근 가능한 형태로 제공할 권리가 확인됐다고 주장하지 않는다. API 기능 존재와 데이터 보존 권리는 별개의 문제로 취급한다.
