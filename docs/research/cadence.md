# 리밸런스 타이밍/케이던스 리서치 (모멘텀 로테이션)

데이터: data.binance.vision 1h 봉 -> UTC 일봉(45종목, 2021-06~2026-10-09), 8h 펀딩 이력(일 커버리지 >=2/3 슬롯 88%).
비용: 편도 0.10% (수수료 0.05 + 슬리피지 0.05), 펀딩 반영(롱 지불/숏 수취). 시뮬 2022-01-01~2026-10-09.
스크립트: app/rs_cadence_engine.py(numba 엔진), rs_cadence_run.py(그리드/WF), rs_cadence_stagger.py(정렬중립), rs_cadence_data.py(로컬 로더).
결과 JSON: cadence_results.json, cadence_stagger_results.json, cadence_final_candidates.json.
(코덱스가 쓴 엔진 초안은 미완성/중복 코드라 폐기하고 직접 재작성함. 미래참조 테스트 통과: 미래가격 교란 시 과거 weights 불변.)

## 핵심 발견
1. **14/3/8 의 +28.9%는 정렬(offset) 운이 크다.** 같은 14/N3/K8 도 시작 오프셋 0,1,2 에 따라 Calmar 1.19/0.58/0.75 (신규 비용). 일봉 UTC 기준시를 바꿔도 N=3 Calmar 0.66~1.49, N=2 0.46~0.84. 고정 N 프로파일이 N=2:0.46, 3:1.19, 4:0.78, 5:1.21 로 들쭉날쭉 = 노이즈.
2. **정렬 중립 평가(N개 트랜치를 오프셋 0..N-1 로 엇갈려 운용 = 매일 1/N 씩 리밸런스)** 로 보면 프로파일이 매끈하다: 케이던스 2~4일이 최적, 7일 이상은 명확히 열위(lb14 K8: N=4 Calmar 1.18 -> N=10 0.37). 모멘텀 신호 반감기가 짧음.
3. **수수료가 지배적**: 14/2/12 = 회전 ~98x/년, 수수료 ~10%/년. 히스테리시스 밴드/멀티호라이즌은 수익은 비슷한데 회전을 절반으로 줄임(수수료 5%/년).
4. 펀딩은 -0.7~+0.3%/년로 무시 가능(롱숏 상쇄).
5. 이벤트 기반(C), 변동성 적응(D), 부분 리밸런싱(E)은 단순 고정 케이던스+밴드(B)/멀티호라이즌(F) 대비 우위 없음. IS 최적은 OOS에서 붕괴(예: K15 N14 IS Calmar 3.5 -> OOS 0.17). 6개월 단위 확장 WF 재선택 결과도 현행 14/3/8(오프셋0 +31%)을 못 넘고(B 21%/MDD26%, C 18%/MDD20%, all 11%/MDD17%) 선택 자체가 불안정.

## 실패한 것
- 고정 N>=7: 엇갈림 평가에서 일관 열위. 이웃 불안정한 IS 1위들(K15 N10~14).
- 이벤트(순위이탈 수/점수감쇠/상한일수): 회전은 줄지만 OOS Calmar 0.15~0.5, 이웃 최소 낮음.
- 변동성 적응 케이던스: OOS 0.3~1.0, 이웃 음수 존재(불안정).
- 부분 리밸런싱(f 0.25~0.75): 수익이 비례 감소, Calmar 개선 없음.
- 확장 WF 재선택: 현행보다 개선 안 됨.

## 권고
- "N=2 고정"도 "N=3 고정"도 최적이 아님. 두 값의 차이는 대부분 정렬 노이즈. 실사용에서는 **단일 정렬에 의존하지 않도록 케이던스 3일 + 히스테리시스 밴드 2 + 멀티호라이즌(14,28)** 으로 회전(수수료)을 줄이는 방향(C1/C4)이 비용 반영 후 Calmar/MDD 모두 가장 안정적. 라이브 K=12 를 유지한다면 N=3 + 밴드2(C4) 가 최소 변경.
- 수익률을 더 보면 C2(lb14 K8 N4)가 CAGR 21%.
- 단, 엇갈림 평가 기준 기대 CAGR 은 ~16~21%/MDD 13~18% 수준이며 문서의 +28.9% 는 재현 불가(오프셋0 31.9%->신규비용 23.8%, 대표값 아님). "베이스라인을 압도"한다고는 말할 수 없음. 개선은 주로 MDD/수수료 쪽.
- 라이브 적용 전 페이퍼에서 밴드/멀티호라이즌 구현과 트랜치 정렬(실제 단일 시각 리밸) 영향 확인 필요.

## 가정/미검증
- 일봉 종가 체결(다음봉 수익부터 반영), 슬리피지 고정 0.05%. 상장일 이전/ffill<=3봉 처리. 펀딩은 보유 weight x 일 합계(8h 마크 미반영).
- 엇갈림 트랜치는 트랜치 간 거래 상계 없이 수수료 계산(보수적). 실제 구현은 매일 1/N 부분 리밸이라 상계로 더 유리.
- 유니버스는 현재 45종목(생존편향 가능: TAO/ENA/JUP 등 최근 상장은 상장 후부터만 편입, 폐지종목 없음).
- 원 문서 백테스트(28.9%/18.6%)는 수수료 0.04%·47종목 데이터라 직접 재현은 31.9%/18.3%(오프셋0, 0.04%, 무펀딩)로 근접만 확인.
