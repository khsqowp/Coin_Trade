# R008 decision

Overlapping forecasts are a viable protocol-design option for resolving R007's arithmetic conflict, but not a performance improvement and not extra independent evidence. Any next study must bootstrap synchronized time blocks across symbols, keep 10T and 20T labels from one forecast dependent, set a precision lower-bound rule before outcomes, and justify a forward duration adequate to the largest horizon. R008 leaves exact inference choices open and therefore does not authorize performance scoring.
