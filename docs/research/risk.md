## 엔진/가정
- 일봉 종가 신호 -> 종가 체결, 방향 불변 포지션은 수량 유지(라이브 apply_targets 동일), 포지션당 명목 = equity*deploy*lev/(2K).
- 비용 0.10%/편도(수수료0.05+슬리피지0.05), 실제 펀딩 이력 반영, 유지증거금 0.5%.
- 교차마진 청산: 매 시간 롱=저가/숏=고가 동시 적용(보수적)한 최악 equity vs 유지증거금. buffer = worst_equity / maintenance (1.0 이하 = 청산, 1.5 이하 = 경고).
- 시작 리밸런스 phase 에 매우 민감(2022 연수익 1%~35%) -> 모든 수치는 phase 0..N-1 평균, MDD는 phase 최악.
- 검증: 문서 방식(상수 비중, 45종목)은 phase0 +30%/MDD 19.8% 재현. 라이브 방식(수량유지)은 같은 데이터에서 CAGR 37~48%/MDD 21~29%(phase별)로 더 높고 변동성도 큼. 엔진은 독립 pandas 구현과 일치(47.0 vs 47.8%).
- 문서 6-1의 4x 청산은 "일손실 > 1/L - 0.5%면 전멸" 모델 때문. 교차마진에서는 equity 98% 손실이 있어야 청산이므로 과대평가. 본 엔진에서 모든 구성 청산 0건, 최소 buffer 14배(4x/100%배치).
  단 이는 교차마진 가정 + 동시 급락 일중. 격리마진이면 해당 없음(라이브 코드는 마진모드 미설정=기본 교차로 추정, 미확인).

## 소액계좌(142 USDT) 실현가능성
포지션당 명목 = 142*gross/(2K): K12 gross1.0 -> 5.9, gross2.9 -> 17.2, gross3.2 -> 18.9; K8 gross1.0 -> 8.9.
- 최소명목 5 USDT: 라이브 4x/80%/K12 진입은 가능(18.9). delever(1x, deploy.8)시 4.7 < 5 -> 전종목 스킵 = 사실상 flat. 
- 최소명목 20 USDT: 4x에서도 18.9 < 20 -> 전량 스킵(거래 0). BTC(~100)/ETH(~20)는 18.9 에서 스킵(미확인, exchangeInfo 미조회).
- 라이브 정확 로직 시뮬(142 USDT, min 5): HWM 대비 -20% 이후 eff_lev=1 -> 명목 4.7<5 -> 전량 flat; flat 이면 equity 가 변하지 않아 dd 가 해소되지 않음 -> 영구 flat 함정. FULL 시뮬: 2022 -11% 이후 2023~2026 거래 0, CAGR -2.4%.
- 추천 구성(vol cap1.5, K8) @142 USDT min5: CAGR 21.6%, iMDD 27%. BTC/ETH 스킵 시나리오는 -1% (이상치 가능, 미검증).
