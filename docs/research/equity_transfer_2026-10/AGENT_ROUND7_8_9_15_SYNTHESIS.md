# 미장·국장 전용 에이전트 결과 종합

작성일: 2026-10-16 (Asia/Seoul)

## 판정

미장·국장 전용 에이전트의 작업은 **부분 완료**다. Round7은 시장별로 제한된 주식 프록시 강건성 시험을 했지만 코인 전략의 완전한 재현은 아니다. Round8·Round9·Round15는 원본 전략·설정·자료의 재현 가능성 인벤토리만 만들었고, 미장·국장 전략 재평가는 모두 0건이다. 따라서 두 시장 시나리오가 코인 연구의 모든 경우의 수까지 동일하게 재검증됐다고 말할 수 없다.

## 미장 Round7

입력은 로컬 KIS 일봉 패널 54종목이며, 비용은 왕복 적용이 아닌 기존 엔진의 편도 비용 설정 `KIS_0.36pct`와 `low_0.08pct`, 체결은 기존 next-open 엔진이다. 신호는 코인 Round7 거래량 급증 대표를 주식 거래량 빈도에 맞춘 프록시로 사용했다. 코인 전용 심볼 제외 대신 미장 실현손익 상위 기여 종목 5개를 제외했다.

| 비용 케이스 | CAGR | MDD | Sharpe | 거래 수 | 랜덤 대조군 p값(CAGR / Sharpe) | 거래수익률 블록 Sharpe 95% CI |
|---|---:|---:|---:|---:|---:|---:|
| KIS 0.36% | 11.46% | 34.20% | 0.748 | 451 | 0.174 / 0.423 | [-0.495, 4.949] |
| 저비용 0.08% | 16.51% | 33.89% | 1.002 | 451 | 0.106 / 0.455 | [0.373, 5.855] |

비용별 무작위 대조군 500회, leave-out 13회(실현손익 상위 5종목 및 2019–2026년 각 연도 제외), bootstrap 1,000회는 산출물에 기록됐다. bootstrap은 일별 계좌수익률이 아니라 실현 거래수익률을 재표집한 비등가 통계다. 원본 코인의 고정 심볼 제외도 미장 기여종목 제외로 바뀌었다. 미래가격 변조 및 인과적 prefix 검사는 실행되지 않았다.

## 국장 Round7

입력은 로컬 KIS 일봉 패널 64종목이다. 코인 Round7 거래량 급증 전략을 `거래량 / 직전 20거래일 평균 >= 3`, `절대 일간 수익률 < 5%`, 8개 이벤트 슬롯, 20거래일 만기청산으로 근사했다. 이는 원본 champion과 동등 신호가 아니다.

| 항목 | 결과 |
|---|---:|
| CAGR | -4.63% |
| MDD | 33.54% |
| 완료 거래 | 974 |
| 최종 자산(초기자산=1) | 0.686 |
| 빈도 일치 무작위 대조군 | 500회 |
| 심볼·연도 제외 | 14회 |
| 미래변조 및 prefix 재생 | 2회, 모두 통과 |
| 20거래 블록 bootstrap | 미실행 |

KR 엔진이 거래별 수익 원장을 내지 않아 bootstrap을 계산하지 않았다. prefix NAV는 기존 사전계산 슬리피지 벡터를 유지했으므로, 슬리피지의 시점별 재분류까지 검증한 것은 아니다.

## Round8·9·15: 두 시장 공통 미완료

- Round8은 원본 top-10 대표와 `variants()`에서 선언된 151개 조합을 확인했으나, 미장 평가 0개·국장 평가 0개다. 원본 신호·BTC 브레이커/재개 조건·포트폴리오 규칙·체결 의미를 주식에서 동등하게 재현하지 못했다. 시장별 dominator나 조건부 robustness 결과도 없다.
- Round9는 원본 TOP_K12 고정 설정 및 8개 기간 셀을 인벤토리화했으나, 미장 재생 0개·국장 재생 0개다. Round8 산출물에서 TOP_K12 후보의 선정 근거를 확정할 수 없고 BTC 재개 규칙을 주식 규칙으로 바꾸는 것은 동등 재현이 아니다.
- Round15는 239개 고유 가설과 원본 다중검정 요약을 보존했으나, 미장 검정 0개·국장 검정 0개다. 시장별 matched-null 입력 및 원시 300회 대조군 결과가 없어 주식 p-value/BH를 재계산할 수 없다. 코인 p-value를 주식 결과로 재사용하지 않았다.

## 검증 및 환경 문제

- 에이전트 보고 기준 US 산출물은 Python 3.12 문법검사, JSON 수치·표본 재검산, `git diff --check`를 통과했다.
- KR 산출물은 JSON 필드·개수 검산과 소스 `compile()` 문법 검사를 통과했다. 전체 pytest는 Python 경로를 지정한 뒤에도 기존 7개 테스트가 `pandas_ta`/Numba의 `no locator available` import 오류로 수집 단계에서 실패했다. 따라서 전체 회귀 테스트 통과로 표현하지 않는다.
- Round7의 두 시장 프록시 신호, 비용·체결 가정, 통계의 단위가 서로 다르므로 수치를 직접 순위 비교하지 않는다.
