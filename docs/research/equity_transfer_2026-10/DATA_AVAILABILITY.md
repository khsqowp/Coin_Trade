118개 파일 전체에서 timestamp의 시·분이 00:00이 아닌 행은 0개였다. 이는 캐시가 날짜별 OHLCV임을 확인한다. 거래일 사이 달력 간격은 주말·휴장을 포함하므로 시간봉 자료로 오인하지 않는다.

코드에서도 `app/rs_equity_transfer.py`의 `_make_D()`는 `b4`를 빈 맵으로 두며, `evaluate_family_signal()`은 timeframe이 `1d`가 아니면 예외를 던진다. 따라서 현재 데이터 상태에서 등록된 4h 조합 3,171개/시장(총 6,342개)은 실행할 수 없다. 일봉을 4시간으로 분할·복제하거나 변동 경로를 추정해 채우지 않았다. 분봉 세션/시가범위·같은 세션 청산 전략도 이 캐시로는 재현할 수 없다.

이 점검은 이 로컬 캐시의 파일 인벤토리만 증명한다. 외부 공급자가 4h 과거 데이터를 보유하는지, API 자격증명이 있는지, 새 데이터를 취득할 권한·비용은 확인하지 않았다. 향후 원본 공급자의 주식 4h 및 1m OHLCV를 확보하면 파일 무결성·거래일 세션·수정주가 여부를 검증한 뒤 미평가 시간대 그리드를 실행해야 한다.
