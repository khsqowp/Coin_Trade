# 미국주식 S&P 500 시점별 유니버스 자료 경로 검토 — 2026-11-24

## 결론

새로 확인한 FirstRate Data는 2000년 이후 S&P 500의 날짜별 편입·편출 및 공시일·효력일을 제공한다고 안내한다. 미국 유니버스 구성자료의 잠재 경로지만, 무료 데모는 최근 364~365일로 제한되고 전체 가격·이용권·요금이 이번 문서 검토만으로 확정되지 않았다. 실제 자료와 권리를 대조하지 않았으므로 현재 백테스트 입력 승인이나 데이터 게이트 통과로 보지 않는다.

## 확인 내용

- FirstRate Data의 공식 문서는 날짜별 구성종목, 편입·편출 내역, 변경 공시일과 효력일, 종목별 membership history를 제공한다고 설명한다. 제거·상장폐지 종목을 포함한다고 안내하며 전체 범위는 2000년 이후다.
- 공개 브라우저 데모는 구성종목 및 변경 이력에서 최근 364~365일로 제한된다. 종목별 이력 endpoint는 요청당 최대 10년이며, 전체 기록의 저장·보존 형식과 오프라인 연구 이용조건은 별도 확인이 필요하다.
- 해당 페이지는 US Fundamentals Dataset의 전체 이력 일회성 접근 및 업데이트 약 $60/월을 표시하지만, 이 비용이 이 데이터셋에 어떻게 적용되는지와 개인 연구 라이선스 범위는 확인하지 않았다. 가입, 구매, API 호출은 하지 않았다.
- FirstRate Data는 멤버십을 제공하는 경로다. 이를 독립적으로 가격 패널과 결합해야 한다. 기존 HistoricalData.net 감사는 2003-10 이후 일봉 OHLCV·분할/배당 조정 및 상장폐지 기록을 안내하지만, S&P의 당시 구성과 상장폐지 이후 정산을 독자적으로 보증하지 않는다고 기록한다. 둘을 결합해도 종목 식별자 연결, 상폐·합병 대가, 일별 PIT 완전성은 확인 전까지 미해결이다.
- 미국주식 사전등록 `PREREG_US_MACRO_OVERLAY_V1.md`는 SPY 단일 종목 가설이므로, S&P500 PIT 자료를 구해도 미사용 종목군 통과 조건을 대신 충족하지 않는다. 이를 횡단면 전략으로 바꾸려면 별도 가설·격자·시도 등록이 필요하며 기존 등록 결과를 재해석하지 않는다.

## 게이트 판정

| 조건 | 현재 증거 | 상태 |
|---|---|---|
| 날짜별 PIT 구성·공시/효력일 | FirstRate Data 공식 설명만 확인 | 잠재 경로, 실제 범위 미검증 |
| 2018·2022 구성 재현 | 공개 데모 범위가 최근 364~365일 | 공개 자료만으로 미충족 |
| 전체 시점 이력 이용권·보존권 | 개인 연구 및 파일 보관의 구체 조건 미확인 | 미확인 |
| 실행 가능한 가격·기업행위 자료 | 기존 HistoricalData.net 보고서는 별도 가격 공급 경로를 기록 | 별도 구입·커버리지 조정 필요 |
| 상폐·합병 정산, 식별자 연결 | 두 공급자의 조합으로 완전성이 입증되지 않음 | 미확인 |
| 미국 사전등록 G | 현재 SPY 단일 종목 설계는 미사용 종목군 조건을 채울 수 없음 | 실행/승격 불가 |

## 다음에 필요한 구체 증거

1. 구매 전 공개 계약서나 공급자 서면 답변으로 개인 전략연구·로컬 보관·백테스트 결과 이용권, 비용, 일회성 파일 전체 보유 범위를 확인한다.
2. 허용되는 경우에도 날짜별 S&P500 membership 샘플과 가격 공급자 coverage manifest를 구매 전 검토해 2018·2022의 식별자·날짜 범위·상폐 종목 대사 가능성을 입증한다. 무료 공개 데모 범위만 사용한다면 2018/2022를 대체할 수 없다.
3. 원자료를 취득할 권리가 확인된 뒤에만 사용자 저장 규칙에 맞춰 데이터 공급자 파일을 `TRADING_DATA_DIR`에 보존하고, cutoff 전용 사본·해시·기업행위 및 상장폐지 결말 검사를 만든다.
4. 새 전략은 별도 사전등록·고정 시도 장부를 먼저 만든다. 현재 SPY 매크로 등록을 수정하거나 미사용 종목군 기준을 완화하지 않는다.

## 조사 경계

공급자의 공식 공개 웹 문서와 기존 저장소의 HistoricalData.net 데이터 감사만 비교했다. 가격행·샘플파일·API 응답을 열지 않았고, 로그인·키 발급·계약 수락·다운로드·구매·백테스트·공유 사전등록/장부 변경은 하지 않았다. 공급자 설명은 실제 데이터의 커버리지·정확도·권리 검증을 대신하지 않는다.
