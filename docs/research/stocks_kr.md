# 국내주식(KOSPI/KOSDAQ) 포팅 백테스트 — 코인 전략을 일봉으로 이식

코드: app/rs_kr_data.py(로더), rs_kr_engine.py(엔진), rs_kr_strats.py(신호), rs_kr_run.py(실행), rs_kr_stress.py(스트레스).
실행: `python -m app.rs_kr_run <out.json>` / `python -m app.rs_kr_stress <out.json>` (trading/ 에서, 로컬 캐시만, API 호출 없음).

## 1. 데이터
- 로컬 .kis-cache/KR_*.csv 64종목 (일봉 OHLCV). 2018-01-02 ~ 2026-10-02 (약 8.8년, 2015 아님). 56종목 2018 시작, 8종목은 2018-07~2022-01 상장.
- 수정주가: KIS 요청이 FID_ORG_ADJ_PRC=0(수정주가). 삼성전자 액면분할(2018-05) 구간 연속, 일간 |변동| 최대 30% -> 미조정 이상치 없음.
- 결측: 최장 공백 8일(명절). 거래량 0 일수 종목당 0~35일. 지수(KOSPI200/KODEX200) 시계열은 로컬에 없음 -> 균등가중 유니버스를 시장 프록시로 사용.
- 점시점 유니버스: 최근 60일 거래대금 중앙값 >= 10억원 & 상장 30봉 이상일 때만 편입. 거래량 0/전일대비 시가 +-29% 이상 점프일은 체결 불가 처리.
- 생존편향: 64종목은 "오늘 유동성 좋은 종목"(SK하이닉스, 한화에어로 등 사후 승자 다수). 상장폐지/탈락 종목 없음 -> 모든 수익률은 상향 편향.

## 2. 체결/비용 가정
- 신호 = 종가 t, 체결 = 시가 t+1. 수수료 0.015%/편도, 매도세 0.18%, 슬리피지 대형(거래대금 500억+) 0.05% / 그 외 0.10%/편도.
- 공매도(이론용) 대차수수료 연 3% 가정. 평가기간 2018-11-01~2026-10-02(SMA200 워밍업 후), 별도 2022-01~.
- WF: IS=앞 60%(~2023-07), OOS=뒤 40%, 폴드 3개(2018-11~21-06 / ~24-02 / ~26-10).
- 미래참조 테스트: 컷 이후 가격을 +-50% 교란해도 이전 자산곡선 최대차 0.0 (비중형/이벤트형 모두 통과).

## 5. 생존편향/승자 의존 스트레스 (rs_kr_stress.py)
사후 최고수익 상위 종목을 빼면(균등가중 연수익 20% -> 16% -> 13%):
| | 전체 | 상위5 제거 | 상위10 제거 |
|---|---|---|---|
| 60/3/21+필터 | 64%/36 | 29%/62 | 17%/59 |
| 60/5/21+필터 | 49%/31 | 17%/59 | 17%/40 |
| 120/5/21 급락 | 58%/38 | 42%/35 | 20%/44 |
| 60/5/21 필터없음 | 48%/50 | 20%/47 | 14%/46 |
| 14/5/3 필터없음 | 10%/55 | 4%/66 | -1%/65 |
무작위 50% 부분유니버스 30회: 60/5/21 계열이 균등가중을 이긴 비율 87~93%(초과 중앙 +7~12%p, 낙폭은 40~48%). 14/5/3 계열은 7~10%만 이김(초과 -5~-7%p).
-> 중기(60~120일) 모멘텀의 우위는 부분적으로 실재하나, 수익 대부분은 소수 승자(SK하이닉스, 한화에어로, 두산에너빌 등 10종목)와 2023/2025/2026 상승장에 의존.
