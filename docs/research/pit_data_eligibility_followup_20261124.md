# 주식 PIT·상장폐지 데이터 경로 재확인 — 2026-11-24

## 결론

공식 공급 경로는 발견했지만, 현재 보유한 한국·미국 데이터가 연구용으로 적격하다는 증거는 아니다. 구매·계정 생성·문의 메시지는 보내지 않았다. 가격, 샘플, 이용권한, 상장폐지 커버리지 확인 전에는 전략 성과 탐색이나 최종 검증에 사용하지 않는다.

## 한국: KRX

- KRX OPEN API 서비스 목록은 2010년 이후 데이터를 제공한다고 명시하고, 유가증권·코스닥 일별매매정보와 ETF 일별매매정보를 제공 항목으로 나열한다. 다만 페이지의 설명만으로 과거 상장폐지 종목의 전체 가격 이력 제공 여부와 재사용 권한을 확인할 수 없다. [KRX OPEN API 서비스 목록](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd)
- KRX 지수정보상품 소개는 종가기준·익일기준 구성종목 파일과 지수조치(Corporate Action) 파일을 제공 항목으로 설명한다. 구성 파일 설명에는 지수 구성종목·가격·편입비중 등이 포함된다. 이는 과거 지수 구성의 PIT 근거가 될 가능성이 있지만, 실제 제공 기간·일자별 보존범위·개별 상폐가격 포함 여부는 이 설명만으로 확인되지 않는다. 안내된 문의처는 KRX 인덱스사업팀이다. [KRX 지수 라이선스·정보상품 안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA005.jsp)
- KRX Data Marketplace 구매안내는 상품별 기본사양·제공기간·항목·샘플·가격을 상세 화면에서 확인하고, 결제와 이용목적 심사를 거쳐 자료를 받는다고 설명한다. 이 경로는 공개 가격을 확인하지 못한 상태에서 상품 사양과 견적 범위를 확인할 다음 공식 경로다. 로그인이나 구매를 진행하지 않았다. [KRX 데이터 구입안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA001.jsp)
- 후속 공개 조회에서 KRX 데이터 상품 목록은 지수구성종목 통계 화면과 데이터 구입 메뉴를 노출했고, KRX 지수정보상품 안내에는 종가지수·구성종목·지수조치(Corporate Action) 파일의 항목 설명이 확인됐다. 그러나 상품 상세의 샘플·가격·기간은 브라우저 수집에서 확인되지 않았다. 데이터마켓 상품 목록 URL은 내부 오류, KRX 영문 상세는 HTTP 403으로 열리지 않았다. 인증·로그인 우회나 구매는 시도하지 않았다. [KRX Data Marketplace](https://data.krx.co.kr/?scrnId=02080803), [KRX 지수 정보상품](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA005.jsp)
- KRX OPEN API의 지수 시세 서비스 화면에는 샘플 테스트 기능이 표시되지만, 요청에는 인증키가 필요하고 실제 샘플 응답은 확인하지 않았다. 서비스 목록이 제시하는 2010년 이후 범위는 지수·주식 일별 API의 설명이며, 이것만으로 일별 과거 지수 구성이나 상장폐지 종목의 가격·정산 이력까지 제공된다고 볼 수 없다. [KRX 지수 API 설명](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES001_S2.cmd?BO_ID=SsgXTEspyJESKvyXZtCU), [KRX API 서비스 목록](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd)
- 기존 로컬 파일의 헤더만 읽었다. `equity_membership_kr.csv`는 `market,symbol,alive_from,alive_through,source,source_asof,status` 열이고, `current_listing_for_membership.csv`는 `market,symbol,listing_date,source` 열뿐이다. 후자는 현재 상장 종목의 상장일 목록으로 보이며 상장폐지 시점·역사적 유니버스 포함을 증명하지 않는다. 행 데이터는 이번에 열지 않았다.

## 미국: CRSP / WRDS

- CRSP US Stock Databases 공식 안내는 36,000개가 넘는 현·비활성 미국 증권에 대해 일·월 시장 데이터와 기업행위를 제공하고, PERMNO/PERMCO 영구 식별자를 통한 시계열 연결을 설명한다. 이 범위는 미국 연구의 핵심 PIT·상폐 요구와 맞을 가능성이 높지만, 현재 계약별 보유기간·상세 항목·가격·개인 연구 사용권은 확인되지 않았다. CRSP 제품 페이지는 구독정보 요청을 안내한다. [CRSP US Stock Databases](https://indexes.morningstar.com/research-data-products/crsp-us-stock-databases)
- WRDS의 CRSP 월간 파일 데모 설명에는 가격·거래량, 상장폐지 정보, 배당·분할·특별배분 이력이 열거되어 있다. 이는 필드 존재의 근거이지, 데모가 전체 과거 가격 표본을 무료 제공한다거나 사용자 계정으로 연구에 이용할 수 있다는 증거는 아니다. [WRDS CRSP 데이터 데모 설명](https://wrds-www.wharton.upenn.edu/demo/crsp/form/)
- 공식 제품 안내상 구독·가격 문의가 필요하다. 계정 생성·가입·자료 다운로드·문의 메시지는 수행하지 않았다.

## 실행 전 데이터 적격성 게이트

다음 항목을 공급자 문서·샘플·견적으로 확인하고, 결과를 로컬 입력 데이터의 행 수·기간·체크섬과 대조해야 한다.

1. 2010년 이후 또는 필요한 기간에 상폐·합병·이전 종목이 포함되는가.
2. 과거 날짜 기준 지수/종목 유니버스와 편입·편출 효력일을 복원할 수 있는가.
3. 종목 식별자가 변경·재사용되어도 연속적으로 연결되는가.
4. 일봉 가격에 분할·배당·기타 기업행위가 어떤 방식으로 반영되는가.
5. 개인 연구·백테스트·저장·파생 통계 목적의 권한과 재배포 제한은 무엇인가.
6. 샘플에서 필요한 기간의 상폐 종목 종가·정산/상폐 수익률과 구성종목 변경을 실제로 검증할 수 있는가.

## 판정

- KRX: 공식 데이터 상품·2010년 이후 일별 API·지수 구성/조치 파일 설명은 확인. 상품 상세 샘플·가격은 공개 조회에서 확인되지 않았고, 인증키 없는 API 응답도 확인하지 않았다. 무료 여부, 과거 전체 PIT 범위, 상폐가격, 연구 목적 권한, 실제 견적은 확인 안 됨.
- CRSP: 역사적 현·비활성 종목과 일·월 자료가 있는 공식 구독 상품은 확인. 현재 견적·개인 라이선스·샘플 접근 가능 여부는 확인 안 됨.
- 따라서 국장·미장 R4/R5 실데이터 전략 결과는 이 조사만으로 승인되지 않는다. 구매 승인 없이 다음 단계는 공식 공개 사양과 상품 상세에서 샘플·가격·이용권한을 확인하는 범위다.
