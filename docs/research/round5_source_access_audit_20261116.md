# Round 5 — 주식 데이터 접근 및 문헌 복제 게이트 (2026-11-16)

## 범위와 판정

이번 단계는 공개된 1차 자료와 공급자 공식 문서만 검토했다. 로컬 가격·회계 데이터, 계정, API 키, 결제, 공급자 연락, 신규 실시간 수집, 성과 백테스트는 사용하지 않았다. 코인 주 기준은 Round 0 헌장과 사용자 확정 답변에 따라 **목표 선도달률 ≥80%**이며, 만기 방향 정확도는 별도 지표다. 이 정의는 이미 헌장에 반영되어 있어 재변경하지 않는다.

**결론:** KR·US 주식 전략의 성과시험은 데이터 적격성 NO-GO다. 공개 문서만으로 원 논문의 성과를 우리 순비용 포트폴리오 규칙으로 재현하거나 사용자 기준을 판정할 수 없다. 다음으로 진행 가능한 일은 무료로 열람되는 문헌 정의와 공식 제공자료 명세를 더 좁히는 것이며, 계정·구매·외부문의는 별도 승인이 필요하다.

## 문헌 후보 복제 가능성

### 한국 순외부자금조달

Lee와 Hwang의 2025 논문은 1994–2023년 KOSPI·KOSDAQ 비금융 기업을 사용하고 DataGuide·TS2000의 재무제표, DataGuide 주가자료를 사용했다고 공개한다. 순외부자금조달은 현금흐름표의 주식·부채 순조달을 평균 총자산으로 나눈다. 저자들은 최저 조달 10분위 매수·최고 조달 10분위 매도 헤지 포트폴리오의 연평균 약 12%와 t=3.11을 보고했다. 이는 저자 표본의 논문 결과이며 연복리 포트폴리오 CAGR, 거래비용 차감 결과, 우리 OOS 기준의 합격 증거가 아니다. [원문 및 변수 정의](https://www.mdpi.com/1911-8074/18/12/693)

주식 조달 변수의 현금흐름 구성은 공개됐으나, 재무자료가 투자시점에 공개·수정된 시각에 대한 PIT 빈티지, 종목별 상장 폐지까지 포함한 매수·매도 체결가능 수익, 공매도 대차 가능성과 비용, 정확한 리밸런싱 달력 및 포트폴리오 가중 계약은 우리 쪽에서 검증되지 않았다. 2025 논문 수치를 실전 목표와 직접 비교하지 않는다. FnGuide/TS2000 자료의 권리·가격 미확정도 별도 차단 사유다.

### 미국 순주식발행

Pontiff와 Woodgate(2008)는 1970년 이후 주식발행이 미국 주식의 횡단면 미래수익률 예측력을 보인다고 보고한다. 공개 초록만으로 에이전트가 제안한 월간 리밸런싱 규칙, 분할조정 주식수의 PIT 공개시점, 포트폴리오 수익 산식·비용을 완전히 재구성할 수 없다. 따라서 월간 저발행 롱/고발행 숏은 아직 등록 후보가 아니다. [Journal of Finance 논문 페이지](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1540-6261.2008.01335.x)

## 진행 결정

1. 한국 API 공개 일별 시세만으로 장기 순외부자금조달 전략의 완전한 시험이 가능한 것처럼 취급하지 않는다. API 기간이 2010년 이후로 제한되고 PIT 회계·기업행동·상장폐지 수익·권리 필드가 미검증이다.
2. CRSP는 데이터 구조 면에서 US 기본 가격 소스로 우선 검토할 가치가 있지만, 샘플은 25개 이슈·2019년까지의 내부 평가용 스냅샷이라는 제한이 있다. 본시험 데이터나 대표성 검증 데이터로 사용하지 않는다.
3. 공급자별 원자료 권리, 필드, 보관/파생물 조건, 가격, PIT 공시 시점이 확인되기 전에는 확인적 백테스트를 실행하지 않는다. 공개 논문 재서술이나 기존 노출 캐시로 수치를 만들지 않는다.
4. 코인 목표 선도달률 기준은 별도 고정되어 있으며, 이번 주식 데이터 조사 결과가 코인 OOS 성과 주장에 영향을 주지 않는다.
