# KR 공개 일봉 데이터 경로 감사 (2026-11-07)

## 판정

이번 조사에서 기존 KRX/FSC 공공데이터 API 외에 **무료 공개 접근과 개인 백테스트 재사용권, PIT 상장·폐지 유니버스, 기업행위 조정, 거래 가능한 가격, 원천 이력**을 함께 입증하는 국내 주식·ETF 일봉 데이터 경로는 확인하지 못했다. 가격 파일은 내려받지 않았고, 가격값 열람·백테스트·원격 서버 접속은 하지 않았다.

## 1차 출처 및 확인 근거

1. [Machine Learner 데이터 다운로드](https://www.ai-stock.co.kr/downloads.html): 2000년~현재, 3,048종목 CSV 설명 및 페이지의 All rights reserved 표기.
2. [Machine Learner KRX OHLCV 설명](https://www.ai-stock.co.kr/krx-ohlcv.html): 일간 OHLCV·시가총액·발행주식수 및 “AI 주식투자 분석 및 머신러닝 학습” 용도 설명. 출처·라이선스·상폐/PIT·기업행위 조정은 설명하지 않는다.
3. [서울대 S-Space 검색 결과](https://s-space.snu.ac.kr/bitstream/10371/176090/1/000000165345.pdf): 검색 인덱스는 FnGuide DataGuide 기반 상장·상폐 표본을 언급했지만, 브라우저에서 열린 PDF는 그 설명과 무관한 문서로 확인됐다. 따라서 검증된 연구 자료나 공개 가격 파일의 존재 증거로 사용하지 않았다.
4. [KRX Data Marketplace 홈페이지 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd): 사이트 정보의 복사·복제·배포·전송·공중송신은 KRX의 사전 허락 없이 금지된다고 명시한다.
5. [KRX 데이터 수신방법](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp): 개인의 단순 참고 목적 이외 이용은 별도 계약이 필요할 수 있다고 안내한다.
6. [Hugging Face aikstockdata 데이터 카드](https://huggingface.co/datasets/aikstockdata/korea-equity-daily): FSC 공공데이터 원천과 공공누리 제4유형 조건을 다시 적용한다고 스스로 명시하며, 현행 종목만 공개하고 누락·상폐 종목은 제거한다고 안내한다.
7. [FSC/공공데이터포털 증권상품 시세 API 메타데이터](https://www.data.go.kr/data/15094806/openapi.do): ETF·ETN·ELW 시세 데이터가 Type 4이고 제3자 권리/무단 재배포 제한을 표시한다. 이 경로도 새 권리 허가가 아니다.

### 후속 1차 출처

1. [PyKRX 소스 함수 문서·구현](https://github.com/sharebook-kr/pykrx/blob/master/pykrx/stock/stock_api.py): `adjusted=True`는 `naver.get_market_ohlcv_by_date(...)`, `False`는 `krx.get_market_ohlcv_by_date(...)`를 호출한다.

5. [공개 KRX JSON/PyKRX 데이터 저장소 README](https://github.com/ChaneHaDa/krx-json-data): KRX 원천과 pykrx/Naver 조정 Parquet를 구분하고, 새 수집에 API_KEY를 요구하며, 3회 실패 시 종목을 유니버스에서 retire한다고 명시한다. 재사용 허가 문서는 확인되지 않았다.
6. [HANARO ETF 개별 상품 페이지 예시](https://www.hanaroetf.com/fund/D5AF92D8402E46E2): 날짜별 시장 종가와 ETF 기준가격을 각각 제공하고 엑셀 다운로드 UI가 있음을 확인했다. 이는 데이터 이용권 또는 전 ETF PIT 보장을 의미하지 않는다.
7. [KRX Data Marketplace 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd): 거래소 사이트 정보는 사전 허락 없는 복제·전송·배포가 제한된다.

**최종 판정:** 이번 후속 탐색에서도 무료로 접근 가능해 보이는 수정가·ETF 파일은 발견했으나, 계정·약관 수락 없이 자동 취득할 수 있고 파생 백테스트 권리, 상폐 포함 시점별 유니버스, corporate action 정합성 및 원시 체결가/정정 이력을 함께 입증하는 소스는 없다. 기존 백테스트 데이터 게이트를 낮추지 않는다.

### 신규로 발견한 공개 저장소

`FinanceData/fdr_krx_data_cache`는 KRX STAT/KIND 수집 결과를 CSV로 Git에 보관하는 공개 저장소다. 저장소 README에는 KRX·KOSDAQ 상장 종목 시세, 상장폐지 종목 목록, 지수, 기업 설명, 지수 구성종목 스냅샷이 기록돼 있다. 공개 저장소이므로 파일 경로와 버전 이력은 무로그인으로 열람할 수 있어 보이는 별도 아카이브 경로다. 다만, README의 자동 수집 비밀값은 `KRX_ID`와 `KRX_PW`이며, 이는 무키·무계정 원천이 아니다. 본 조사에서는 저장소 데이터 파일·가격값은 열지 않았다.

| 게이트 | 근거 및 판정 |
|---|---|
| 무키/무계정 | 미통과. 저장소 README가 수집을 위해 KRX ID/PW를 GitHub Secrets에 설정하도록 요구한다. 공개 복제본을 읽는 일과 적법한 원천 수집 권한은 별개다. |
| 무료 접근 | 공개 GitHub 복제본 자체는 무료 접근 가능. 단, 저장소 공개는 KRX 데이터 재사용권을 부여하지 않는다. |
| 데이터 재사용/파생 백테스트 | 미통과. 저장소 루트에 데이터 라이선스가 표시되지 않는다. 원천은 KRX STAT/KIND이며 KRX 공식 마켓데이터 사용 약관 범위가 따로 적용된다. |
| 상폐/PIT | 상폐 목록과 지수구성 스냅샷 경로가 존재하지만, 상폐 종목의 전체 일별 가격 시계열을 보장한다는 설명은 없다. 스냅샷/커밋 이력은 날짜별 멤버십의 완전성을 입증하지 않는다. |
| 기업행위·조정·정정 | README는 일별 원시 시세 및 기업 상세를 언급하지만 수정가격/배당 총수익 산식·action ledger·정정 빈티지 정책을 명시하지 않는다. 성과 테스트 입력으로 불충분하다. |
| 실행 가능 가격·달력 | KRX 시세 수집 저장소라는 설명은 있으나, 모든 날/종목의 raw OHLCV coverage, 거래정지·정리매매·상장폐지 시점 가격 완전성은 확인되지 않았다. |
| 백테스트 사용 판정 | 후보 출처로 기록하되, 현재는 법적 권리·PIT·기업행위 게이트 미통과. 내려받거나 가격값을 사용하지 않는다. |

### 공식 공공 API 재확인

공공데이터포털의 금융위원회 주식시세정보는 별도 KRX OPEN API 화면과 다른 접점이지만, 공식 카탈로그에서 KRX 원천 연계, 이용신청/인증키, 공공누리 제4유형 조건을 확인했다. 제4유형은 출처표시·비상업적 이용·변경금지이고, 제3자 무단 제공·재배포를 금지한다. 따라서 “공개 웹사이트/API에서 무료로 조회된다”만으로 전략 규칙 적용·조정·파생 성과 검정에 쓸 수 있다고 단정할 수 없다. KRX Open API 공식 서비스도 데이터 수신방법에 인증키 신청 절차가 있고, 상장 주식·ETF 일별 데이터의 시작 범위를 2010년으로 안내한다. 계정·키를 새로 만들거나 기존 보유 자격증명을 사용하지 않았다.

### 학술·공공 리포지터리 교차 탐색

Zenodo, Figshare, OSF, Harvard Dataverse, 국내 대학 저장소를 대상으로 KOSPI/KOSDAQ 개별주식 일별 파일, 상폐 종목 및 재사용 라이선스를 조합해 검색했다. 확인 가능한 학술 연구는 한국 전체 또는 상폐 포함 표본을 사용한다고 쓰더라도 원시 일별 가격 파일을 공개하지 않거나, DataGuide/FnGuide/Compustat 등 공급자 데이터에 의존하는 경우가 있었다. 이 검색에서 원 데이터의 공개 다운로드, 명시적 재사용권, 상폐/PIT 명부, 조정 이력까지 모두 검증할 수 있는 저장소는 확인하지 못했다. 검색 결과만으로 부재를 절대 증명할 수는 없지만, 현재 발견 후보는 연구 백테스트 게이트에 제출할 만큼의 증거가 없다.

**이번 라운드 결론:** 공개 Git 저장소로 캐시된 가격 파일이라는 새 후보는 발견했지만, 수집은 계정 비밀값을 요구하고 원천 데이터 라이선스가 없으며, 상장폐지 목록이 PIT 일별 가격 패널을 뜻하지 않는다. 공공 API는 신청/키와 Type 4 권리 제한이 남는다. 가격 다운로드·값 열람·백테스트 없이 모두 차단 판정으로 기록한다.
