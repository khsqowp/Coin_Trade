# Preregistration v6 amendment: undefined bootstrap replicates

> Read v2–v6 as a version chain. v6 supersedes v5 only for undefined-replicate handling; all other v5 rules remain frozen. This amendment is before all outcome scoring. No strategy outcome has been inspected or calculated.

- Frozen: 2026-11-20.
- A replicate is **not redrawn** for any reason. It is defined separately for each metric/contrast by the denominator rule below.
- For absolute candidate M2 at a horizon, a replicate is undefined only when the resampled date sequence contains zero candidate events at that horizon.
- For each candidate-versus-direction-baseline contrast, the resampled paired denominator is the number of candidate treatment anchors present in the sampled dates. Baseline abstentions, invalid entries, gaps, and non-target-first results remain paired misses. The replicate is undefined only when that paired denominator is zero; the candidate and baseline therefore cannot have different paired denominators.
- For each CVD-versus-price-only contrast, the replicate is undefined if either arm has zero issued events for that horizon in the resampled dates. Do not create synthetic events or substitute a zero M2 for an empty arm.
- For each metric/contrast, report `defined_replicates`, `undefined_replicates`, and the exact denominator for every defined replicate or a hash-verified denominator vector. If undefined replicates exceed 1% of the fixed 10,000 draws, mark that metric/contrast NOT EVALUABLE and do not calculate its interval. Otherwise calculate the specified quantiles from only the defined replicates, without redrawing or changing the denominator rule. Any NOT EVALUABLE one of the fixed 10 contrasts blocks the joint decision; do not reduce multiplicity family size.
- Four-role approval and pre-outcome data/funding audit gates remain mandatory. All results remain exploratory due prior historical exposure.
- **Funding timestamp-audit acceptance scope:** before scoring, cross-check the complete frozen 36-symbol cohort against the official read-only USD-M funding history endpoint on each fixed UTC date `2023-03-24`, `2024-03-24`, and `2025-02-28`. Require HTTP 200, identical daily timestamp sets, and exact Decimal-equal rates for every returned/archive row; retain SHA-256 of each raw REST body. Any mismatch or unavailable response blocks funding-adjusted scoring until resolved. This is a sample semantic check, not a proof of every historical row; state that limitation. A restricted price-path-only exploratory run may be allowed only if all four reviewers explicitly approve it, with net expectancy NOT EVALUABLE and no candidate gate or advancement decision.
