## 1. 변동성 단위 (진입일 종가까지의 정보만 사용, 진입 시점 고정)
- ATR: 일봉 TR(고저/전일종가) 14일 단순평균 / 진입일 종가 (비율). 
- RV: 일 로그수익 14일 표준편차 sigma_d, 이동 크기 = k * sigma_d * sqrt(3).
- 유리한 이동(excursion) = 롱 H/진입가-1, 숏 1-L/진입가 (진입가=최초 진입가; 물타기/재배치로 평균가가 바뀌어도 기준점은 고정).

## 3. 체결/비용
- 기본 체결: 시간봉 H/L 가 임계를 터치하면 임계가에 체결, 불리한 방향 슬리피지 0.05% + 수수료 0.10%.
- 대안: 'next-bar-open' = 터치한 봉의 종가(패널에 open 없음; 다음봉 시가≈직전봉 종가)에 체결 + 동일 슬리피지/수수료.
- 트레일링은 같은 봉 안에서 고점 갱신 후 저점 터치를 허용(보수적).
- 비용 민감도: base / 2x (수수료 0.20% + 익절 슬리피지 0.10%, V0도 동일 2x) / 펀딩 스트레스(펀딩 x3 + 양방향 보유자 추가 1bp/일 명목).
- 익절 청산 시 펀딩은 청산 시각까지 8시간 정산 횟수 비율로 안분.

## 4. 분할/검증
- IS 2022-01-01..2024-06-30 (선택은 IS만), OOS 2024-07-01..말.
- 선택 기준(사전): IS 에서 위상평균 Sharpe 개선(변형-V0) 최대 설정 1개(회계별).
- CPCV: 전체 일자열을 N=6 연속 그룹, 검증 2그룹 조합 C(6,2)=15 분할 -> 경로 5개; 훈련에서 검증 경계 전후 20일(>= lookback14+rebal3) purge/embargo. 설정 13열(V0 + 12) 행렬로 PBO(CSCV 로짓 방식, 훈련 Sharpe 최고의 검증 상대순위) 와 선택 설정의 경로별 OOS Sharpe 분포 보고. PBO 통과 기준 <= 0.30.
- 위상 0,1,2 전부 실행. 위상별 지표의 평균/최악 보고. 부트스트랩/CPCV/DSR 은 3위상 일수익 평균(3 sleeve 평균) 시계열 사용, 위상별 부트스트랩 CI 도 보조 보고.
- 이웃 강건성: 선택 설정과 모든 설정의 각 파라미터 x0.75, x1.25 (축별, 트레일링은 a,b 각각). 고원만 인정.
- 블록 부트스트랩: 블록 15일(민감도 10, 20), 1000+ 재표본, 변형-V0 Sharpe 차 및 Calmar 차의 90% CI(5%~95%).
- DSR (Bailey-Lopez de Prado): 설정 간 일 Sharpe 분산으로 SR0, 왜도/첨도 반영, 기준 0.95. 절대 SR 의 DSR 과 '차이 시계열(변형-V0)'의 DSR 둘 다 보고하되 판정은 차이 시계열 기준.
- 지표: Sharpe(일수익, sqrt365), CAGR, 종가 MDD, Calmar=CAGR/종가MDD, 일중 MDD(엔진 규약), 최악일, 왜도, 첨도, 노출, kill 횟수.
- 익절 품질 진단: 발동률(포지션당, 연당), 청산 후 +1/+3/+7일 포지션 방향 순수익률(청산가 기준, 변동성 단위 정규화 병기), '계속 갔나' 비율.
- 거래 단위 꼬리 분석: 거래(진입~완전청산) 순손익/진입시 자산 기준 상위 1%/5% 거래의 총손익 기여, 거래 왜도, 승률, 손익비(payoff).
