## 2. 사전등록 격자 (12 설정, 추가 없음)

단위: ATR = 진입일까지 14일 일봉 ATR/종가. 유리이동 = 최초 진입가 대비 시간봉 H(롱)/L(숏).
| 종류 | 설정 |
|---|---|
| TP 전량 at k*ATR | T_atr2, T_atr3, T_atr5, T_atr8 (k=2,3,5,8) |
| TP at k*sigma_d*sqrt3 | T_rv3 (k=3) |
| 트레일링(활성 a*ATR, 고점대비 b*ATR 반납) | R_4_2, R_6_2, R_6_3, R_8_3 |
| scale-out(유리이동 s*ATR 에 50% 청산, 잔량 유지) | S_4, S_6, S_8 |
회계: C=청산분 다음 리밸런스까지 현금(정상 선정되면 재진입), D=같은 방향 잔존 포지션에 비례 재투입. 시행 수 = 12 x 2 x 2(총노출) = **48**; 이웃 28 포함 시 76. 체결: 임계 체결 + 슬리피지 0.05% + 수수료 0.10% (대안: 터치한 봉 종가 = next-bar 근사, 2x 비용, 펀딩 스트레스). IS 2022-01~2024-06, OOS 2024-07~2026-10-09. 위상 0,1,2.

## 3. 핵심 결과 요약 (전체 표는 4절 이후 tables.md 내용 그대로)

1. **IS 에서는 좋아 보이고 OOS 에서는 전부 나쁘다.** 회계 C: 12설정 평균 dSharpe IS +0.126(양 10/12), OOS -0.619(양 0/12). 회계 D: IS +0.187(11/12), OOS -0.561(1/12). 총노출 lev2 보조도 C 에서 OOS 12/12 음(D 에서만 T_atr8 +0.18, S_8 +0.05). IS 는 2022~2024H1(하락/횡보 중심), OOS 는 2024H2 이후 큰 추세 구간으로, 익절이 우측 꼬리를 잘라 큰 추세 수익을 포기하는 것과 합치(가설이며 인과 검증은 아님).
2. **타이트할수록 해롭다**: k=2 ATR 은 거래의 23.7% 에서 발동, OOS CAGR -47%(전구간 Sharpe 0.32, MDD 85%). 트레일링 R_4_2 는 휩쏘로 전구간 Sharpe 0.44. 느슨한 k=8/scale 8 은 V0 에 수렴(발동 2.5~2.7%/거래)하여 차이가 0 에 가깝다 -> 개선이 아니라 "아무것도 안 하기"에 근접.
3. **꼬리**(T9): V0 는 상위 1% 거래가 총이익의 24.3%, 상위 5% 가 48.1%, 거래 왜도 6.76, 손익비 1.33. T_atr2 는 6.3%/24.9%, 왜도 -0.59, 손익비 1.06, 승률 46.2->49.1%(승률 상승 + 손익비 하락 = 우측 꼬리 절단). T_atr3 도 왜도 -0.04. 느슨한 S_8/T_atr8 은 꼬리를 대부분 보존(18.2%/15.6%, 왜도 3.05/1.85)하나 Sharpe/Calmar 개선은 없음.
4. **익절 품질 진단**(T8): 청산된 포지션은 청산 후에도 같은 방향으로 계속 갔다. 청산 후 +1/+3/+7일 포지션방향 수익률이 같은 날 같은 방향 V0 보유 포지션 평균보다 **+0.4~+5.3%p 높음**(t≈1~5; T_atr2 +3일 +0.89%p t=4.8, T_atr5 +7일 +2.9%p t=4.0, T_atr8 +7일 +5.3%p t=4.0). 단 계속상승 비율(>0)은 38~52%로 평균은 우측 꼬리가 만든다. 즉 익절은 평균적으로 "더 갈 놈"을 내렸다는 진단으로, 포트폴리오 PnL 결과와 독립적으로 일치.
5. **우연히 양인 곳은 잡음 범위**: T_atr8 은 C 전구간 +0.06, D(재투입) 에서 IS +0.30/OOS +0.08/전구간 +0.20(3위상 모두 양)이나 부트스트랩 CI [-0.15,+0.65](0 포함), 2x 비용에서 -0.25, 이웃 k=6 은 OOS -0.61/k=10 은 +0.35 로 비단조(잡음 바닥 0.06~0.18 과 같은 규모). D 의 IS 선택은 T_rv3(전구간 -0.21)이므로 선택 규칙상 채택 불가. T_atr8-D 는 사후 관찰로 exploratory.
6. **펀딩 스트레스**(펀딩x3 + 추가 1bp/일): V0 Sharpe 0.70 으로 하락. 이때 T_atr8 +0.48, S_8 +0.44, T_rv3 +0.32, R_8_3 +0.29 로 상대 우위가 생기는데, 이는 노출 감소(현금 비중)로 펀딩 부담이 줄어든 효과이며 알파가 아니다. 판정 기준 아님.
7. **CPCV 한계**: 설정을 고정(재학습 없음)하면 5개 경로가 동일 일자 집합이라 경로별 Sharpe 가 동일 -> 경로 분포로는 정보 없음(prereg 기준 3은 실질적으로 전구간 부호와 동일). 대신 15개 검증 분할: S_8 은 양 10/15(평균 -0.04, 중앙 +0.18, 최소 -0.74), 모든 설정에서 최악 분할이 -0.45~-2.0 로 최선 분할(+0.04~+0.80)보다 크다. CV 에서 훈련 Sharpe 로 고르는 절차(경로 5개)의 검증 Sharpe 0.74~0.94 < V0 1.10 (5/5 경로에서 V0 열세), PBO 0.80.

## 5. 이 결론을 바꿀 증거 (what would change my mind)
- 사전등록된 새 격자가 서로 다른 레짐(예: 다른 거래소/종목군, 2018~2021 데이터, 비생존 유니버스)에서 IS·OOS 구분 없이 dSharpe>0, 부트스트랩 CI 하한>0, 2x 비용 생존으로 반복될 것. 특히 k>=8~10 ATR 같은 아주 느슨한 영역에서의 소폭 이득이 라이브 규모 슬리피지에서도 유지된다는 증거.
- 목적이 수익이 아니라 "위험 축소"라면 (예: 펀딩 스트레스, 꼬리 손실 상한) 별도 목적함수·별도 사전등록으로 평가해야 함 (여기서는 Sharpe/Calmar 개선만 기준).
- 실제 라이브에서 시간봉 이하 해상도 체결 데이터 (open/틱)로 next-bar 체결 비용을 실측해 본 결과가 시간봉 근사와 크게 다를 경우.

## 6. 한계
- 시간봉 H/L 만 있고 open/틱 없음: 임계 체결 가정(갭 미반영), next-bar 는 봉 종가로 근사. 트레일링은 같은 봉에서 고점 후 저점 순서를 보수적으로 가정. 슬리피지 0.05% 고정은 소형 알트 급락일에 낙관적일 수 있음.
- 45종목 현재 상장 생존 유니버스, 2022 초에는 28종목, 단일 표본 약 4.8년, 2024 한 해의 기여가 큼.
- V0(3.8x)는 kill 연 ~2회 + 14일 쿨다운의 경로 의존이 강해 dSharpe 의 잡음 바닥이 ~0.06(sd)~0.18(최대). 이보다 작은 차이는 해석 불가. 위상은 3개뿐.
- 부트스트랩은 3위상 평균(sleeve) 일수익 기준이며 블록 15일(10/20 민감도). 일수익 자기상관이 블록보다 길면 CI 가 좁게 나올 수 있으나 이미 모든 CI 가 0 을 포함.
- DSR 시행 수는 사전 등록 48 기준이며 연구 전체(선행 연구 수천 건)의 탐색은 포함하지 않았으므로 오히려 낙관적이다.
- 회계 D(재투입)는 같은 방향 잔존 포지션에만 종가 근사 가격으로 추가 매수하는 단순 모델.
- 익절 후 재진입 정책은 "다음 정기 리밸런스에서 정상 규칙대로"이며 재진입 금지 변형은 미검증(exploratory 로도 실행하지 않음).
- 거래 단위 꼬리 통계는 3위상 합산 거래(위상 간 중복 보유 포함)로 독립 표본이 아니다.
