- **DSR/PBO/부트스트랩 구현**(A 코드 직접 검토): DSR 식(skew, 비초과 kurtosis, SR0 기대최댓값)은 맞다. PBO(CSCV S=10, 252분할, 로짓 순위)도 맞다. 그러나 (a) 절대 Sharpe DSR 은 V0 자체도 통과해 변별력이 낮다(T09 N12 DSR 0.98 이지만 V0 비교가 핵심; B의 차이시계열 DSR 이 옳은 접근), (b) 블록 부트스트랩은 한 경로만 재표본하므로 킬 카오스 분산(별개 원천)을 포착하지 못한다.

- **최소검출효과(MDE)**: 내 쌍체 블록부트스트랩(15일 블록, 2000회)으로 T09-V0 dSharpe 점추정 +0.29, **SE 0.20**, 90% CI [-0.02, +0.62] → 80% 검정력/5% 양측 MDE ≈ **0.56 Sharpe**. B의 CI(S_8 반폭 0.51 → SE 0.31)로는 MDE ≈ 0.9. V0 Sharpe 가 1.1 이므로 **±0.5~0.9 미만의 개선/악화는 4.8년 한 경로로 구별 불가.** 또 킬 임계 ±0.02 만 바꿔도 dSharpe(T09-V0)가 +0.25 / +0.29 / -0.20 으로 요동(경로 카오스에 의한 '차이의 잡음' sd ~0.25) → B가 잰 V0 수준 잡음(sd 0.063, 최대 0.178)은 **차이 지표의 잡음을 과소평가**한다. 결론: 세 팀의 'noise'는 "효과 없음"이 아니라 "작은 효과는 구별 불가"가 정확한 표현. 큰 해악(T_atr2 같은 타이트 TP)은 검출 가능했고 실제로 검출됨.

- A가 진단한 APT 2022-11-08 킬 타이밍 나비효과: 이벤트 목록에 APT 2022-11-08(진입 11-04, 체결 hr19, 직전 종가 +52% 위) 확인. 킬 임계 ±0.02 변형으로 일반화 확인.

## 8. 남은 수정 사항 / 루프 종료 판단

**TP 루프: 종료 가능.** 추가 TP 변형 라운드는 정보 이득이 없다(MDE 대비 효과 크기 불가, 잡음 바닥 ~0.25). 아래는 TP 가 아닌 후속 라운드 후보를 우선순위로.

1. (결과 신뢰도 영향 최대) **V0 충실도 교정**: 킬을 일중(시간봉 worst-case 또는 15분)으로 평가하는 변형을 추가하고 LIVE 킬 빈도/타이밍을 재산출. 모든 LIVE 설정 연구의 전제.
2. **위상 독립화**: 킬 리셋 시 위상 유지(phase 보존) 또는 시작일 지터 N>=20 로 경로 다양성 확보; 효과는 쌍체 차이의 분포로 보고.
3. **비생존 유니버스**: 상폐/사멸 코인 포함 패널(가능한 범위) 또는 최소 민감도 분석.
4. **레버리지/킬 설계 연구(사전등록)**: lev x deploy x kill 격자(예 <=12개), 목적함수 사전 고정(일중MDD, 최악위상), 이웃 강건성, 5. 의 방향 확인. 이것이 사용자가 실제로 얻을 수 있는 가장 큰 개선 후보.
5. **불변 사전등록**: prereg 를 커밋(해시 기록) 후 실행; A는 report.md 복구.
6. (선택, 낮은 우선) 위크 체결 가능성은 라이브/페이퍼에 분봉·호가 로깅을 켜서 데이터가 쌓인 뒤에만 재개.
