## 1. 메커니즘 정의 (공통)
- 청산은 UTC 일 종가에서, 그날 종가까지의 정보만으로 판단. 청산가 = 그날 종가, 비용 편도 cost.
- "구간 내" = 정기 리밸런스일/crash flat 전환일에는 청산 규칙을 적용하지 않음(그날은 V0 규칙이 결정). 청산된 종목은 다음 정기 리밸런스에서 목표에 있으면 재진입(그 사이 재진입 없음).
- (a) 평균회귀 청산 A: Z = 전 종목 횡단면 z-score(2일 수익률, h=2 고정). 롱은 Z>=+z, 숏은 Z<=-z 이면 "유리 방향 극단" 청산(급등 롱/급락 숏을 익절). 
  ADV(역방향): 롱 Z<=-z 또는 숏 Z>=+z (스퀴즈/급락 방어; 평균회귀 가설이 맞다면 해롭다는 반증용).
- (b) 순위감쇠 B: 매일 14d 모멘텀 순위(V0 신호와 동일) 평가. 롱은 순위>=K+m, 숏은 순위<N-K-m (N=적격 종목 수) 이면 청산(m = 여유폭). 적격 종목 < 2K 이면 규칙 비적용.
  R1/R2 = 단순히 리밸런스 주기를 1일/2일로 단축(청산 규칙 없음, 회전율 비용 포함).
- (c) 달러중립 트림 T: 청산 직후 순노출(롱명목-숏명목)이 청산 전과 같도록 반대(초과) 쪽 포지션을 비례 부분청산(비용 지불). 없으면 중립 방치.

## 3. 지표
- 1차 지표: ΔCalmar = Calmar(변형) - Calmar(V0), Calmar = CAGR / 종가 기준 MDD (위상별 계산 후 평균과 최악 위상 보고). 보조: ΔCAGR, ΔMDD, Δ일중MDD, kill 횟수, 회전율/수수료 드래그.
- 회전율 = 연환산 (총 거래 명목 / 평균 자산), 수수료 드래그 = 회전율 x 편도비용.
- 부트스트랩: 위상 평균(동일가중) 일수익률 시계열 쌍(변형, V0)에 대해 순환 블록 부트스트랩(블록 15일, 5000 리샘플, 동일 인덱스 쌍 리샘플, seed 고정) -> ΔCalmar 분포. 
  p = P*(Δ*<=0), 헤드라인 12개에 대해 Holm 보정; CI는 Bonferroni 수준(양측 1-0.05/12). "개선 CI가 0 제외" = 하한 > 0.

## 5. 강건성 테스트
- 심볼 서브셋: np.random.default_rng(20261030) 로 45종목 중 30종목 비복원 10회. 각 서브셋에서 신호/순위/z 를 서브셋 안에서 재계산, BTC crash flag 는 전체 패널. 서브셋별 ΔCalmar(위상평균) > 0 비율.
- 플라시보 1 (hazard-matched random exit): 변형의 실제 청산 확률(청산 수 / 청산 가능 포지션-일, 롱/숏 별도)을 추정해 신호 무시하고 같은 확률로 무작위 청산, 100 시드, 같은 트림 설정. 실제 ΔCalmar 가 플라시보 분포의 95 백분위 초과 시 통과 (경험적 p<=0.05).
- 플라시보 2 (time-shift, A계열만 A1~A6,C1): Z 행렬을 순환 시프트(무작위 30~(T-30)일) 100회. 동일 기준.
- R1/R2 는 플라시보 정의 불가("n/a") -> 최고 판정은 "helps (placebo n/a)". 
- 비용: 편도 0.10%(기본)과 0.20%(2x 수수료+슬리피지) 모두에서 V0 대비 ΔCalmar.
- 이웃 안정: 두 이웃 모두 IS, OOS ΔCalmar > 0 (평균 위상).
