# 탐색 사전등록 — 현 구성 상위 코호트 일봉 스크린

등록 시점: 2026-11-07 Asia/Seoul  
등급: `SURVIVOR-COHORT / exploratory only`  
목적: 기존 로컬 일봉 자료에서 후보 규칙을 빠르게 선별한다. 본 시험은 유효한 S&P 500/KOSPI 200 PIT 백테스트가 아니며, 두 전략 성공 기준에 포함하지 않는다.

## 입력 유니버스

- US: S&P DJI 공개 페이지의 상위 10개 구성원 표(페이지에 표시된 기준일 2026-08-31)를 그대로 고정한다: NVDA, AAPL, MSFT, AMZN, GOOGL, AVGO, GOOG, META, MU, TSLA. 로컬 캐시 교집합 7종목: AAPL, AMZN, GOOGL, META, MSFT, NVDA, TSLA.
- KR: 삼성자산운용 KODEX 200 공개 페이지에서 2026-11-07 검색 시 확인한 상위 보유종목 표 29개 종목을 고정한다: 005930, 000660, 402340, 009150, 105560, 005380, 055550, 034020, 006400, 028260, 012450, 086790, 068270, 000270, 035420, 032830, 012330, 316140, 066570, 005490, 034730, 373220, 000810, 010120, 033780, 267260, 009540, 329180, 017670. 로컬 캐시 교집합 21종목: 000270, 000660, 000810, 005380, 005490, 005930, 006400, 009150, 012330, 017670, 028260, 032830, 034730, 035420, 055550, 068270, 086790, 105560, 316140, 373220, 402340. 페이지 표 자체의 적용일은 확인되지 않았으므로 retrieval snapshot을 고정한 것이며, KOSPI 200 지수 전 구성원이 아니다.
- 종목 목록은 시작 시점에 고정하며, 과거 편입상태를 재구성하지 않는다. 퇴출·상폐·미래 편입을 이 코호트로 판정하지 않는다.
- 로컬 자료는 `.kis-cache` 일봉만 읽는다. 현재 문서 주석상 미국 가격은 KIS MODP=1 수정가격이다. 배당/기업행위 반영, 가격 버전, 완전성은 이 스크린에서 새로 인증하지 않는다.

## 고정된 데이터 분할 및 체결

- 캐시 이용가능 범위: 2018년부터 2026년 마지막 관측일까지. 각 종목 최소 253개 관측치가 확보된 뒤 신호를 계산한다.
- IS: 2018-01-01부터 2022-12-30까지.
- OOS: 2023-01-01부터 캐시 마지막 날짜까지.
- 신호는 거래일 t 종가까지의 정보만 사용하고, 목표 비중은 다음 공통 거래일 종가에 체결한다.
- 월간 규칙은 각 달의 마지막 거래일 종가에서 신호를 만들고 다음 거래일 종가에 체결한다. 거래 코호트 기준선은 동일 종목 고정 equal-weight 매수보유다.
- 매매비용은 별도 아래 표대로 turnover에 적용한다. 레버리지·공매도·세금 우대·현금 이자는 0으로 둔다.

## 사전 지정 후보

각 시장별 세 규칙만 평가한다. 상위 K는 코호트 크기의 20%를 올림한 값이다(US K=2, KR K=5).

1. `MOM_12M_SKIP_1M`: 252일 전 종가 대비 21일 전 종가의 수익률을 점수로 사용한다. 월말마다 양(+) 점수 종목 중 상위 K를 동일비중으로 보유하고, 조건 미충족 슬롯은 현금으로 둔다.
2. `MOM_6M_SMA200`: 126일 수익률을 점수로 사용한다. 종가가 과거 200거래일 SMA 위이고 점수가 양수인 종목만 후보로 삼아 월말 상위 K를 동일비중 보유한다. 조건 미충족은 현금이다.
3. `DONCHIAN_126_63`: 종가가 직전 126개 거래일(현재일 제외)의 최고가를 상향 돌파한 종목을 월말 후보로 삼는다. 후보를 126일 수익률로 정렬해 상위 K를 동일비중 매수한다. 종가가 직전 63개 거래일(현재일 제외) 최저 종가 아래로 마감하면 다음 거래일 종가에 청산한다. 진입은 월말에만 하고 현금 슬롯을 허용한다.

기준선은 동일 코호트를 첫 체결일에 동일비중 매수 후 유지하며 동일한 시장별 진입·청산 비용을 적용한다. 별도로 데이터 없는 외부 지수를 꾸며내지 않는다.

## 평가/보고

- 3규칙×2시장×비용 조건을 전부 기록한다. 수익률만 골라 보고하지 않는다.
- IS/OOS CAGR, 최대낙폭, Sharpe, 연도별 OOS 수익률, turnover, 비용 합계, 거래 수를 함께 산출한다.
- 표본 규모가 작고 현재 생존 코호트 선택이므로 p-value 또는 DSR 통과를 주장하지 않는다. 최상위 수치 하나로 전략을 선발하지 않는다.
- 결측 가격은 임의 보간하지 않는다. 유니버스/기간/가격 문제 발견 시 해당 케이스를 중단 사유와 함께 기록한다.
- 결과는 이 사전등록 해시를 참조한다. 규칙을 바꾸려면 새 addendum을 작성하고 기존 결과와 분리한다.
