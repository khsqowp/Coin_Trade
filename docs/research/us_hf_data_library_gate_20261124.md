# HF Data Library 미국 주식 자료 게이트 — 2026-11-24

## 결론

HF Data Library는 계정 없이 기본 파일을 받을 수 있는 무료 미국 주식·ETF 1분 OHLCV지만, 2022-03-07부터 시작해 2018년 자료가 없고 자체 이용조건은 학술 연구 전용·거래 목적 사용 금지를 명시한다. 2018/2022 PIT 횡단면 검증 경로로 채택하지 않는다. 이 사이트를 이용한 다운로드·API 호출·파일 열람은 하지 않았다.

## 확인된 제공 범위

- 공급자 문서는 IEX Exchange HIST 체결 기반의 미국 주식·ETF 1분 OHLCV를 2022-03-07부터 제공한다고 명시한다.
- 페이지는 1,253개 티커를 표시하지만, 해당 티커가 상장폐지 종목까지 포함하는지 명시하지 않는다. 종목별 첫·마지막 바 날짜를 제공한다고 설명할 뿐 과거 날짜별 PIT 투자 가능 유니버스, 상폐 최종가·정산가를 보장하지 않는다.
- 원시 버전은 주식분할만 조정하고 배당·spin-off는 조정하지 않는다고 설명한다. 전체 수익률 비교에는 추가 기업행위 보정 근거가 필요하다.
- 라이선스 표시는 CC BY 4.0이지만, FAQ와 페이지 하단은 데이터가 academic research only, not for trading이라고 명시한다. IEX Historical Data 별도 약관도 적용된다고 안내한다. 전략 거래 목적 검증 자료로 사용이 허용된다고 가정하지 않는다.
- 기본 브라우저 다운로드는 계정 없이 가능하다고 안내한다. API 사용은 무료 key를 요구하므로 조사 범위에서 사용하지 않았다.

## 프로젝트 게이트 대조

| 요구 | 확인 | 판정 |
|---|---|---|
| 2018 가격 | 시작일이 2022-03-07 | 미충족 |
| 2022 가격 | 일부 구간은 제공 가능하나 날짜 범위·종목별 첫/마지막 행 확인 전 | 불완전 |
| PIT 유니버스와 상폐 가격 | 완전한 historical membership/delisting 보증 없음 | 미충족 |
| 기업행위 반영 | raw 버전은 분할만 조정, 배당·분할기업은 미반영 | 총수익 근거 부족 |
| 거래 전략 연구 이용권 | academic research only, not for trading; IEX 별도 약관 적용 | 미확인·부적격으로 보수 판정 |

이 자료는 공개 접근 가능성과 2022년 일부 가격자료가 있다는 점만 보여준다. 기존 미국 횡단면 G를 실행하거나 2018 약세장·상폐편향 기준을 통과시키지 못한다.
