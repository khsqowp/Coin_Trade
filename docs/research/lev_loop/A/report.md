## 3. 모델 명세 (요약)
- 청산: 매 시간 worst-case 마진 잔고(롱 L / 숏 H 동시, 펀딩 포함) <= 유지증거금 이면 청산. TIER: 포지션별 USD 명목가 구간 0.5%/1%/2.5%/5% (A0=10,000 USD 가정; 실제로는 대부분 최저 구간) ; FLAT3: 전 포지션 3%(보수, 청산수수료/알트 구간 포괄). 경로는 청산 후에도 반사실로 계속(자본<=0 만 파산). 청산 여유 = (worst-case 마진 - 유지증거금)/전일 종가 equity, 최소값 보고.
- 스트레스: VOL = 종목별 시간 로그가격 변동 x1.5 (거듭제곱 변환; 신호 순위 불변, BTC crash 필터와 펀딩은 재계산/종가비 근사), COST = 수수료+슬리피지 0.2%/side (2x), COMB = 둘 다(보고용).
- admissible = 120 경로 전부에서 TIER 와 FLAT3 청산 0 이 BASE, VOL, COST 모두에서 성립(시간 킬 모드 3/1/0 별 계산; 청산 체크는 모든 모드에서 시간 worst-case).

- 4배 초과 질문: lev 5/6 BETTER+admissible 셀 0개 -> **"4배 초과는 도움이 되지 않음 (구분 불가한 성장 + 청산 위험 급증)"**.
- 레버 하향(소유자 제약상 권고 아님): lev 3~3.5 + kill none 계열이 성장 동일 + 청산 여유 +0.14~0.40 (VOL 포함 3.0 만 안전) 로 지배적일 가능성이 있으나 구분 불가.

신뢰 수준:
| 강하게 뒷받침 | lev 6 은 실제 과거(2025-10-10)에서 FLAT3 유지증거금 기준 청산; lev 5 는 1.5x 변동성 재생에서 OOS 100% 청산; kill=none lev>=3.5 도 VOL 에서 청산; 성장은 레버 5~6 에서 현재와 구분 불가; 킬 시뮬 충실도가 결과 부호를 바꿈 |
| 약함 | 현재 셀이 안전하다는 결론(여유 +0.10 이 얇음, 청산 모델 가정 의존); kill .5 가 .35 보다 낫다는 힌트(FULL g .89 vs .72, CI 가 0 포함); 레버 3~3.5 의 우월성 |
| 알 수 없음 | 라이브 15초 킬의 실제 빈도/손익(0.1~0.5 사이 어디인지); 실제 거래소 유지증거금표/ADL/자동감축/청산수수료; 사멸 코인; 2025-10-10 형 이벤트의 틱 레벨 실제 슬리피지 |

## 8. 한계
1. 킬 모델 브래킷이 너무 넓다(CAGR -37~+104%). 라이브가 어디에 있는지 모르는 한 "현재 설정 성장"의 점추정은 신뢰 불가. 이것이 가장 큰 결함.
2. 시간봉 H/L 동시 최악 가정은 청산 확률을 **과대**, 실제 순간 갭(15초 이하 분)은 **과소**할 수 있음. 청산은 마진 모델이며 부분 청산/자동 감축/ADL/청산수수료 미모델.
3. VOL 재생은 로그가격 x1.5(드리프트도 x1.5) 근사이고 펀딩 환산은 종가비 근사. 사건 시점 정렬에 따라 가부가 120 경로에서 동시에 뒤집힘(상관 높음; 유효 독립 사건 수 ~3-6).
4. 지터 120 경로는 서로 겹치는 윈도우라 독립 표본이 아님; 부트스트랩이 킬 상태 의존성을 일부 파괴(경로 선택으로 일부 복원).
5. 생존편향 45개 현재 상장 심볼, V0 파라미터가 전체 구간에서 선택됨(IS 선택은 레버/킬에만 유효), 수정 1 은 단일 경로 관찰 후 추가(사전등록 엄격성 약화), 집중도는 복리 미보정.
6. A0=10,000 USD 구간 가정은 사실상 영향 없음(최저 구간).

## 9. 라운드 2 후속 가치 상위 3
1. **킬 충실도 직접 교정**: 라이브 equity_history/킬 로그(읽기 전용)와 분봉(1m) 가격으로 15초~1분 단위 킬 트리거를 재생해 모드 1/3 사이의 위치를 확정. 이것이 없으면 성장 점추정은 의미 없음.
2. **킬 설계 재탐색**: kill=.35 는 성장을 만들지 못하고 보험 역할만 한다. "청산 근접 시에만 작동하는 마진 기반 킬/감축(예: 유지증거금 여유 < X 에서 감축)" vs "dd 킬"을 같은 120 경로 쌍체 설계로 비교(사전등록, 별도 라운드).
3. **청산 모델 검증**: 실제 Binance 유지증거금 구간표(심볼별 notional tier, 청산수수료, 자동감축)를 반영하고 1분 H/L 로 2025-10-10, 2024-12-09, 2025-05-10 사건을 재생해 lev 4~5 의 실제 여유를 계측; 사건 정렬에 덜 의존하는 복수 스트레스(상관 붕괴, 갭)를 추가.
