## C. 지표 (모두 기술통계, 합격/불합격 없음)
기준가 ref = 해당 시간 직전 1분봉 종가(= 직전 시간종가). 시간 h 안의 1분 봉으로
- 롱측 와이크 l_last = ref - min(low_last), l_mark = ref_mark - min(low_mark); 숏측 u_last = max(high_last) - ref, u_mark 대칭.
- f 인자 = l_mark / l_last (롱), u_mark / u_last (숏). 유의 조건: l_last/ref >= 1% (미만은 제외, 개수 병기).
- 종목별 "해당 일 최악 시간"(l_last/ref 최대 시간)의 f, 그 분포(p10/중앙/p90), 가중 합산 f = sum(l_mark)/sum(l_last).
- 리뷰 break-even f(0.97 @4x U3_23 등) 이상인 종목 비율.
- 극값 분: 시간 내 low(롱)/high(숏) 가 발생한 분(0~59), 종목 간 분산(IQR), 롱 low 분 vs 숏 high 분 쌍별 |차|<=5분 비율.
- 롱 바스켓/숏 바스켓 1분 수익률 상관 (스트레스 시간 내, 실제 V0 북 가중).
- "동시최악비율" = (1분 해상도 포트폴리오 최악 손익, 분 종가 가격 기준 & 분 L/H 앵커스 기준 두 가지) / (시간 L/H 동시 최악 손익: 롱 시간저가, 숏 시간고가) 를 일 내 24개 시간 중 시간 L/H 손실이 최대인 시간과, 24시간 중앙값에서 보고.
  북 = indep_sim.py(V0 4x, dep .95, K=8, 3일 리밸, 킬 .35)의 위상 0/1/2 가 해당 일에 보유한 q,e (record=True) — 리뷰와 동일 엔진. 데이터 결측 종목 gross 비중 15% 초과 시 해당 일/위상은 "커버리지 부족" 표기.
  가격 모델은 (i) 라스트, (ii) 마크(청산/미실현 기준) 두 가지 모두.

## D. 라이브 equity 재구성 (보정) — 합격 규칙
입력: 상태 파일 equity_history(2026-09-25~현재), entry_log, trade_log(리밸/리사이즈/킬 메시지), positions(현재 수량으로 역검증), 공개 1분 마크가격.
재구성: 포지션 변경 시점 사이의 구간 s 에서 E_rec(t) = sum_i q_i (P_i(t) - P_i(t_s)) 의 변동분(마크 1분 종가, 선형 보간 없이 최근 1분 종가). 지갑 잔고(현금)는 구간별 미지 상수이므로 구간 중앙값 잔차를 제거한다.
잔차 r_t = (E_rec(t)-E_rec(t_s)) - (E_live(t)-E_live(t_s)) 에서 구간별 중앙값 제거 후 / E_live(t).
- **합격**: (1) 포지션 수량 재구성이 현재 상태 positions 와 +-3% 일치 (역검증), (2) 재구성 가능 구간 샘플이 flat 이 아닌 전체 샘플의 >= 70%, (3) 풀링 RMSE <= 0.30% of equity.
- 하나라도 미충족 -> "보정 실패", 브래킷 유지(경험적 lambda 는 제시하지 않고 참고치만 표기).
- 보조(비판정): 구간 시작 앵커만 쓴 오차, 펀딩 영향 추정.
합격 시: 시간별 실측 순간 하락 d_inst_h = (E_rec(h 종가 직전 1분) - min_분 E_rec)/E_rec(close) (1분 해상도, 15초는 x1.2 보정 병기), 같은 시간·같은 북의 시간 L/H 앵커스 최악 d_anti_h (1분 데이터의 시간 H/L 사용) -> 경험적 lambda = sum d_inst / sum d_anti (풀링) 및 시간별 분포. 1분 equity 로 DD 임계(0.15,0.2,0.25,0.27) 도달 횟수를 시간종가 DD 와 비교.
그 lambda 를 lambda_kill.py(리뷰) 보간 킬 백테스트에 넣어 현재 셀 CAGR 구간 재산정(브래킷은 lambda 신뢰구간 하한/상한).
