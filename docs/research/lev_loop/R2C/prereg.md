## 2. 전략과 셀 (<= 18 셀)

전략 = 라이브 V0(교차 롱8/숏8, 14일 모멘텀, 3일 리밸런스, 수량 유지, 비용 0.1%/편, 펀딩 실제, BTC 14일 -10% 충격 시 전량 flat, 킬 후 쿨다운 14일), 엔진 `app/rs_lev_r2c_engine.py`.
셀 = lev {3.0(참조 전용), 3.5, 4, 5} x kill {0.35, 0.5, 0.6, 없음} = 16 셀, deploy 0.95 고정. 기준 = (4.0, 0.35).
킬 충실도 lambda in {0, 0.15, 0.3}: 시간 킬 판정 equity = 시간종가 - lambda x (시간종가 - 앵커스 L/H 최악), 체결도 그 값(review.md 5절/lambda_kill.py 정의). kill 없음 셀은 lambda 무관(1회).
총 비교 열(콤보) = 4 lev x (3 킬 x 3 lambda + 1) = 40.
참조(3.0, 3.5)는 소유자가 하향을 거부하므로 후보가 아닌 비교 참조이며 3.5 는 판정표에 "하향(소유자 제외)" 표기. 후보 = 기준을 제외한 lev>=3.5 의 11 셀.

청산 진단(경로를 종료시키지 않고 계수): 쐐기 비율 f in {0.5, 0.75, 1.0} — 롱 불리가 = 직전 시간종가 - f x (직전 종가 - 저가), 숏 불리가 = 직전 종가 + f x (고가 - 직전 종가), 롱 L/숏 H 동시, 유지증거금 = **조정가격 명목** x {tier(BTC/ETH 0.4%, 알트 1.0%), flat 3%}. 청산 = (잔고 + 평가손익 - 유지증거금) <= 0.
청산 수 판정: f=0.5 와 0.75 에서 tier 와 flat3 **둘 다** 0 이어야 통과(보수적).

## 3. 지터 / 유효 궤적 / 반복

- 모든 반복(rep)은 시작 위상 {0,1,2} 무작위, 킬 쿨다운 14+U{-2..2}일(킬 서수별), 쿨다운 해제 후 리밸런스 지연 U{0,1,2}일(킬 서수별). 공통 난수: 같은 rep 의 지터 표는 모든 셀이 공유(쌍체).
- 연속 전구간 실행(full): R=48 rep, 시작일 무작위 오프셋 0..29일.
- 윈도 실행(windows): 겹치지 않는 90일 구간(첫 거래 가능일부터), 각 윈도 W=1 로 재시작, R=24 rep, 윈도 값 = rep 평균 연환산 ln W.
- 보고: 모든 수치 옆에 고유 최종자산 수(unique trajectories / R), 킬 에포크 수(서로 7일 이상 떨어진 고유 킬 일자 군집), 평균 킬 수.

## 4. 검정력 분석 (결과 열람 전 단계, 분산만 출력)

`r2c_power.py` 는 **평균/점추정을 출력하지 않고** SE, MDE, 표본 수, 고유 궤적 수만 출력한다.
(a) 이상 고정비율: lev=1 무킬 일수익률의 15일 블록 부트스트랩, 쌍 (G=lev x 0.95) 4->5, 4->3.5, 3.5->5, 3->4 의 ln 성장 차 SE 및 MDE=2.8 x SE.
(b) 실제 엔진: 윈도 쌍체 차(후보 - 기준, 같은 lambda) 의 표준오차. MDE_t = (t_{.975,n-1}+t_{.80,n-1}) x sd/sqrt(n) (n=윈도 수; 소표본 보정).
(c) 목표 효과: lev 변경 delta=0.05/년(Kelly 이득), 킬 변경 delta=0.12/년(킬 제거 이득 하한). MDE_t <= delta 이면 "MDE 충족".
(d) 필요 표본(결정 가능성): Y_req = Y_sample x (MDE_t/delta)^2 (연), OLD+NEW 합산 가정 별도.
MDE 미충족이면 어떤 결과도 "keep" 근거로 쓰지 않는다.

## 5. 고정 판정 규칙 (후보 c vs 기준, lambda 별)

후보는 아래 **전부** 만족해야 "supported":
1. (CI) OLD 와 NEW 각각에서, lambda=0.15 와 0.3 모두, 쌍체 윈도 블록 부트스트랩(B=10,000, 윈도 단위 복원) 95% CI 하한 > 0 **그리고** t 구간 하한 > 0.
2. (일관성) 윈도 중 비동률 윈도(|차|>1e-12) >= 5개이고 그중 차>0 비율 >= 70% (OLD, NEW 각각, lambda 0.15/0.3). OLD 에서는 추가로 심볼 서로소 반쪽 22종목 부분집합(무작위 분할 6회 x 2 = 12개, 각 R=8 연속 실행)의 평균 차>0 비율 >= 70% (분할 내 서로소; 분할 간 평균 중첩 ~50% 명시).
3. (청산) OLD 와 NEW 연속 전구간 모든 rep 에서 lambda 0/0.15/0.3 의 후보 셀 청산 수 0 (2절 규칙).
4. (MDE) OLD 와 NEW 모두 MDE_t <= delta (4절).
분류: 전부 통과 = supported; 아니면 순서대로 — 청산 수>0 → unsupported(청산); 어느 (표본, lambda)에서든 부트스트랩 CI 상한 < 0 → unsupported(해악 지시); MDE 미충족 → **uninformative**; 그 외 → unsupported(검정력 충분하나 이득 없음).
보조(비구속): IS/OOS 분리 CI, OLD-PIT 부호 일치, 생존편향 스트레스(상위5 제거 / 30종목 3블록 합집합 / 상폐 스트레스) 부호, f* 비악화(날짜-이동 지표는 이 라운드 범위 밖).

스트레스(OLD, 비구속 보고): (S1) 기준 셀 lambda=0.15 의 종목별 실현 손익 기여 상위 5 종목 제외; (S2) 45종목을 15종목 3블록으로 나눈 뒤 두 블록 합집합 30종목 3개(쌍별 중첩 정확히 50%; "30종목 <50% 중첩"은 45종목에서 수학적으로 불가능, 최소 중첩 15/30=50%) x 4 분할; (S3) 상폐 스트레스: 상폐 위험률 = PIT 편입 심볼 중 데이터가 2026-08-31 이전에 종료된 심볼 수 / 편입 심볼-연, 각 rep 심볼별 베르누이, 사건일 균등 무작위, 보유 포지션 롱 x0.1 / 숏 x2.0 정산(불리한 방향, C 팀 관행), 이후 심볼 제외.
