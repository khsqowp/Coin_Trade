## 0. 먼저 결론

1. **"KEEP CURRENT"는 "효과 없음"이 아니라 "구별 불가"다.** 세 팀 결정규칙은 모두 기본값이 KEEP이고, 로그성장 차이의 최소검출효과(MDE, 80% 검정력/5%)는 이상적 고정비율 모형에서도 0.30/년(4x vs 5x), 킬 경로 카오스를 포함한 실제 엔진에서는 0.6~1.4/년이다. 이론상 4x->5x Kelly 이득은 +0.03~0.06/년이므로 **성장 면의 레버리지 비교는 이 데이터로 원리적으로 불가능**하다. 따라서 어떤 팀의 "KEEP"도 "4x가 최적"의 증거가 아니다.
2. **A/B/C의 청산 수치는 서로 모순이 아니라 서로 다른 조건부 확률이다.** 현재 셀 "0/120"은 120 경로가 사실상 1개 궤적(아래 3절)이라 "0/1"이며, 2025-10-10에 포지션이 gross/eq 2.83(중앙값 3.79 보다 낮은 상태)이었다는 운에 의존한다. C의 "1/30 유니버스(4x)"는 포지션 구성 복권, B의 "단위 손실 x gross > MM"은 gross 상태 복권이다. 세 조건을 함께 보면 **4x의 청산 안전성은 (gross/eq, 숏 헤지 작동 여부 f/h, 마크-라스트 괴리) 가정에 따라 0%에서 70%까지 움직인다**(6절 표).
3. **킬 시뮬 충실도 브래킷(CAGR -37%~+104%)은 라이브 5분 equity로 좁힐 수 있다.** 라이브가 시간봉 최악(T1) 대비 시간 내 하락 폭 비율(lambda)이 약 0.1~0.3이다. 내 독립 구현에서 lambda=0.05~0.3이면 4x 현재 셀 CAGR은 약 48~68%(킬 12~15회)이고, lambda=0(A 모드3)의 102%는 낙관 경계, lambda=1의 -39%는 비현실적 경계다. 즉 **A/B/C가 보고한 "+84~104%"는 라이브 기대치로 과대, "-37%"는 과소이며 현실 점추정은 대략 50~70%**(그마저 +-30%p 카오스).
4. **킬의 "청산 보험" 주장은 BASE 실제 역사에서 확인되지 않는다.** 일종가 킬 .35 / .5 / .6 / 없음의 최악일 청산 임계 날개비율(f*)이 0.54 / 0.40~0.61 / 0.61 / 0.61 이고, 최대 gross/eq 는 5.62 / 8.64 / 5.54 / 5.54 로 킬 .35가 우월하지 않다. A의 보험 증거(VOL 1.5x 재생에서 4x none 40/120 청산)는 합성 스트레스 하의 정렬 복권이다. 단 이론적으로 킬은 gross/eq 상한(3.8/0.65=5.85)을 거는 효과가 있고, 이것이 유일한 구조적 보험 메커니즘이다.
5. **새 발견(고가치, 백테스트 범위 밖): 라이브에서 지금까지 발생한 유일한 킬(2026-10-12 05:50 UTC)은 시장 손실이 아니라 지갑 이체 기준선 이중 적용으로 보이는 가짜 킬이다**(8절). 시장 DD는 20% 였는데 hwm 이 +74.01 이동해 dd 44.4%로 판정, 16개 포지션 전량 시장가 청산, 8.5시간 정지. 백테스트의 어떤 킬 모델에도 없는 위험이다.
6. **라운드 2는 필요하나 "레버리지 비교"가 아니라 (a) 청산 꼬리의 상태변수(gross/eq, 순노출, 종목 집중) 통제와 (b) 마크가격/분봉 데이터로 킬/청산 충실도 교정, (c) 표본 확장(상장폐지 포함/2020-21)으로 목적을 바꿔야 한다**(10절). 성장 비교 라운드를 더 돌리는 것은 정보 이득이 없다.

### 3.3 유효 표본, MDE, "KEEP CURRENT"의 의미
- **유효 표본**: 120 경로 -> 1 궤적(E1). 독립 청산 사건 ~1(2025-10-10), 보조 사건 2024-12-09, 2025-05-09/10 은 여유가 더 큰 사건(4x 여유 +.5). 유효 15일 블록 수 ~116(4.8년). 청산 확률에 대해서는 사건 수 1로 CI 가 사실상 [0, 1) 에 가깝다(균등 사전 Beta 사후 95% 구간: 4x 1/30 -> 0.8%~16.7%, 0/30 -> 0.1%~11.3%, 5x 8/30 -> 14%~45%).
- **MDE (80% 검정력, 5% 양측 = 2.8 x SE)**:
  - 이상적 고정비율 레버(킬 없음, 15일 블록): g(5)-g(4) 점추정 +0.063/년, SE 0.108, 95% CI [-0.130, +0.286], **MDE 0.30/년**; g(3)-g(4) -0.135, SE 0.110, MDE 0.31; g(6)-g(4) SE 0.218, MDE 0.61; g(5)-g(3) SE 0.222, MDE 0.62 (`mde.out`).

### 5.1 독립 청산 구현 vs C/B/A

### 5.2 2025-10-10 "라스트가격 봉" 이 청산을 인공물로 만드는가
오프라인에 마크가격 데이터 없음(`.rs_cache` 에는 BTC 일봉 프리미엄 지수뿐). 대신 감도 분석:
- **마크-라스트 괴리 계수 f**(롱 가격 = 직전 시간종가 - f x (직전종가 - 저가), 숏은 고가 쪽 대칭; f=1 이 팀들의 가정): U3_23 4x 청산은 **f >= 0.97 에서만** 성립(break-even f = 0.97). 즉 마크가격이 라스트 와이크의 3%만 덜 극단이어도 사라진다. 5x 8개 서브셋의 break-even f 는 0.73~0.98(중앙 0.89), 6x 12개는 0.61~0.98. f=0.75 이면 4x 0/90, 5x 3/90(1 서브셋), f=0.5 이면 5x 도 0/90 (`liq_subsets.out`).
- **숏 헤지 작동 계수 h**(동기 모델 = 같은 시간 저가에 숏도 이익): 동기 극단에서 4x 최소 여유 +0.59(30 서브셋 전체), 5x +0.46. 2025-10-10 실제 북(4x 위상0): 롱 1.73x eq 는 저가에서 -0.759, 숏 1.11x eq 는 같은 시간 저가에서 +0.778, 고가에서 -0.016 -> **헤지가 작동하면 순손실 ~0, 앵커스면 -0.78**. 종목별 시간21 저가/직전종가: 우주 중앙값 -60%, 롱 북 BNB -31%, XMR -16%, ZEC -35% 로 상대적으로 얕았고 숏 북 RENDER -82%, WLD -75% 로 깊었음(운이 좋은 구성).
- 결론: 2025-10-10 청산은 **(앵커스 최악) x (라스트 와이크 100% 마크 반영) x (특정 구성) 의 3중 가정이 모두 성립할 때만** 나타나는 사건이다. 아티팩트라고 단정할 수 없는 이유: ADL(이익 숏 강제 감축)과 유동성 진공이 실제로 헤지를 제거하고 마크가격도 급락 시 괴리를 줄이지만 0 은 아님. 반대로 안전하다고 단정할 수 없는 이유는 6절의 날짜-이동 분석. **정확한 f/h 는 이 연구로 결정 불가이며 마크가격 분봉 + ADL 기록이 필요하다.**

### 6.4 소유자 목적과 증거 사이의 내적 비일관성 (중립 서술)
1. "청산 불가"를 보증하는 레버리지는 증거상 어느 값에서도(3x 도 앵커스 f=1 이면 16~27% 일) **보증 불가**. 보증 가능한 것은 조건부(f, h, gross/eq)뿐.
2. "최대 수익"은 3~6x 구간에서 데이터로 식별 불가(MDE >= 0.3/년 vs 이론 이득 0.03~0.06/년). 즉 레버 선택은 수익이 아니라 **꼬리 위험 선호**로 결정되는 문제이고 꼬리 위험은 레버에 대해 볼록하게 증가(f* .74 -> .54 -> .42 -> .34).
3. "하향 불가"와 "청산 불가"는 같은 gross 를 쓰는 한 충돌할 수 있다. 증거는 하향이 수익을 줄인다는 것을 보이지 못했고(3x 동등) 청산 안전은 개선함을 보였다. 반대로 상향이 수익을 늘린다는 증거도 없다. 따라서 "하향 불가/상향 개방"은 증거에 근거한 결론이 아니라 선호다.
4. 증거와 양립하는 비하향 선택지는 **평균 gross 를 건드리지 않고 gross/eq 와 순노출/집중의 꼬리 상태만 줄이는 설계**(예: gross/eq > 4.2 일 때만 감축, 순노출 캡, 종목 캡)이다. B 의 래더/볼타깃은 평균 gross 를 2.1~3.3 으로 낮춰 이 제약을 위반했고 이 방향은 미검증.
5. 소유자 운영 사실(상태 파일): 2026-10-11 09:12 ~ 10-24 09:37 약 13일간 deploy 0.5(목표 gross 2.0)로 운용, 실현 gross 는 평소 3.54~3.62(최소명목 스킵). 즉 실제 운용 레버는 이미 가변적.

### R2-B (킬/청산 충실도 교정, 실제 데이터) - 수정 대상: 모든 팀의 E2/E3
(1) data.binance.vision 의 1분봉(라스트) + **markPriceKlines 1분**으로 2025-10-10, 2024-12-09, 2025-05-09/10, 2024-08-05, 2022-06-13 을 재생해 종목별 f(마크 와이크/라스트 와이크)와 분 단위 동기성(h)을 실측. (2) 라이브 `entry_log`(+RESIZE/청산 로그)로 2026-09-02~현재 포지션 시계열을 재구성하여 1분 가격으로 순간 equity 를 계산하고 라이브 5분 equity 로 검증(RMSE 사전 허용 0.3%), 통과 시 lambda 분포를 경험적으로 추정. (3) 경험적 lambda/분 단위 순간 DD 로 킬 규칙을 재생, 킬 수/CAGR 구간 재산정(현 50~70% 추정 확인/반박). (4) 라이브 쪽 관측 개선 제안만(코드 수정 아님): 15초 equity+포지션 스냅샷의 영속 저장.
고정 결정 규칙: 재구성 equity 가 라이브와 RMSE <= 0.3% 일 때만 lambda 를 사용; 아니면 "충실도 교정 실패"로 보고하고 브래킷 유지.

### R2-C (표본 확장 / 일반화) - 수정 대상: C 의 서브셋 중복, 생존편향 E8
(1) 상장폐지 포함 point-in-time 유니버스(2020~현재, 가능한 범위의 폐지된 USDT-M 심볼 포함), (2) 2020~2021 이전 구간(2020-03-12, 2021-05-19, 2021-12 등 독립 사건) 추가, (3) 레버 {3.5, 4, 5} x 킬 {.35, .5, .6, 없음} x lambda in {0, 0.15, 0.3} 의 ln W 차이와 f* 를 이전 표본(2022~) 과 신규 표본 모두에서 보고. 서브셋은 50% 중복 비허용(구조화 leave-k-out).
고정 결정 규칙: 어떤 변경도 (i) 신규+기존 두 표본에서 쌍체 15일 블록 CI 하한 > 0, (ii) f* 비악화, (iii) 사전 MDE 대비 효과 크기 충족 - 셋 다 충족해야 "변경 후보". 사전 MDE 가 효과 가정(+0.1/년)보다 크면 "uninformative"로 종료.

종료: 라운드 2 후 라운드 3 은 R2-B 가 충실도 교정에 성공했을 때만. 아니면 루프 종료.
