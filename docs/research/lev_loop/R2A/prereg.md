## 1. 셀 (9개, 상한 10 이내)
| 셀 | 규칙 |
|---|---|
| C0_control | 현행 (kept-qty, 캡 없음) |
| C1_norm | 통제 + 총노출 정규화: 매 리밸런스에서 유지 포지션도 목표명목(eq*dep*lev/16)으로 재조정 (B 의 E6 교란 분리용) |

| N03 / N05 | 순노출 캡 abs(net)/eq = 0.3 / 0.5 |
| S12 | 단일 종목 캡 (아래 해석 주의) |
| X1_G42_S12 | G*=4.2 + 종목 캡. 근거: 2025-10-10 의 위험은 "gross 상승일" 과 "ZEC 집중" 이 겹친 상태. 순노출 캡(거래 회전이 큼)은 제외해 평균 gross/비용 영향을 최소화 |
| X2_G46_N05_S12 | 세 캡의 가장 느슨한 값 결합. 근거: 느슨한 캡 3개의 합이 개별 캡 효과의 합 이상인지(상호작용) 확인 |

캡 규칙(전부 라이브 구현 가능한 형태, 결정은 봇이 가진 데이터(시간봉 종가 마크) 만 사용, 시장가 체결 = 해당 시간봉 종가 + 비용 0.1%):
- 평가 시점: 매 시간 종가(h=0..22) 및 일 종가(리밸런스 후). 시간 내 와이크는 방어 못 함(한계로 기재). 15초 폴링은 시간 샘플보다 더 자주 잡으므로 이 구현은 보수적.
- 적용 순서: 순노출 -> 종목 -> 총노출.
- 총노출: gross/eq > G* 이면 모든 포지션을 비례 축소하여 gross/eq = 0.95*G* 로 (4.2 -> 3.99, 4.6 -> 4.37).
- 순노출: abs(net)/eq > cap 이면 gross 를 보존하며 무거운 쪽 축소/가벼운 쪽 확대, 목표 abs(net)/eq = cap-0.1 (히스테리시스).
- 종목: abs(포지션 명목)/eq > cap_eq 이면 해당 종목만 cap_eq 로 축소. **해석 주의**: 과제문은 "12% of equity" 이나 목표 gross 3.8x 에서 종목당 명목은 eq 의 23.75% 라서 문자 그대로 적용하면 평균 gross 를 절반으로 낮춰 소유자 제약과 모순. 라운드1 review 10절은 "한 종목 <= 12% of gross". 따라서 cap_eq = 0.12 x (lev x dep) = 0.456 x eq (= 목표 gross 의 12%, ZEC 0.51 초과)로 구현한다. 초과분은 재분배하지 않음.
- 축소/확대는 실제 체결 회계(부분 실현손익, 평균 진입가 재계산, 비용 차감)로 처리.

## 2. 킬 모델 브래킷 (모든 셀 x 5모델, 단일 모델 금지)
daily(일 종가 킬, V0), hourly(lambda=0, 시간종가), lam05, lam15, lam30 (equity_h(lambda)=종가_h - lambda x (종가_h - 앵커스 L/H 최악_h), HWM 은 시간종가). 통제군은 review 의 lambda_kill 값을 재현해야 함.

## 3. 경로와 지터
M=60 경로: k=0 은 비지터 기준 경로, k>=1 은 시작일 오프셋 0..39일, 리밸런스 위상 0..2, 킬마다 쿨다운 +-2일 및 재진입 지연 0..2일 (시드 910000+k, 모든 셀에서 동일 -> 쌍체). 모든 확률/CI 옆에 (a) 유효 독립 궤적 수 (마지막 365일 구간 비례성 군집), (b) 독립 사건 수 (청산일을 15일 이상 간격 군집한 에피소드 수, 경로 합집합 및 경로당 평균), (c) 15일 블록 수를 병기.

## 4. 고정 지표
(1) f*: 보유일 책(시간 21시 직전, 즉 20시 종가 책, 20시 종가 자산)에 2025-10-10 21:00 봉(직전 시간종가 대비 상대 이동; 롱=L/ref, 숏=H/ref)의 비율 f 를 곱해 이식했을 때 교차마진 청산(여유<=0)이 되는 최소 f. 유지증거금: 티어 r1 (BTC/ETH 0.4%, 알트 1.0%) x **충격 후 조정가격 명목**(E5). 쿠션(f)이 f 에 선형이므로 닫힌 형태로 계산(f>1 은 선형 외삽, 상한 99). 경로별 f* = 보유일 최소, 셀 값 = 60 경로 중앙값. 1차 모델 anti(롱 L / 숏 H 동시).
(2) 날짜이동 청산확률 P: 위 이식으로 보유일 중 쿠션<=0 비율. 모델 3종: anti(롱L/숏H 동시), sync(전 심볼 동시 극단: 전부 L 또는 전부 H 중 나쁜 쪽), hedged(숏이 같은 시간 L 로 이익). f in {0.5, 0.75, 1.0}. 15일 블록 부트스트랩 CI 병기. 보조: 유지증거금 flat 3%.
(3) 평균 gross 변화: 보유일 일 종가 gross/eq 평균(캡 적용 후), 60 경로 평균, 통제군 대비 상대 변화. 보조: 정지일 0 포함 평균.
(4) 30개 고정시드(20261030) 30-심볼 서브셋: 서브셋별 (4a) 실제 기간 시간별 최소 청산 여유(앵커스 f=1, 티어, 조정가격), (4b) 이식 최소 여유(anti f=1.0). 서브셋 경로는 비지터 기준 경로 1개. "더 나쁨" = 후보 < 통제 - 1e-9 (엄격). 허용오차 0.02 버전은 정보용.
(5) 성장: 경로별 ln(최종자산)/년의 후보-통제 쌍체 차. 쌍체 15일 블록 부트스트랩(경로 평균 일 로그수익 차의 블록 합) CI 95% 및 Bonferroni(비교 8개) CI. 

## 5. MDE (후보 실행 전에 통제군만으로 계산: stage0)
MDE0 = max( 2.8 x sqrt(2) x sd(g_경로) / sqrt(n_unique), 2.8 x sqrt(2) x SE_블록부트스트랩(g_경로평균) ), 킬 모델별로. 사전 설정한 현실적 효과 크기 = 0.05/년 (평균 gross 변화 <=3% 이므로 Kelly 기울기 기준 최대치). MDE0 > 0.05 이면 성장은 'uninformative' 로 표기하며 "효과 없음" 이라고 쓰지 않는다. stage0 결과는 stage1 전에 해시한다.

## 6. 채택 규칙 (사전 고정, 하나라도 실패하면 기각)
IS 구간(2022-01-01 ~ 2024-06-30)에서 5개 킬 모델 **전부**에서:
- A1: median f*_anti(후보) - median f*_anti(통제) >= +0.12
- A2: P_anti(f=0.75, 티어) 가 통제 대비 상대 50% 이상 감소 (통제 P=0 이면 평가불가=실패)
- A3: 보유일 평균 gross 변화 >= -3%
- A4: 30 서브셋 중 (4b) 가 통제보다 엄격하게 나쁜 서브셋 없음
- A5: 라이브 구현 가능성 문서화 (정확한 규칙, API 호출, 실패 모드) — report.md 에 셀별로 기재
IS 전부 통과한 셀만 OOS(2024-07-01 ~ 2026-10-30, 신규 시작)에서 같은 규칙을 재평가하고, 통과해야 "worth adopting". IS 에서 통과 셀이 없으면 OOS 는 열지 않는다(미접촉으로 유지). 선택에는 IS 만 사용. 사전 정의된 셀 외 파라미터 튜닝 없음(트림 계수 0.95, 순노출 히스테리시스 0.1 은 고정값).

## 7. 시행 수와 보정
셀 9 x 킬 모델 5 x 구간 최대 2 = 최대 90 (셀,모델,구간) 평가, 후보 8. 채택 규칙은 임계값 판정이라 p-값 보정 대상이 아니며(다중 기준 AND 로 가혹), 성장 차 CI 는 Bonferroni(m=8)를 병기. 사후 탐색은 판정과 분리 표기.
