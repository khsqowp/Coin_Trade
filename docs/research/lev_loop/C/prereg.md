## 1. 모델 가정(엔진 사양)
엔진 변경은 옵션 플래그로만 추가, 기본값은 V0와 동일.
1. MM(유지증거금) 모드
   - mm_mode=0: 레거시(일 단위, 평탄 0.5%) — 재현 전용.
   - mm_mode=1 (기본 "tier"): 시간 단위. 시간 h마다 롱은 L, 숏은 H 동시 불리 가격 a_h로 평가한 equity_h = W + 펀딩 + sum q(a_h - e) 가 maint_h = sum mm(|q|*a_h) 이하이면 청산(경로 종료). 1구간 요율 r1: BTC/ETH 0.4%, 그 외 알트 1.0%. 명목 N>=5,000이면 max(N*r1, 구간식): [5k,25k) 2.5%N-75, [25k,100k) 5%N-700, [100k,250k) 10%N-5700, [250k,..) 12.5%N-11950. (참고: 계정 $127 규모에서는 1구간만 실효. 자산이 수만 달러가 되기 전까지 tier 구간 효과는 무시 가능.)
   - mm_mode=2 (flat3): 위와 같으나 모든 심볼 요율 3% 평탄(보수 변형). 모니터로도 동시 산출.
2. 모니터(경로를 바꾸지 않고 동시에 계산, 각각 최소 완충 buffer = (equity_adverse - maint)/W_일시작 의 경로 최솟값과 최초 위반일):
   M_tier, M_flat3, M_gap5, M_gap10, M_flashF1, M_flashF2.
   - gap g: 각 시간에서 직전 종가 대비 불리 방향 상대 이동이 가장 큰 보유 포지션 1개에 추가 g*|q|*a 손실(마크/라스트 괴리, ADL 근사). g=5%, 10%.
   - flash F1: 2025-10-10 일봉의 심볼별 하방 위크 w_j = max(0, 1 - min_h L[2025-10-10,h,j] / C[2025-10-09,23,j]) (상장 전 NaN은 단면 중앙값). 모든 보유 포지션에 동시에 롱은 -w_j, 숏은 +w_j(미러) 불리 충격을 매일 일 종가 equity에 적용. F2: 같은 충격을 그 날 hourly worst-case equity 위에 중첩(극단). 위반: stressed_equity <= maint_tier.
3. 증거금/상한(L3): 심볼별 최대 레버 cap_j. 기본 BTC,ETH=100, 대형(BNB XRP SOL TRX DOGE ADA LINK LTC BCH AVAX XLM)=50, 나머지=50. L3a: "나머지"(low-cap)=10, L3b: BTC/ETH 제외 전부=5. 규칙: 1구간 MM = 0.5/cap_j(바이낸스 관례 근사). 신규 진입 시 사용 IM = sum |q|*px/cap_j (신규 포함)가 현재 equity(마크)를 넘으면 해당 진입 건너뜀(n_skip). 최대 IM/equity 사용률을 기록.
4. 소액 계정(L4): eq0=127, minn=5 (BTC 100, ETH 20 generic), lot 절삭 포함(엔진 기존 로직).
5. 펀딩 스트레스(L7): 사전에 고정한 규칙으로 선택한 30일 창(패널 단면 평균 |FD| 의 30일 이동합이 최대인 창, 2022-01-01 이후, 전략 실행 전 계산)에서 FD x3.
6. kill 충실도 모드(kill_mode): 1=일 종가(V0), 2=시간 종가 equity(매 시간 체크), 3=시간 worst-case(L/H 동시 불리) equity가 dd>=35% 이면 그 시간 불리 가격으로 청산, 4=모드3 + 청산 명목의 1% 추가 슬리피지. HWM은 모드 2~4에서 시간 종가 equity 최대값 사용. 시간 순서: 매 시간 (청산 판정 -> kill 판정). 쿨다운 14일/재진입 HWM 리셋은 V0 동일.
7. 상장폐지 스트레스(U4): 연 3건(2022~2026 각 연도 3개 임의 일; 시드 1..20, numpy default_rng(seed), 이벤트 일은 [d_start+30, 끝-30]에서 연도별 비복원 추출, u~U(0,1)). 이벤트일 보유 포지션 중 인덱스 floor(u*보유수) 1개에 대해: 롱이면 그 날 12시~23시 H/L/C x0.1 (-90%), 숏이면 x2.0 (+100% 스퀴즈/고가 정산). 이벤트 심볼은 그 날 종가 청산 후 영구 제외. 보유 포지션이 없으면 이벤트 소멸.

## 3. 측정 지표
설정별: 최종자산 배수, CAGR, 연율 로그성장 g, 종가MDD, 일중MDD, kill 수, 청산 경로 수, 최소 완충(모니터별), IM 최대 사용률, 스킵률.
지터(J1,K*): 120경로 분포 중앙값/p10/p90 (최종자산, CAGR, MDD, kill), 경로 쌍체(동일 오프셋·위상) ln(TW_s/TW_S0) 의 중앙값과 양(+) 비율.
부트스트랩: 이동 블록(길이 15일 기본; 10, 20 민감도), B=2000, 시드 20261030, 통계량 = g(설정) - g(S0), 위상평균 일 로그수익률 차이. 보고 CI = Bonferroni(m=4 비교, 양측 alpha=0.05/4 -> 하한 퍼센타일 0.625, 상한 99.375).
순서 지속성: 각 유니버스(U1,U2,U3 30개)에서 g 순위 5개 설정; 기준(U1) 순위와의 Kendall tau 중앙값, 최상위 설정 빈도, S_k > S0 인 유니버스 비율(전구간 및 IS·OOS 각각).
시행 수/헤어컷: 총 엔진 실행 수와 판정 대상 비교 수를 기록. 헤어컷 = 점추정에서 1.163 * SE_boot 차감(5개 설정 최대값 기대치, Sharpe 헤어컷 정신) + Bonferroni(m=4).

## 4. 적격성(admissible) 규칙 (실행 전 고정)
설정 s는 아래 "코어 스트레스" 전체에서 청산 위반 0건(J1 120경로 전부 + U2 + U3 30개 x 3위상 + U4 20시드 x 3위상)일 때만 admissible:
 A1 tier MM 종료형 (L1), A2 flat 3% (L2), A3 gap 10% (L6, 따라서 gap5 포함), A4 펀딩 x3 (L7), A5 cap10 (L3a), A6 kill_mode 3 및 4에서 청산 0 (K2,K3), A7 상장폐지 스트레스에서 청산 0 (U4), A8 플래시 F1 (L8).
"극단"(binding 아님, 별도 보고): F2, L3b(cap5), gap 위반. "ALL" 최대 레버는 코어 + 극단 전부 0인 최대 래더 레버로 따로 보고.
최소거리: 각 스트레스별 최소 완충 보고.

## 5. 판정 규칙 (고정)
순서: (1) 코어 스트레스 위반 있으면 "inadmissible (liquidation under stress S)".
(2) admissible 이면 비교 vs S0 (U1, 전구간, Bonferroni CI):
 - "admissible and better than current": CI 하한 > 0 AND U1·U2·U3 (32개 유니버스) 중 >= 70%에서 g_s > g_S0 AND OOS 구간 점추정 > 0.
 - "worse": CI 상한 < 0 AND 32개 중 >= 70%에서 g_s < g_S0.
 - 그 외 "admissible but not distinguishable".
전체 결론: 코어 admissible 인 래더 설정 중 최고 노출, 그 안전마진(첫 위반 래더 레버 / 해당 레버, 최소 완충), IS 로그성장 헤어컷 후 최고 설정의 OOS 확인 여부. 수준 표기: strongly supported / weak / unknown. 100% 확신 불가.
