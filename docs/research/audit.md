## 4. 다중검정 (널 분포, 스태거드 시리즈, 0.10%, 펀딩 포함)
- 널 A: 무작위 지속 점수(AR(1) rho=0.928, 일평균 회전율을 베이스라인 0.240에 맞춤), 500회, 동일 자격/비용.

- 널 B: 일자를 통째로 셔플(모멘텀/반전 자기상관 파괴, 횡단면·변동성·펀딩 보존), 풀히스토리 28종목, 500회(QK는 200회).
  CW Sharpe 평균 -0.38 sd 0.48, p95 0.37, 최대 1.21, P(Calmar>2)=0.
  QK Sharpe 평균 -0.28 sd 0.49, p95 0.50, 최대 1.02.
  동일 유니버스 실제 베이스라인: CW Sharpe 0.73 -> 98.8 백분위, QK 1.06 -> 100.0 백분위(Calmar 99.5).
- 독립 시도 7,000회 가정 시 널의 기대 최대 Sharpe(가우시안 근사) ~1.07 (N=1000: 0.82, N=100: 0.47).
  실제 설정들은 상관이 매우 높아 유효 N은 훨씬 작지만, "IS Calmar>2" 급은 널 A/B 어디서도 0/500 이었다(최대 Calmar 1.33).
  => 단일 검정 기준 베이스라인은 우연으로 보기 어렵다(p~0.004~0.012). 그러나 CW Sharpe 0.86은 7,000회 선택 최대치(~1.07) 안쪽이라
     "7,000개 중 최고"로 뽑힌 값이라면 선택만으로도 설명 가능. 내가 본 것은 사전 지정된 단일 베이스라인(14일/K8/3일)이며 이 값은 위 p값을 따른다.
  IS Calmar>2 같은 후보는 이 널에서 나오지 않으므로 선택효과 + 과적합(특히 오프셋/유니버스)로 보는 것이 타당. (후보 시리즈 자체는 미보유.)
