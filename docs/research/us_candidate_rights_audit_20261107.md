# US 일봉 후보 권리·PIT 게이트 재검토 (2026-11-07)

## 판정

이번 조사에서는 파일을 내려받거나 Parquet을 열지 않았다. MarketParquet의 공개 안내 페이지에 표시된 예시 OHLC 숫자는 근거로 사용하지 않았다. 계정을 만들거나 API 키를 발급하지 않았고, 약관 동의 버튼도 누르지 않았다. 서버·실거래 경로에는 접근하지 않았다.

| 후보 | 접근·비용·권리 | OHLC·기간·조정 | 상폐·PIT | 게이트 판정 |
|---|---|---|---|---|
| **ml4t Wiki Prices Parquet** | ml4t 문서는 사용자가 이미 보유한 로컬 Parquet을 읽는 `WikiPricesProvider`를 설명한다. 코드 저장소의 MIT 라이선스는 소프트웨어 라이선스이며, 데이터 파일 자체의 배포 허가를 입증하지 않는다. 원 데이터인 Quandl/Nasdaq WIKI는 Nasdaq Data Link 설명상 커뮤니티 큐레이션 데이터이며 공개 도메인으로 표시되어 있으나, API/데이터 내보내기는 로그인 필요라고 안내한다. 현재 계정 약관을 수락하거나 원본을 받지 않았다. | ml4t 문서는 3,199개 미국 종목, 1,540만 행, 약 631MB, 1962–2018을 주장하고 `adj_open/high/low/close/volume`을 사용한다. Nasdaq WIKI 색인 문서는 History를 Jan 1996으로 표시한다. 기간 표기가 서로 달라 실제 스냅샷의 시작일·스키마·해시 확인이 필요하다. WIKI는 2018-04-11 이후 갱신 중단, Nasdaq은 투자·분석 용도를 권하지 않는다고 명시한다. | ml4t는 상장폐지 종목 포함을 주장하지만 이는 프로젝트 설명이지 WIKI의 PIT 완전성 보증이 아니다. 날짜별 유니버스 스냅샷/상폐 완전성/빈티지 재현 근거를 확인하지 못했다. 과거 조정 필드가 미래 기업행위에 따라 다시 계산됐는지 파일로 검증하지 않았다. | **현재 DATA_BLOCKED.** 적법하게 확보된 파일이 별도 존재하면 출처·파일 라이선스·해시·schema·기간·기업행위 적용시점을 먼저 고정한 뒤, 2018 이전 탐색용 별도 사전등록에 한해 재심사 가능. 현 WIKI 설명 자체가 투자·분석 비권고이므로 유효 전략 증거로 취급할 수 없다. |
| **MarketParquet free daily sample** | 사이트 문서는 최근 7일 파일은 무계정 공개, 최근 약 365일 전체 샘플은 무료 계정/API 키 이용이라고 나눈다. 다만 같은 사이트의 데이터 라이선스는 라이선스가 archive 구매 시 계정별로 부여된다고 명시하며, 무료 파일 안내는 무료 파일에 라이선스가 없다고 명시한다. 따라서 무료 공개 접근은 곧 연구 이용 허가가 아니다. 계정 생성·다운로드·약관 동의는 하지 않았다. | 사이트 문서는 2000년부터 현재까지 일봉 OHLCV, 최근 1년 무료 샘플, 전체 아카이브 79달러 일회 구매를 표시한다. 주식·ETF 가격은 split-adjusted이며 현금 배당은 가격에 포함하지 않는다고 설명한다. 배당 총수익 전략에는 별도 배당 데이터가 필요하다. | 제공자 주장은 과거 파일에 `-DELISTED` 종목이 마지막 거래일까지 남아 날짜별 당시 거래 가능 유니버스를 만든다는 것이다. 그러나 별도 point-in-time publication vintage는 확인되지 않았다. 품질 변경기록은 과거 날짜의 누락 심볼 보완, 과거 분할 재조정, 여러 파일 수정 기록을 공개한다. 이는 완전성을 개선하지만 과거 배포 시점의 데이터 상태 재현과는 다르다. | **무료 샘플은 권리 미통과 및 OOS 기간 부족으로 부적격.** 유료 전체 아카이브는 개인 연구·백테스트 사용권과 2000년 이후 기간을 사이트가 명시하므로 잠재 후보지만, 구매 승인은 없고 원천 벤더·PIT 빈티지·전체 유니버스 완전성을 독립 검증하지 않았다. 구매 또는 데이터 열람 없이 백테스트 적격 판정 불가. |

## 확인한 1차 자료

1. [ml4t Wiki Prices provider 문서](https://github.com/michaelbiafore/data_ml4t/blob/main/docs/providers/wiki_prices.md): 로컬 Parquet 입력, 3,199 종목/1962–2018/상폐 종목 포함 주장을 설명한다. 데이터 파일을 어떻게 취득하거나 라이선스하는지는 적지 않는다.
2. [ml4t 저장소의 라이선스](https://github.com/ml4t/data/blob/main/LICENSE): MIT는 코드에 대한 라이선스다. 해당 문서에서 WIKI Parquet 파일 권리는 확인되지 않았다.
3. [Nasdaq Data Link WIKI Prices](https://data.nasdaq.com/databases/WIKIP): 공식 설명은 커뮤니티 큐레이션, 공개 도메인, 3,000+ tickers, Jan 1996 history, 2018-04-11 이후 미지원, 투자·분석 비권고를 함께 표시한다. API/데이터 내보내기 인증은 로그인 필요로 안내한다. 이 페이지의 직접 열람은 현재 404였으며, 검색 색인에 남은 공식 페이지 내용을 확인했다.
4. [MarketParquet 무료 데이터 안내](https://marketparquet.com/guides/free-historical-stock-data): 최근 7일은 무계정, 최근 365일은 무료 계정, 무료 파일 자체는 라이선스가 없다는 점을 명시한다.
5. [MarketParquet 가격·접근 안내](https://marketparquet.com/pricing): 무료 최근 1년과 79달러 전체 아카이브, 상폐 포함 주장, 아카이브 구매자를 위한 내부 연구 권리를 설명한다.
6. [MarketParquet 데이터 라이선스](https://marketparquet.com/license): 개인 연구·백테스트 및 파생 성과 공개를 허용하지만, 계정별 권리는 archive 구매 시 부여되고 원시 파일 재배포는 금지한다고 명시한다.
7. [MarketParquet 이용약관](https://marketparquet.com/terms): 무료 샘플 예외 외 데이터 다운로드에 계정이 필요하며, 미구매 데이터 접근 및 구매를 대체하는 사이트 스크래핑을 금지한다고 명시한다. 약관 내용을 조사했을 뿐 동의 조작은 하지 않았다.
8. [MarketParquet 문서](https://marketparquet.com/documentation), [품질·방법론 기록](https://marketparquet.com/data-quality): 일별 schema, split-only 조정, 배당 미포함, PIT 유니버스에 대한 제공자 주장과 과거 수정 이력을 설명한다. 원천 가격 벤더의 명칭과 point-in-time 배포 이력은 확인하지 못했다.

## 다음 안전 단계

* Wiki Parquet이 로컬에 이미 있다면, 파일을 열기 전에 출처·취득 시점·명시 라이선스·SHA-256을 확인한다. 권리가 확인되면 값 열람 전에 schema와 기간만 검사하고, 그 결과로 2018 이전 탐색 전용 사전등록을 별도로 검토한다.
* MarketParquet은 무료 파일을 받지 않는다. 사용자가 유료 전체 아카이브 구매를 별도로 승인하는 경우에만 제공자 원천, 사용권 범위, 날짜별 유니버스/상폐 정의, 보존·수정 이력, 표본 기간과 파일 해시를 확보한 뒤 데이터 게이트를 재심사한다. 무료 샘플은 무계정으로 접근 가능해도 라이선스가 없다고 사이트가 적었으므로 연구용 입력으로 쓰지 않는다.
* 양 후보 모두 이번에는 결과값·가격열·성능수치를 생성하지 않았다. 어느 전략의 엣지 존재 여부도 추론하지 않는다.

이 보고서는 데이터 접근·사용권에 대한 조사 기록이며 법률 의견이 아니다.
