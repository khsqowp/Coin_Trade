# 국장 PIT·상장폐지 주식자료 유료 경로 감사 — 2026-11-24

## 결론

한국주식 자료에는 무단 자동수집을 피하면서 이용허가가 붙은 파일을 구입하는 공식 KRX Data Marketplace 경로가 있다. 다만 현재 공개 문서만으로 실제 구매 상품의 기간·종목·상폐 가격 범위와 전략 백테스트/로컬 보관 권한을 확정하지 못했다. 따라서 이는 후속 확인 가치가 있는 조달 경로이지, 지금 실행할 수 있는 데이터 게이트 통과가 아니다.

## KRX 공식 판매 경로

- KRX OPEN API는 유가증권·코스닥 종목의 일별 매매정보를 2010년부터 제공한다고 명시한다. 이는 서비스 설명상 전체 과거가 2010년 이전으로 확장되지 않으며, 약관 동의·키 발급·API별 이용 신청이 필요한 경로다. 약관은 비상업적 이용만 허용하고, 제공된 정보를 제3자에게 제공하지 못하게 하며, 이용기간 만료·해지 후에는 정보를 이용하지 못하게 한다. 공공데이터 포털에 올라온 금융위/KRX 주식시세 API도 공공누리 제4유형(상업적 이용 금지·변경 금지)과 제3자 제공·재배포 금지를 표시한다. 개인 비상업 전략연구의 내부 계산은 조건부로 가능할 수 있으나, 연간 이용기간이 끝난 뒤 원자료를 계속 쓰는 재현 가능한 로컬 백테스트 권리는 확인되지 않았다.
- 공식 구매 카탈로그에는 주식의 `일별 매매정보` 및 ETF·ETN·ELW의 `일별 매매정보`가 각각 별도 상품으로 표시되어 있다. 해당 설명은 주식의 일자별 매매정보와 증권상품의 일자별 매매정보를 제공한다고 말하지만, 공개 카탈로그 응답에는 적용기간·폐지 종목 완전성·필드 목록이 나오지 않았다.
- KRX Data Marketplace 구매안내는 상품 상세에서 기본 사양·제공기간·데이터 항목·전달방식·샘플·가격을 확인한 뒤 신청·결제하고, 이용목적 심사를 거쳐 파일을 받는 절차를 설명한다. 학술기관·학생 할인 요건도 안내하지만, 개인 전략 연구에 적용되는 이용 허락은 해당 구매 상품의 별도 약관으로 확인해야 한다.
- KRX의 상장폐지종목 시세 화면은 상장폐지일·사유 및 일별 OHLCV 필드가 존재함을 보여준다. 화면 필드만으로 일괄 구매 상품의 전체 기간·모든 폐지 종목의 가격행·정리매매 또는 최종 정산액·자동 이용권을 입증하지 않는다.

## 보조 공급자 검토: FnGuide DataGuide / FnSpace

- FnGuide는 주가·수정주가·수익률·이벤트 데이터 이력을 1980년부터 안내하며, FnSpace 도움말은 과거 특정 날짜에 상장 상태였던 종목 코드 목록에서 현재는 폐지된 종목도 나올 수 있다고 설명한다. 따라서 PIT 목록과 과거 가격이 함께 있을 가능성은 있으나, 실제로 폐지 종목 가격 이력과 최종 포지션 가치가 보장되는지는 확인되지 않았다.
- 공개 이용·요금 안내는 DataGuide의 최초 계정 연 720만원(VAT 별도), 첫 계약 1년 내 중도 해지 불가를 기재한다. 데이터는 조회·분석 용도로 제한되고 기계적 대량 추출 또는 DB 구축이 계약 위반이라고 명시한다. 이 조건상 자동 백테스트 입력으로 내려받아 장기 보존하는 경로는 적격하다고 보기 어렵다.
- FnSpace 고객지원은 현재 상장 기업 데이터를 기본 제공 대상으로 하고, 과거 특정일 당시 상장기업 목록에 현재 폐지된 기업이 포함될 수 있다고 설명한다. 하지만 이는 특정일 유니버스 확인 가능성을 보여줄 뿐, 종목별 OHLCV 시계열·정산금액·다운로드/자동 분석 권리 증거가 아니다.

## 실행 전에 확보해야 하는 답변

KRX에 구매 문의가 필요하다면 상품 후보를 정하기 전에 아래 항목을 서면으로 확정해야 한다.

1. KOSPI·KOSDAQ 보통주와 ETF 각각 2018-01-01~2026-05-31 일별 raw OHLCV의 전체 파일 구매가 가능한지, 실제 제공기간·파일형식·자료량은 무엇인지.
2. 모든 당시 상장·거래정지·정리매매·상장폐지 종목이 포함되는지, 일별 PIT 상장 유니버스/종목 식별자 이력/상장폐지 효력일·최종 거래일이 함께 오는지.
3. 상폐·합병·감자·분할·배당 발생 후 보유 포지션을 정산할 수 있도록 현금대가·주식대가·권리락 및 분배 데이터가 포함되는지.
4. 개인이 내부 투자전략 연구·자동화 백테스트·비공개 로컬 보관·파생 통계 보존에 사용할 수 있는지, AI/외부 도구에 원자료를 전송하지 않고 처리해야 하는 조건이 있는지.
5. 허용되는 2개 독립 연도 또는 2018·2022 전 기간 커버리지 샘플과 제공 데이터 해시/정정 정책을 구매 전에 볼 수 있는지.

이 답변과 가격을 확인해도 실제 파일 취득·사용은 구매약관의 구체 조항과 사용자 승인 이후에만 시작한다. 데이터 적격성 검증 전에는 기존 국장 사전등록을 실행하거나 바꾸지 않는다.

## 조사 경계

KRX·공공데이터·FnGuide의 공개 상품 안내·약관·FAQ만 확인했다. 로그인, API 키 발급·호출, 자동수집, 화면 다운로드, 가격행 열람, 공급자 연락, 계약 동의, 데이터 구매 및 백테스트는 하지 않았다. 공급자 설명이나 메뉴 필드 존재는 실제 자료 커버리지·정확도·사용권 검증을 대신하지 않는다.
