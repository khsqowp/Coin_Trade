# KRX·KODEX 100/200 자료 경로 점검

점검일: 2026-11-07  
범위: 공식 KRX·삼성자산운용 공개 페이지와 약관만 확인. 계정/API 키 생성, 약관 동의, 다운로드, 서버 접속은 하지 않음.

## 결론

공식 출처로 KOSPI100·KOSPI200의 구성 정보와 지수 변경 이력 데이터 상품이 존재한다는 점은 확인했다. 다만 신뢰 가능한 과거 구성 이력은 KRX의 유료 데이터 상품 경로로 안내되고, 무료 KRX OPEN API는 2010년 이후 일별 지수·주식·ETF 매매정보를 제공한다고만 확인된다. OPEN API가 지수 구성 이력까지 무료 제공하는지는 확인되지 않았다. 따라서 무료로 과거 구성종목을 재구성할 수 있다고 가정해 연구를 시작하면 안 된다.

## 확인 결과

| 항목 | 확인된 사실 | 판정 |
|---|---|---|
| KOSPI100/200 정의 | 삼성자산운용은 KODEX 200의 기초지수를 KOSPI200으로 설명하고, KOSPI100 ETF 자료는 KOSPI200 중 시가총액 상위 100종목 추종으로 설명한다. | 확인 |
| KRX 구성종목 조회 화면 | KRX 공식 화면에 지수명·조회일자 입력과 구성종목 표가 존재한다. 과거 날짜 조회가 가능해 보이지만, 실제 지원기간과 과거 전체 조회 가능성은 확인하지 않았다. | 화면 존재 확인, 역사 범위 미확인 |
| KRX 지수 과거 구성 자료 | KRX는 종가기준/익일기준 구성종목정보 파일에 구성종목·반영주식수·가격·비중·유동비율을, 지수조치정보에 구성변경 및 지수 채용주식수 변동을 포함한다고 명시한다. | 자료상품 존재 확인 |
| 해당 자료의 무료 여부 | KRX 데이터상품 안내는 회원가입·로그인, 상품 선택, 결제, 이용목적 심사 후 수령 절차를 안내한다. 가격표의 개별 가격은 확인하지 않았다. | 무료 경로 미확인; 유료 상품 경로 확인 |
| KRX OPEN API의 가격/범위 | 목록은 2010-01-04 이후 KOSPI 지수 시계열, 유가증권 일별매매정보, ETF 일별매매정보 등을 열거한다. 지수 구성 이력 API는 목록에서 확인하지 못했다. | 일별 데이터 범위 확인, 구성 이력 API 미확인 |
| OPEN API 권리/조건 | 이용약관 동의와 인증키 신청이 필요하고, 비상업적 목적만 허용하며 키당 하루 10,000회 제한을 둔다. 개인의 내부 백테스트가 비상업적 사용에 해당하는지는 약관 문구만으로 확정하지 않았다. | 약관 조건 확인, 개인 연구 적용 해석은 미확정 |
| 가격 OHLC 및 기업행위 | API 목록에 일별매매정보는 있으나, 이번 점검에서는 응답 스키마/샘플값을 조회하지 않았다. 지수조치 데이터는 구성 변경 등 지수 차원의 사건이며, 개별 종목 배당·분할 전체를 포함한다고 단정할 근거는 없다. | OHLC 필드·개별 기업행위 범위 미확인 |
| KODEX ETF 실제 보유내역 | KODEX 200 상품 화면에 적용일 선택, 전체 보유종목 다운로드 안내가 있다. 실제 ETF PDF에는 현금성 자산 등이 들어갈 수 있고 비중 산정에서 현금성 자산을 제외한다고 명시되어, 지수 편입종목과 ETF 보유내역을 같은 데이터로 취급하면 안 된다. | 현재/선택일 화면 확인, 전 기간 이력 미확인 |
| KODEX 코스피100 상장 이력 | 삼성자산운용 자료에서 237350의 상장일을 2016-01-27로 확인했다. 이 ETF 가격만 사용하면 2016년 이전 구간을 대체할 수 없다. | 확인 |

## 연구 적합성 판정

- **제한 유니버스 연구는 가능성이 있으나, 아직 데이터 게이트 미통과다.** KRX의 과거 구성 정보상품이 실제로 구입 가능하다는 것과 무료·자동 접근권을 갖는 것은 별개다.
- 무료 KRX OPEN API를 쓰려면 먼저 약관에 동의하고 키를 신청해야 하므로, 이번 범위에서는 사용하지 않았다. 비용이 0원인지, 로컬 비상업 백테스트 및 원자료 보관이 허용되는지 확인되지 않았다.
- KODEX 200/코스피100 ETF 자체의 시장가격만 연구하면 구성 이력 문제는 줄어들지만, ETF 상장 이후 구간으로 제한되고 지수 자체나 과거 구성종목 전략을 검증하는 대체물이 아니다. ETF 분배금, 거래비용, 추적오차를 별도로 반영해야 한다.
- 다음 안전 단계는 KRX 데이터상품 가격·제공기간·필드·이용권한을 로그인/구매 없이 공개 문서나 KRX 문의로 확인하는 것이다. 과거 구성 이력이 무료 공개되지 않는다면, KODEX ETF 자체 전략으로 연구 목적을 바꾸는 별도 사전등록이 필요하다.

## 검증 한계

데이터를 내려받거나 API를 호출하지 않았으므로, 실제 파일의 날짜 커버리지, OHLC 필드, 수정주가 여부, 배당/분할 반영, 종목코드의 상장폐지 보존 여부는 검증하지 않았다. KRX 화면의 조회일자 입력은 역사적 조회의 UI 증거일 뿐, 전체 과거 조회권이나 자동 수집권의 증거가 아니다.
