# Phase 5 결과 — 1분 단일 캔들 몸통 우세 신호

## 판정

**탈락.** 10분·20분 모두 목표 선도달률 80%에 크게 못 미쳤고, 왕복 14bp 비용 반영 평균 순 R도 음수다. 이 고정 규칙은 추가 파라미터 탐색이나 Monte Carlo로 구제하지 않는다.

## 고정 시험

- 규칙: 완료된 1분봉에서 `abs(close-open)/(high-low) >= 0.80`; 몸통 방향으로 롱/숏.
- 진입: 다음 연속 1분봉 시가. ATR(14) 기반 1R 손절·익절, 동시 터치는 손절 우선, 손절 갭은 불리한 시가 체결.
- 평가: 10분·20분, 고정 5개 달력 블록. 모든 신호를 M2 분모에 포함하고, 경로 결측·불량·폴드 경계 초과는 미해결로 유지.
- 비용: 기본 왕복 14bp, 스트레스 왕복 28bp. 펀딩비는 데이터 부재로 미반영.
- 데이터: 100개 심볼, 2026-07-16~2026-11-14, 완료 cutoff `2026-11-14T00:29:00Z`. 입력 SHA-256 `cac23a3d18be66e226bdf8c3dbc0d08f5c6c185d4f18ed2a8687f08d2b6f67b1`, 1,864,249,344 bytes.
- 이 자료는 이전 연구에서 이미 노출된 짧은 개발 구간이다. 5개 블록은 시간 안정성 진단이지 독립 OOS가 아니다.

## 데이터·구현 검증

- ATR 준비 앵커 16,786,513개 중 coverage 분자에 포함되는 신호 4,251,682개(25.328%). ATR 없는 발행 신호 395개도 M2 전체 신호 분모에는 포함했다.
- 데이터 게이트: coverage, 경로 해결률, 비중복 N/심볼 수 모두 통과.
- 독립 scalar/vector 비교: 10분 resolved 표본 942개, 20분 910개; 라벨 불일치 0, base/stress 순 R 최대 오차 0.
- 임의 결과 튜닝, 파라미터 격자, Monte Carlo 구제는 수행하지 않았다. 사전 등록된 실패 규칙으로 여기서 종료한다.
- JSON 결과에 실행기 및 공유 resolver 소스 파일의 시작·종료 SHA-256을 기록했다. 이는 파일 바이트 동일성 지문이며, 실행 프로세스 내부의 로드된 bytecode provenance를 독립 증명하는 값은 아니다.
