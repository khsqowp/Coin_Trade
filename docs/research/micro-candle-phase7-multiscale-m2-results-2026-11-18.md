# Phase 7 결과 — 고정 미세 패턴의 3분·5분 스케일 재시험

## 판정

**8개 셀 전부 1차 탈락.** 패턴을 새로 꾸미지 않고, Phase 5 몸통우세와 Phase 6 스윕·리클레임을 3분·5분봉으로 올렸지만 어느 조합도 목표 선도달률 80% 또는 비용 후 양의 기대값을 충족하지 못했다. 파라미터 조정·역방향 전환·Monte Carlo 구제는 하지 않는다.

## 고정 시험과 데이터

- 3분/5분봉은 UTC epoch 버킷으로 만들고, 완전하고 유효한 연속 1분봉 N개가 정확한 예상 타임스탬프에 있을 때만 집계했다. 부분 버킷이나 구성 분봉 결측·오류는 제외했다.
- 기존 고정 규칙 2개: 몸통/범위 비율 ≥0.80의 몸통 방향 추종, 2봉 한쪽 극값 돌파 후 직전 범위 안쪽·중간값 너머 종가의 리클레임.
- 10/20 집계봉 보유기간은 3분에서 30/60분, 5분에서 50/100분이다. 다음 연속 집계봉 시가 진입, 1R 목표/손절, 동일 봉 동시 터치는 손절 우선, 손절 갭은 불리한 시가, 시간 종료는 H번째 봉 종가로 처리했다.
- 기본/스트레스 왕복 비용 14/28bp, 펀딩 미반영. 5개 폴드는 availability 시각 기준 반개구간으로 적용했다.
- 입력: 100개 심볼, 1분 DB 1,864,249,344 bytes, SHA-256 `cac23a3d18be66e226bdf8c3dbc0d08f5c6c185d4f18ed2a8687f08d2b6f67b1`, cutoff `2026-11-14T00:29:00Z`. 데이터 품질 감사는 관측 심볼 구간 내 결측·잘못된 OHLCV·오프그리드·중복이 0이라고 보고했다.
- 이 자료는 짧고 이전 연구에 노출된 개발 데이터다. 폴드는 독립 OOS가 아니다. 보고된 100종목도 point-in-time 상장/상폐 유니버스로 검증된 집합이 아니다.

## 계산 검증

- 빈도 단계에서 outcome label을 읽지 않았고, 여덟 셀 모두 빈도 통과 후에만 결과 경로를 평가했다.
- M2 실행 전 빈도 보고서의 심볼·폴드별 집계를 원본 DB에서 재계산했고, 총계·비중복 수·심볼 분산까지 대조했다.
- 셀별 독립 scalar/vector 비교는 약 1,500건씩 수행했다. 모든 셀에서 라벨·무거래 불일치 0, 기본/스트레스 순 R 최대 오차 0이었다.
- 관련 테스트 50개 통과. 구현 게이트는 통과했고 성과 게이트는 모두 실패했다.

## 연구 연속성

두 에이전트는 OHLC-only 1분 패턴 후보를 더 만들면 이미 조사된 inside-bar, 돌파/압축, pullback/re-entry, 반전 패밀리와 중복될 가능성이 높다고 판단했다. 이어 3분·5분 스케일 확장안을 독립 검토했고, 둘 다 사전등록·코드 게이트의 수정사항 반영 후 PASS했다.

다음은 이와 같은 저분봉 규칙을 10분·15분봉으로 넓혀 같은 고정 목표·비용·분모를 재검증한다. 그 단계에서도 성과가 없으면 OHLC 패턴 변형을 무한히 추가하지 않고, 이미 준비된 microstructure/L2 데이터가 정확한 시간·시퀀스 품질 게이트를 만족하는지 검토하는 쪽으로 범위를 넓힌다. 이 순서에서 거시 필터는 아직 사용하지 않는다.
