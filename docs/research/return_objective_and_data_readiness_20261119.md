## 연구 목표와 통과 기준

최종 목적은 여러 시장 국면에 걸쳐 비용 차감 후 장기 복리 순수익을 극대화하는 것이다. 모든 국면에서 반드시 수익을 보장할 수는 없다. 따라서 상승·하락·횡보·고변동 구간에서 전략과 포트폴리오 배분을 따로 검증하고, 한 구간의 성과만으로 전체 전략을 선택하지 않는다. 사용자가 지정한 수치는 이 목적을 대체하는 목표가 아니라 전략 채택을 위한 위험·증거 문턱이다.

- 국장·미장 주식/ETF: 각 시장별 OOS 청산 거래 N≥200, 순 CAGR≥20%, MDD≤30%, Sharpe≥1.0을 모두 요구한다.
- 코인 수동 롱·숏 신호: 전체 발행 신호의 M2 목표 선도달률 점추정≥80%, 비중복 OOS 신호 N≥200. 기한 종료 방향 정확도는 별도 보고한다. 사전 등록한 비용 차감 후 기대값이 양수여야 한다. 목표 적중률만으로 수익성이라 판정하지 않는다.

위 기준을 두 명세에 반영했다: [`주식·ETF 명세`](../kr-us-equity-trader/SPEC.md), [`코인 차트 예측 명세`](../chart_predictor/SPEC.md). 이 수정은 주문·모의주문·배포를 승인하지 않는다.

### 국장 주식·ETF

현재 캐시는 장기 생존편향 없는 순수익 검증 자료로 부적격하다. 수집 시점·가격 빈티지·PIT 유니버스·상폐/합병·기업행위·ETF 분배금이 파일별로 증명되지 않는다. 같은 캐시에서 성과를 재계산해도 독립 OOS가 생기지 않는다.

후속 후보(미검증): KODEX 200 단일 ETF를 무레버리지로 보유하고 직전 완료 20거래일 실현변동성 기준으로 월간 노출을 조절한다. 목표 변동성은 시험 전에 15%로 고정하고 노출은 100%를 넘지 않게 한다. 기존 모멘텀·역변동성·SMA200·압축돌파와 구별되는 단일 지수 위험 노출 가설이지만, 데이터 적격성을 해결하기 전에는 성과시험을 하지 않는다. 유사 기존 기록은 registry ID 26, 48–50, 53, 63이다.

현재 92종목 캐시도 시점별 유니버스와 기업행위 이력이 확인되지 않고 가격은 여러 기존 연구에서 이미 열람됐다. 그러므로 독립 OOS로 쓸 수 없다.

### 코인 신호 연구 — 독립 리뷰 2건

두 리뷰 모두 기존 캔들 지표 추가, 오더블록 확신도 강화, RSI/EMA 풀백 변형을 새 전략처럼 재시험하는 것을 반대했다. 이 계열은 기존 연구와 중복되거나 이미 여러 차례 실패했다. 현재 캔들 DB는 실제 주문흐름·호가·펀딩·미결제약정 테스트에 필요한 필드를 제공하지 않는다.

첫 후보(데이터 선행): 타임스탬프가 보존된 호가/체결 불균형 한 개를 사전 정의하고 고정 triple-barrier로 채점한다. 이벤트 시점 정렬, 갭/누락, 체결·비용 가정과 독립 표본성을 검증할 새 고빈도 데이터가 필요하다.

두 번째 후보(증분 포트폴리오 가설): 고정 USDT-M 코인군의 완성된 1시간봉 breadth를 위험노출 게이트로 사용하고, 20시간 고점 돌파 포트폴리오에 적용한 결과를 동일 신호의 무필터 대조군과 비교한다. 기존 돌파/BTC 레짐 연구(registry ID 33, 80)와 연관되므로 완전히 새 전략군으로 부르지 않는다. 이미 연구에 노출되지 않은 전향/OOS 표본, 고정 장벽, 포트폴리오 위험예산 및 비용을 먼저 등록해야 한다.
