# 자동 투자 시스템 두 제품 — 최종 목표

갱신: 2026-11-14

두 제품은 목표, 위험 정책, 실행 권한이 서로 다르므로 별도 설계·검증·운영한다.

## A. 코인 차트 분석·신호 알림

- 상세 기준: [`chart_predictor/SPEC.md`](chart_predictor/SPEC.md)
- linuxserver에서 코인 시장을 실시간 관찰하고, 급등·급락 가능성이 검증된 경우에만 CoinBot 텔레그램으로 분석 차트와 근거를 전송한다.
- 사용자는 알림을 참고해 롱·숏·배율·주문 여부를 직접 결정한다. 이 제품은 주문하지 않으며 기존 8:8 자동매매 시스템과 분리한다.
- 핵심 평가지표는 보정된 신호 정확도와 커버리지다. 기존 합의한 target-first 75% 이상, 수수료 차감 후 양의 기대값 및 2:1~4:1 목표/손절 비율을 신호 게이트로 유지한다.
- 실행 런타임(Hermes, OpenClaw, 자체 구축)은 미정이다. 사용자 API 승인 전에는 구독제 에이전트만 사용한다.

## B. 국장·미장 주식·ETF 자율매매

- 상세 기준: [`kr-us-equity-trader/SPEC.md`](kr-us-equity-trader/SPEC.md)
- 대상은 한국 및 미국 상장 주식과 ETF로 한정한다. 코인, 선물·옵션 등 파생상품은 범위 밖이다.
- 최종 목적은 사전에 검증된 전략과 위험 규칙 안에서 에이전트가 자율적으로 매매하는 시스템이다. 연 20%는 목표치이지 보장·예측이 아니다.
- 초기 검증은 과거 데이터 백테스트다. 이는 브로커 모의주문이나 실거래가 아니다. 에이전트 런타임·브로커·데이터 제공자와 실제 주문 전환 조건은 아직 정하지 않았다.
- 최대 허용 낙폭은 사용자 결정 전까지 미정이다. 이 값이 미정인 동안 성과를 실거래 준비 완료로 판정하지 않는다.

## 저장·배포 원칙

- 두 명세는 로컬 저장소와 linuxserver의 Coin_Trade 문서 경로에 동일한 사본으로 보관한다.
- 서버 사본은 문서 백업이다. 문서 동기화만으로 컨테이너 빌드·배포·재시작·주문 기능 활성화를 하지 않는다.
- Oracle 서버와 그곳에서 중지된 연구 컨테이너는 두 제품 모두의 범위에서 제외한다.
