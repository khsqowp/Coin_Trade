# 실거래 전환 계획 (KIS 모의투자 → 토스 실전, 20만원 시작)

지금은 실행 안 함. 국장 자동화(kr_swing_loop)를 KIS 모의투자로 충분히 굴려서 신호/주문/손절 로직
자체가 맞다는 확신이 선 뒤, 실제 소액 자본을 넣기로 결정한 시점에 이 문서 순서대로 진행한다.

## 왜 토스로 바꾸나
KIS Open API(우리가 지금 쓰는 모의투자 계좌)는 정수 주(1주) 단위 주문만 지원한다. 20만원 같은 소액으로는
매수 가능한 종목이 45개 워치리스트 중 2개(기업은행/카카오뱅크)뿐이라 사실상 신호가 거의 안 걸린다.
토스는 실거래 계좌에서 미국주식 소수점 매매를 지원해서(매수는 금액지정, 매도는 수량지정 시장가) 같은
20만원으로도 대부분의 종목에 진입 가능해진다. 단, 한국투자증권 미니스탁과 마찬가지로 토스도 국내주식
소수점은 지원하지 않는다 — 소수점은 미국주식에서만 유효하다.

## 중요 제약 — 토스는 모의투자가 없음
KIS와 달리 토스 API는 페이퍼트레이딩 환경이 없다. 전환하는 순간 첫 주문부터 실제 자금이 나간다.
그러니까 "토스로 다시 테스트"는 불가능하고, 로직 검증은 반드시 KIS 모의투자 단계에서 끝내야 한다.

## 코드 변경 범위
- `kr_daily_scan.py` / `kr_intraday_risk.py`의 신호 판단 로직(EMA9/21 크로스 + SMA200 필터, -2% 손절)은
  그대로 둔다 — 브로커를 바꿔도 전략 자체는 안 바뀐다.
- 주문 실행부만 교체: `kis_order.py`(KIS 전용 TR_ID/엔드포인트)를 대체할 `toss_order.py` 신규 작성 필요.
  아직 작성 안 함 — 실거래 전환 시점에 토스 API로 실제 주문 가능 여부부터 다시 검증(§검증 항목 참고).
- 매수 방식 차이: KIS는 수량(ORD_QTY) 지정, 토스는 미국주식 매수 시 금액(orderAmount) 지정 — 수량을
  역산하는 대신 목표 매수금액을 그대로 넘기도록 주문함수 시그니처를 바꿔야 함.
- 매도 방식 차이: 토스 소수점 매도는 미국주식 "시장가" 주문에서만 허용 — 지정가 매도는 정수 단위로
  제한될 수 있음(미검증, 확인 필요).

## 파라미터 변경 (실거래 전환 시점에만 적용, 지금은 그대로 둠)
`trading/app/kr_watchlist.py` 현재 값:
- `MAX_CONCURRENT_POSITIONS = 5`
- `MAX_POSITION_FRACTION = 0.20`

20만원 같은 소액 실거래에서는 분산 자체가 의미 없으므로(위 계산 참고) 아래로 변경:
- `MAX_CONCURRENT_POSITIONS = 1` — 신호 뜬 종목 하나에 집중
- `MAX_POSITION_FRACTION = 0.95` — 사실상 풀매수

미국 시장에 동일 자동화(us_swing_loop 계열)를 만들 경우 같은 값 적용.

## 검증 항목 (실거래 전환 전 반드시 확인)
1. 토스 Open API에 실제로 프로그래매틱 주문 엔드포인트가 (미니스탁처럼 별도 앱 전용이 아니라) 열려있는지
   재확인 — 이전에 확인한 스펙은 있었지만 실제 계좌로 주문 테스트는 안 해봄.
2. 토스 앱키 발급 절차, 계좌연동 방식(OAuth 등) 확인.
3. 소수점 매수(금액지정) 주문의 최소 금액 단위, 수수료 체계 확인.
4. 실거래이므로 극소액(예: 1만원)으로 먼저 단발 주문 테스트 — 매수/매도 각 1건씩 왕복해서 체결/청산이
   의도대로 되는지 실측.
5. 3, 4번 통과 후에만 파라미터 변경 + kr_swing_loop을 실거래 계좌로 연결.
